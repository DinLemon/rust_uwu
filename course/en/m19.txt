```solution
#[derive(Debug, Clone, PartialEq)]
enum Status { Todo, Done }

#[derive(Debug, Clone)]
struct Task { id: u32, title: String, status: Status }

struct TodoList { tasks: Vec<Task>, next_id: u32 }

impl TodoList {
    fn new() -> Self {
        TodoList { tasks: Vec::new(), next_id: 1 }
    }

    fn add(&mut self, title: &str) -> u32 {
        let id = self.next_id;
        self.tasks.push(Task { id, title: title.to_string(), status: Status::Todo });
        self.next_id += 1;
        id
    }

    fn done(&mut self, id: u32) -> Result<(), String> {
        match self.tasks.iter_mut().find(|t| t.id == id) {
            Some(task) => {
                task.status = Status::Done;
                Ok(())
            }
            None => Err(format!("No task {id}")),
        }
    }

    fn show(&self) {
        for t in &self.tasks {
            let mark = if t.status == Status::Done { "x" } else { " " };
            println!("[{mark}] {}. {}", t.id, t.title);
        }
    }
}

fn main() {
    let mut list = TodoList::new();
    list.add("buy bread");
    list.add("learn Rust");
    list.done(2).unwrap();
    list.show();
    println!("{:?}", list.done(99));
}
```
```expect
[ ] 1. buy bread
[x] 2. learn Rust
Err("No task 99")
```
hint: In `add`: remember `let id = self.next_id;`, then `self.tasks.push(Task { ... })`, then `self.next_id += 1;` and return `id`.
hint: In `done`: `self.tasks.iter_mut().find(|t| t.id == id)` returns `Option<&mut Task>`. Check it with `match`.

:: recap
- `iter_mut().find(...)` finds an element in order to change it.
- No element — an honest `Err`, not a panic.

:: goals

:: text A command as an enum
The user writes text. Let us turn it into a clear type:

```rust
enum Command {
    Add(String),
    Done(u32),
    List,
}
```
The function `parse` turns a string into `Result<Command, String>`. Input mistakes are not a panic, but an `Err`.

:: task
Complete `parse`: `add text` → `Add`, `done number` → `Done`, `list` → `List`, everything else → `Err`. The rest of the program is ready.
```rust
#[derive(Debug)]
enum Command {
    Add(String),
    Done(u32),
    List,
}

fn parse(line: &str) -> Result<Command, String> {
    let (cmd, rest) = match line.trim().split_once(' ') {
        Some((c, r)) => (c, r.trim()),
        None => (line.trim(), ""),
    };
    match cmd {
        // your branches
        _ => Err(format!("Unknown command \"{cmd}\"")),
    }
}

fn main() {
    for line in ["add buy bread", "done 1", "list", "done abc", "jump"] {
        println!("{line} -> {:?}", parse(line));
    }
}
```
```solution
#[derive(Debug)]
enum Command {
    Add(String),
    Done(u32),
    List,
}

fn parse(line: &str) -> Result<Command, String> {
    let (cmd, rest) = match line.trim().split_once(' ') {
        Some((c, r)) => (c, r.trim()),
        None => (line.trim(), ""),
    };
    match cmd {
        "add" if !rest.is_empty() => Ok(Command::Add(rest.to_string())),
        "done" => rest
            .parse::<u32>()
            .map(Command::Done)
            .map_err(|_| format!("\"{rest}\" is not a task number")),
        "list" => Ok(Command::List),
        _ => Err(format!("Unknown command \"{cmd}\"")),
    }
}

fn main() {
    for line in ["add buy bread", "done 1", "list", "done abc", "jump"] {
        println!("{line} -> {:?}", parse(line));
    }
}
```
```expect
add buy bread -> Ok(Add("buy bread"))
done 1 -> Ok(Done(1))
list -> Ok(List)
done abc -> Err("\"abc\" is not a task number")
jump -> Err("Unknown command \"jump\"")
```
hint: The branch for add: `"add" => Ok(Command::Add(rest.to_string())),`
hint: For done, parse the number: `match rest.parse::<u32>() { Ok(n) => Ok(Command::Done(n)), Err(_) => Err(format!("\"{rest}\" is not a task number")) }`

Text statistics. Count the lines, words and letters (without spaces and line breaks). Print: `lines: 2, words: 6, letters: 25`.

fn main() {

fn main() {
    let text = "Rust is fast\nand very reliable";
    let lines = text.lines().count();
    let words = text.split_whitespace().count();
    let letters = text.chars().filter(|c| !c.is_whitespace()).count();

hint: Letters without spaces: `text.chars().filter(|c| !c.is_whitespace()).count()`.

:: task
A temperature converter. Parse strings like `"36.6C"` and `"100F"` and convert them to the other scale. Wrong input — `error`.
```rust
fn convert(input: &str) -> String {
    String::from("error")
}

fn main() {
    for s in ["100C", "212F", "abc", "20X"] {
        println!("{s} -> {}", convert(s));
    }
}
```
```solution
fn convert(input: &str) -> String {
    let Some(unit) = input.chars().last() else {
        return String::from("error");
    };
    let number = &input[..input.len() - unit.len_utf8()];
    let Ok(value) = number.parse::<f64>() else {
        return String::from("error");
    };
    match unit {
        'C' => format!("{}F", value * 1.8 + 32.0),
        'F' => format!("{}C", (value - 32.0) / 1.8),
        _ => String::from("error"),
    }
}

fn main() {
    for s in ["100C", "212F", "abc", "20X"] {
        println!("{s} -> {}", convert(s));
    }
}
```
```expect
100C -> 212F
212F -> 100C
abc -> error
20X -> error
```
hint: The last character is the unit: `input.chars().last()`. Everything before it is the number.
hint: The number without the last character: `&input[..input.len() - unit.len_utf8()]`, then `parse::<f64>()` and `match unit { 'C' => ..., 'F' => ..., _ => ... }`.

```solution
enum Op {
    Income(i64),
    Expense(i64),
}

fn main() {
    let ops = [Op::Income(500), Op::Expense(120), Op::Expense(80), Op::Income(50)];
    let balance = ops.iter().fold(100, |acc, op| match op {
        Op::Income(n) => acc + n,
        Op::Expense(n) => acc - n,
    });
    println!("{balance}");
}
```
```expect
450
```
hint: `ops.iter().fold(100, |acc, op| match op { ... })`
hint: The branches: `Op::Income(n) => acc + n,` and `Op::Expense(n) => acc - n,`

```solution
use std::collections::HashMap;

fn main() {
    let text = "cat dog cat fish dog cat";
    let mut counts: HashMap<&str, u32> = HashMap::new();
    for w in text.split_whitespace() {
        *counts.entry(w).or_insert(0) += 1;
    }
    let mut pairs: Vec<(&str, u32)> = counts.into_iter().collect();
    pairs.sort_by(|a, b| b.1.cmp(&a.1));
    for (word, n) in pairs.iter().take(2) {
        println!("{word}: {n}");
    }
}
```
```expect
cat: 3
dog: 2
```
hint: `let mut pairs: Vec<(&str, u32)> = counts.into_iter().collect();`
hint: Descending: `pairs.sort_by(|a, b| b.1.cmp(&a.1));`, then `pairs.iter().take(2)`.
