# MODULE m02 | Функции | Как разбить программу на маленькие кусочки

## LESSON m02-1 | Своя функция | 6
:: goals
- Зачем нужны функции
- Как написать свою функцию и вызвать её

:: text Функция — это маленькая программа
**Функция** — кусок кода с именем. Написал один раз — вызываешь сколько угодно.

> Как кнопка на пульте: нажал «громче» — и не думаешь, что внутри происходит.

`main` — тоже функция. Просто особенная: с неё всё начинается.

:: code
```rust
fn greet() {
    println!("Привет!");
    println!("Рад тебя видеть.");
}

fn main() {
    greet();
    greet();
}
```
```out
Привет!
Рад тебя видеть.
Привет!
Рад тебя видеть.
```
`greet();` — это **вызов**: «выполни функцию greet». Скобки обязательны.

:: quiz
Сколько раз напечатается «Привет!», если в `main` написать `greet();` три раза?
[ ] 1 => Каждый вызов выполняет функцию заново.
[x] 3 => Верно. Один вызов — одно выполнение.
[ ] 6 => В `greet` одна строка «Привет!». Три вызова — три раза.

:: order
Собери программу: функция `hello` и её вызов из `main`.
```rust
fn hello() {
    println!("hello");
}
fn main() {
    hello();
}
```

:: recap
- `fn имя() { ... }` — объявление функции.
- `имя();` — вызов.
- Порядок функций в файле не важен.

## LESSON m02-2 | Параметры | 6
:: goals
- Передавать в функцию данные
- Указывать типы параметров

:: text Функции нужны данные
Функция `greet` всегда говорит одно и то же. Скучно. Хочется передать ей имя.

Для этого есть **параметры** — переменные в круглых скобках:

```rust
fn greet(name: &str) {
    println!("Привет, {name}!");
}
```
`&str` — тип текста. Подробнее про него — в модуле о заимствовании.

:: text Тип параметра обязателен
Внутри функции Rust угадывает типы. А у параметров — **нет**. Тип надо написать всегда.

```rust
fn show_age(age: i32) { ... }
fn area(width: f64, height: f64) { ... }
```
Несколько параметров разделяются запятыми.

:: code
```rust
fn print_sum(a: i32, b: i32) {
    println!("{a} + {b} = {}", a + b);
}

fn main() {
    print_sum(2, 3);
    print_sum(10, -4);
}
```
```out
2 + 3 = 5
10 + -4 = 6
```

:: fill
Допиши функцию, чтобы она принимала число `n` типа `i32`.
```rust
fn print_double(___: ___) {
    println!("{}", n * 2);
}
```
= n
= i32
explain: Параметр пишется как `имя: тип`.

:: task
Напиши функцию `say_twice`, которая печатает переданный текст два раза. В `main` уже есть вызов.
```rust
// напиши функцию say_twice здесь

fn main() {
    say_twice("Rust");
}
```
```solution
fn say_twice(text: &str) {
    println!("{text}");
    println!("{text}");
}

fn main() {
    say_twice("Rust");
}
```
```expect
Rust
Rust
```
hint: Начни с `fn say_twice(text: &str) {`
hint: Внутри — две строки `println!("{text}");`

:: recap
- Параметры — входные данные функции.
- Тип параметра пишем всегда: `fn f(x: i32)`.
- При вызове передаём значения: `f(5)`.

## LESSON m02-3 | Возврат значения | 7
:: goals
- Как функция возвращает результат
- Разница между выражением и инструкцией
- Почему важна последняя строка без `;`

:: text Функция может что-то вернуть
Функция может не только печатать, но и **вернуть** результат. Как калькулятор: дал числа — получил ответ.

Тип результата пишут после стрелки `->`:

```rust
fn double(x: i32) -> i32 {
    x * 2
}
```

:: text Последняя строка без точки с запятой
Заметил? `x * 2` написано **без** `;`. Это не опечатка.

В Rust последняя строка функции без `;` и есть результат. Её называют **выражением**: у неё есть значение.

Строка с `;` — **инструкция**. Она что-то делает, но значения не отдаёт.

:: code
```rust
fn square(n: i32) -> i32 {
    n * n
}

fn main() {
    let result = square(7);
    println!("7 в квадрате = {result}");
    println!("3 в квадрате = {}", square(3));
}
```
```out
7 в квадрате = 49
3 в квадрате = 9
```

:: code
А теперь лишняя `;`. Запусти и посмотри на ошибку.
```rust
fn square(n: i32) -> i32 {
    n * n;
}

fn main() {
    println!("{}", square(3));
}
```
fails: yes
Компилятор пишет `mismatched types`: обещали вернуть `i32`, а вернули «ничего» `()`. И подсказывает: `remove this semicolon` — убери точку с запятой.

:: text Слово return
Можно вернуть значение и явно, словом `return`. Обычно так делают, чтобы выйти **раньше** конца функции:

```rust
fn safe_div(a: i32, b: i32) -> i32 {
    if b == 0 {
        return 0;
    }
    a / b
}
```

:: quiz
Что вернёт эта функция при вызове `add_one(5)`?
```rust
fn add_one(x: i32) -> i32 {
    x + 1
}
```
[x] 6 => Верно. Последняя строка без `;` — результат.
[ ] 5 => Функция прибавляет единицу.
[ ] Ничего, ведь нет `return` => `return` не нужен: последнее выражение возвращается само.

:: task
Напиши функцию `max`, которая возвращает большее из двух чисел. Программа должна напечатать `9`.
```rust
fn max(a: i32, b: i32) -> i32 {
    // твой код
}

fn main() {
    println!("{}", max(4, 9));
}
```
```solution
fn max(a: i32, b: i32) -> i32 {
    if a > b { a } else { b }
}

fn main() {
    println!("{}", max(4, 9));
}
```
```expect
9
```
hint: Тебе пригодится `if a > b { ... } else { ... }`. Подробно про `if` — в следующем модуле.
hint: `if` тоже возвращает значение: `if a > b { a } else { b }` — без точек с запятой.

:: recap
- `-> тип` — что функция возвращает.
- Последнее выражение без `;` — результат.
- Лишняя `;` в конце превращает результат в «ничего» `()`.
- `return` — выйти из функции раньше.

## LESSON m02-4 | Блоки и область видимости | 5
:: goals
- Что такое блок `{ }`
- Где «живёт» переменная

:: text Блок тоже выражение
Любые фигурные скобки `{ }` — это **блок**. Его последнее выражение — значение блока.

```rust
let total = {
    let a = 2;
    let b = 3;
    a + b
}; // total = 5
```

:: text Переменная живёт внутри своего блока
**Область видимости** — участок кода, где переменную видно. Обычно это блок, где её создали.

```rust
fn main() {
    {
        let secret = 42;
        println!("{secret}"); // тут видно
    }
    // println!("{secret}"); // тут уже нет — ошибка
}
```
> Как комната: вещь, оставленная внутри, не видна из коридора.

:: quiz
Что будет, если раскомментировать последнюю строку в примере выше?
[ ] Напечатается 42 => Переменная `secret` исчезла вместе со своим блоком.
[x] Ошибка компиляции: `secret` не найдена => Верно. За закрывающей `}` переменной уже нет.
[ ] Напечатается 0 => Rust не придумывает значений. Он просто не найдёт переменную.

:: recap
- `{ ... }` — блок. Его значение — последнее выражение.
- Переменная видна только внутри блока, где создана.
