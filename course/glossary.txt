// термин | английский | объяснение
Программа | program | Список команд для компьютера. Выполняются по порядку, сверху вниз.
Компилятор | compiler | Программа, которая проверяет код и переводит его в машинные команды. У Rust это `rustc`.
Функция | function | Кусок кода с именем. Пишется через `fn`, вызывается как `имя()`.
Макрос | macro | Код, который пишет код до компиляции. Узнаётся по `!`: `println!`, `vec!`.
Переменная | variable | Коробка с именем и значением. Создаётся через `let`.
Изменяемая переменная | mutable | Переменная, которую можно менять. Пишется `let mut`.
Константа | constant | Значение, которое не меняется никогда: `const MAX: u32 = 10;`.
Затенение | shadowing | Новый `let` с тем же именем создаёт новую переменную, старая прячется.
Тип | type | Что лежит в переменной: число, текст, `bool` и так далее.
Выражение | expression | Код, у которого есть значение: `2 + 2`, вызов функции, блок `{}`.
Инструкция | statement | Код, который что-то делает, но значения не даёт. Обычно кончается на `;`.
Область видимости | scope | Участок кода, где переменную видно. Обычно — её блок `{}`.
Комментарий | comment | Заметка для людей после `//`. Компьютер её пропускает.
Цикл | loop | Повторение кода: `loop`, `while`, `for`.
Диапазон | range | Последовательность чисел: `1..5` (без 5) или `1..=5` (с 5).
Кортеж | tuple | Несколько значений разных типов в скобках: `("Аня", 25)`.
Массив | array | Ряд значений одного типа фиксированной длины: `[1, 2, 3]`.
Вектор | Vec | Список одного типа, который может расти: `vec![1, 2, 3]`.
Индекс | index | Номер элемента. Считается с нуля.
Паника | panic | Аварийная остановка программы. Например, при выходе за границы массива.
Стек | stack | Быстрая память для данных известного размера. Как стопка тарелок.
Куча | heap | Память для данных, которые могут расти. Как склад с номерками.
Владение | ownership | Правила: у значения один владелец; ушёл владелец — значение удалено.
Владелец | owner | Переменная, которая отвечает за значение и его удаление.
Перемещение | move | Передача владения: `let b = a;` для `String`. После этого `a` использовать нельзя.
Клонирование | clone | Полная копия значения: `.clone()`.
Copy | Copy | Трейт простых типов (числа, `bool`, `char`), которые копируются сами.
Ссылка | reference | Доступ к значению без владения: `&x`.
Заимствование | borrowing | Создание ссылки. Как дать книгу почитать.
Изменяемая ссылка | mutable reference | Ссылка, через которую можно менять: `&mut x`. Одновременно может быть только одна.
Висячая ссылка | dangling reference | Ссылка на значение, которого уже нет. Rust их не допускает.
Срез | slice | Ссылка на часть последовательности: `&v[1..3]`.
Строковый срез | &str | Ссылка на текст. Текст в кавычках — тоже `&str`.
String | String | Владеющая строка в куче. Может расти.
UTF-8 | UTF-8 | Способ хранить текст. Русская буква занимает 2 байта.
Структура | struct | Свой тип из именованных полей.
Метод | method | Функция типа, пишется в `impl` и вызывается через точку.
Конструктор | constructor | Функция, которая создаёт значение. Обычно `new()`.
Перечисление | enum | Тип, значение которого — один вариант из списка.
Сопоставление с образцом | pattern matching | Выбор ветки по форме значения: `match`, `if let`.
Option | Option | `Some(значение)` или `None`. Замена `null`.
Result | Result | `Ok(значение)` или `Err(ошибка)`. Для операций, которые могут не удаться.
Оператор ? | question mark operator | Достать `Ok`, а при ошибке сразу вернуть её из функции.
HashMap | HashMap | Словарь: ключ → значение.
Модуль | module | Именованная часть кода: `mod имя { }`.
Крейт | crate | Программа или библиотека, которая собирается целиком.
Cargo | Cargo | Инструмент для создания, сборки, запуска и тестирования проектов.
rustup | rustup | Установщик и обновлятор Rust.
Обобщение | generics | Код для любого типа: `fn f<T>(x: T)`.
Трейт | trait | Описание умения типа: набор методов. Синоним — «типаж».
Ограничение трейтом | trait bound | Требование к типу: `T: Display`.
derive | derive | Автоматическая реализация трейтов: `#[derive(Debug)]`.
Время жизни | lifetime | Сколько живёт ссылка. Метка вида `'a`.
'static | 'static | Время жизни «вся программа». У текста в кавычках.
Замыкание | closure | Безымянная функция на месте: `|x| x + 1`. Видит переменные вокруг.
Итератор | iterator | Выдаёт элементы по одному. С ним работают `map`, `filter`, `collect`.
Ленивость | laziness | Итератор ничего не делает, пока не попросят результат.
Тест | test | Функция с `#[test]`, которая проверяет код.
Умный указатель | smart pointer | Адрес значения плюс правила владения: `Box`, `Rc`, `Arc`.
Box | Box | Кладёт значение в кучу.
Rc | Rc | Несколько владельцев одного значения в одном потоке.
RefCell | RefCell | Позволяет менять значение через общий доступ. Проверка — при запуске.
Поток | thread | Отдельная линия выполнения программы.
Канал | channel | Труба для сообщений между потоками.
Mutex | Mutex | Замок: пускает к данным по одному.
Arc | Arc | Как `Rc`, но безопасный для потоков.
async | async | Способ писать код, который много ждёт, не занимая потоки.
Future | Future | Обещание результата. Выполняется исполнителем после `.await`.
Рантайм | runtime | Исполнитель async-кода. В реальных проектах — tokio.
unsafe | unsafe | Блок, где компилятор не проверяет часть правил. Новичку не нужен.
Редакция | edition | Версия правил языка. Сейчас актуальна 2024.
Rust Playground | Rust Playground | Сайт, где запускается код Rust. Им пользуется этот курс.
Разыменование | dereference | Получить значение по ссылке: `*r`.
Рекурсия | recursion | Функция вызывает сама себя.
