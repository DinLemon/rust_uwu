```solution
#[derive(Debug, Clone, PartialEq)]
enum Status { Todo, Done }

#[derive(Debug, Clone)]
struct Task { id: u32, title: String, status: Status }

struct TodoList { tasks: Vec<Task>, next_id: u32 }

impl TodoList {
    fn new() -> Self {
        TodoList { tasks: Vec::new(), next_id: 1 }
    }

    fn add(&mut self, title: &str) -> u32 {
        let id = self.next_id;
        self.tasks.push(Task { id, title: title.to_string(), status: Status::Todo });
        self.next_id += 1;
        id
    }

    fn done(&mut self, id: u32) -> Result<(), String> {
        match self.tasks.iter_mut().find(|t| t.id == id) {
            Some(task) => {
                task.status = Status::Done;
                Ok(())
            }
            None => Err(format!("Нет задачи {id}")),
        }
    }

    fn show(&self) {
        for t in &self.tasks {
            let mark = if t.status == Status::Done { "x" } else { " " };
            println!("[{mark}] {}. {}", t.id, t.title);
        }
    }
}

fn main() {
    let mut list = TodoList::new();
    list.add("купить хлеб");
    list.add("учить Rust");
    list.done(2).unwrap();
    list.show();
    println!("{:?}", list.done(99));
}
```
```expect
[ ] 1. купить хлеб
[x] 2. учить Rust
Err("Нет задачи 99")
```
hint: В `add`: запомни `let id = self.next_id;`, потом `self.tasks.push(Task { ... })`, потом `self.next_id += 1;` и верни `id`.
hint: В `done`: `self.tasks.iter_mut().find(|t| t.id == id)` вернёт `Option<&mut Task>`. Разбери его через `match`.

:: recap
- `iter_mut().find(...)` — найти элемент, чтобы изменить.
- Нет элемента — честный `Err`, а не паника.

## LESSON m19-3 | Шаг 3 — команды | 8
:: goals
- Разобрать текстовую команду в enum
- Связать всё через `match`

:: text Команда как перечисление
Пользователь пишет текст. Превратим его в понятный тип:

```rust
enum Command {
    Add(String),
    Done(u32),
    List,
}
```
Функция `parse` превращает строку в `Result<Command, String>`. Ошибки ввода — не паника, а `Err`.

:: task
Допиши `parse`: `add текст` → `Add`, `done число` → `Done`, `list` → `List`, остальное — `Err`. Остальная программа уже готова.
```rust
#[derive(Debug)]
enum Command {
    Add(String),
    Done(u32),
    List,
}

fn parse(line: &str) -> Result<Command, String> {
    let (cmd, rest) = match line.trim().split_once(' ') {
        Some((c, r)) => (c, r.trim()),
        None => (line.trim(), ""),
    };
    match cmd {
        // твои ветки
        _ => Err(format!("Не знаю команду «{cmd}»")),
    }
}

fn main() {
    for line in ["add купить хлеб", "done 1", "list", "done abc", "jump"] {
        println!("{line} -> {:?}", parse(line));
    }
}
```
```solution
#[derive(Debug)]
enum Command {
    Add(String),
    Done(u32),
    List,
}

fn parse(line: &str) -> Result<Command, String> {
    let (cmd, rest) = match line.trim().split_once(' ') {
        Some((c, r)) => (c, r.trim()),
        None => (line.trim(), ""),
    };
    match cmd {
        "add" if !rest.is_empty() => Ok(Command::Add(rest.to_string())),
        "done" => rest
            .parse::<u32>()
            .map(Command::Done)
            .map_err(|_| format!("«{rest}» — не номер задачи")),
        "list" => Ok(Command::List),
        _ => Err(format!("Не знаю команду «{cmd}»")),
    }
}

fn main() {
    for line in ["add купить хлеб", "done 1", "list", "done abc", "jump"] {
        println!("{line} -> {:?}", parse(line));
    }
}
```
```expect
add купить хлеб -> Ok(Add("купить хлеб"))
done 1 -> Ok(Done(1))
list -> Ok(List)
done abc -> Err("«abc» — не номер задачи")
jump -> Err("Не знаю команду «jump»")
```
hint: Ветка для add: `"add" => Ok(Command::Add(rest.to_string())),`
hint: Для done разбери число: `match rest.parse::<u32>() { Ok(n) => Ok(Command::Done(n)), Err(_) => Err(format!("«{rest}» — не номер задачи")) }`
