# MODULE m00 | Старт | Что такое программа и как говорить с компьютером

## LESSON m00-1 | Что такое программирование | 4
:: goals
- Что такое программа
- Что такое Rust и зачем он нужен
- Как устроен этот курс

:: text Программа — это рецепт
**Программа** — это список команд для компьютера.

Как рецепт: «возьми, смешай, поставь в духовку». Компьютер выполняет команды по очереди, сверху вниз.

Компьютер очень быстрый, но совсем не догадливый. Он делает **ровно** то, что написано. Не больше.

:: text Язык программирования
Компьютер понимает только нули и единицы. Писать ими неудобно.

Поэтому люди придумали **языки программирования**. Ты пишешь текст, похожий на английский. Специальная программа переводит его в нули и единицы.

**Rust** (читается «раст») — один из таких языков.

:: quiz
Что делает компьютер, если в программе есть ошибка в логике?
[ ] Сам понимает, что ты имел в виду, и исправляет => Компьютер не умеет догадываться. Он не знает, что ты «имел в виду».
[x] Выполняет ровно то, что написано => Да. Поэтому программы пишут точно и аккуратно.
[ ] Отказывается работать и выключается => Обычно нет. Он просто сделает то, что написано, даже если это бессмыслица.

:: text Чем хорош Rust
- **Быстрый.** Программы на Rust работают так же быстро, как на C и C++.
- **Надёжный.** Многие ошибки он ловит **до** запуска программы.
- **Популярный.** На нём пишут браузеры, игры, сервера, утилиты и даже части Windows и Linux.

> Rust считают сложным. Это правда только наполовину. Он строгий, но объясняет каждую свою претензию. Мы пойдём маленькими шагами.

:: text Как устроен курс
- Урок — 5–10 минут.
- Один экран — одна мысль.
- Жми «Дальше», когда готов. Таймеров нет.
- Ошибаться можно сколько угодно. Ошибка — это тоже шаг.
- Устал — закрой вкладку. Курс запомнит, где ты остановился.

:: quiz
Что делать, если на каком-то шаге стало скучно или тяжело?
[ ] Заставить себя дочитать модуль до конца => Так обычно становится только хуже. Короткие перерывы помогают лучше.
[x] Сделать перерыв: прогресс сохранится сам => Да. Вернёшься — продолжишь с того же шага.
[ ] Начать курс заново => Не нужно. Всё пройденное уже сохранено.

:: recap
- Программа — список команд. Компьютер выполняет их по порядку.
- Компьютер делает ровно то, что написано.
- Rust — быстрый и строгий язык. Он ловит ошибки до запуска.

## LESSON m00-2 | Первая программа | 6
:: goals
- Написать и запустить первую программу
- Узнать, что такое `fn main` и `println!`

:: text Привет, мир!
Первая программа любого программиста печатает «Привет, мир!».

Ниже — настоящая программа на Rust. Нажми **«▶ Запустить»**. Код отправится на сервер Rust Playground, скомпилируется и вернёт результат.

:: code
```rust
fn main() {
    println!("Привет, мир!");
}
```
```out
Привет, мир!
```
Получилось? Ты только что запустил программу на Rust.

:: text Разберём по словам
```rust
fn main() {
    println!("Привет, мир!");
}
```
- `fn` — сокращение от function, **функция**. Это именованный кусок программы.
- `main` — имя функции. Программа **всегда** начинается с функции `main`.
- `{` и `}` — фигурные скобки. Внутри — команды функции.
- `println!` — команда «напечатай строку».

:: text Мелочи, которые важны
```rust
println!("Привет, мир!");
```
- Текст пишется в двойных кавычках: `"..."`.
- В конце команды стоит точка с запятой `;`.
- У `println!` есть восклицательный знак. Он значит, что это **макрос** — особая команда. Подробнее — в конце курса. Пока просто помни: `println!` пишется с `!`.

:: quiz
С какой функции начинается любая программа на Rust?
[ ] `start` => Такого правила нет. Попробуй ещё.
[x] `main` => Верно. `main` — главная функция, вход в программу.
[ ] `println!` => `println!` печатает текст. Но программа начинается не с неё.

:: order
Собери программу, которая печатает «Hi».
```rust
fn main() {
    println!("Hi");
}
```
explain: Сначала заголовок функции, потом команда внутри, потом закрывающая скобка.

:: task
Измени программу так, чтобы она напечатала **Меня зовут Rust**.
```rust
fn main() {
    println!("Привет, мир!");
}
```
```solution
fn main() {
    println!("Меня зовут Rust");
}
```
```expect
Меня зовут Rust
```
hint: Меняй только текст внутри кавычек.
hint: Должно получиться: `println!("Меня зовут Rust");`

:: recap
- Программа начинается с `fn main() { ... }`.
- `println!("текст");` печатает строку.
- Текст — в кавычках, в конце команды — `;`.

## LESSON m00-3 | Компилятор — твой строгий друг | 6
:: goals
- Что такое компилятор
- Как читать сообщения об ошибках

:: text Кто такой компилятор
**Компилятор** — программа, которая переводит твой код в нули и единицы.

У Rust компилятор называется `rustc`. Перед переводом он внимательно проверяет код. Нашёл проблему — не переводит, а пишет сообщение.

> Представь учителя, который проверяет сочинение до того, как его отправят в печать. Строгий, но всегда объясняет, что не так.

:: text Ошибка — это нормально
Ошибки компиляции видят **все**: новички и профи с опытом 20 лет.

Ошибка не значит «я плохо стараюсь». Она значит «компилятор нашёл место, которое надо уточнить». Это подсказка, а не оценка.

:: code
Здесь пропущена точка с запятой. Запусти и посмотри, что скажет компилятор.
```rust
fn main() {
    println!("Раз")
    println!("Два");
}
```
fails: yes
Компилятор пишет `expected ;` — «ожидалась `;`» — и показывает стрелкой, где именно.

:: text Как читать ошибку
Сообщение об ошибке обычно состоит из трёх частей:
1. `error` и короткое описание: что не так.
2. Номер строки и кусок кода со стрелкой `^`: где.
3. Иногда `help`: как исправить.

Читай **сверху вниз** и сначала первую ошибку. Часто остальные исчезают сами, когда исправишь первую.

:: quiz
В программе пять ошибок. С какой лучше начать?
[x] С самой первой => Да. Одна ошибка часто вызывает целую цепочку следующих.
[ ] С последней => Последние часто — эхо первой. Начни сверху.
[ ] С самой короткой => Длина сообщения не важна. Важен порядок.

:: task
Почини программу: компилятор ругается. Нажми «Запустить», прочитай сообщение и исправь.
```rust
fn main() {
    println("Я починил программу!");
}
```
```solution
fn main() {
    println!("Я починил программу!");
}
```
```expect
Я починил программу!
```
hint: Посмотри внимательно на имя команды. Чего-то не хватает.
hint: У `println` должен быть восклицательный знак: `println!`.

:: recap
- Компилятор проверяет код до запуска.
- Ошибки — это подсказки, а не провал.
- Читай ошибки сверху вниз, начинай с первой.

## LESSON m00-4 | Несколько строк и комментарии | 5
:: goals
- Печатать несколько строк
- Писать комментарии для людей

:: text Команды идут по порядку
Внутри `main` можно написать много команд. Они выполняются сверху вниз, одна за другой.

:: code
```rust
fn main() {
    println!("Шаг 1: проснуться");
    println!("Шаг 2: выпить воды");
    println!("Шаг 3: учить Rust");
}
```
```out
Шаг 1: проснуться
Шаг 2: выпить воды
Шаг 3: учить Rust
```

:: text Комментарии
**Комментарий** — заметка для человека. Компьютер её пропускает.

Комментарий начинается с двух косых черт `//` и идёт до конца строки.

```rust
fn main() {
    // Это комментарий. Он ничего не делает.
    println!("А это команда"); // комментарий можно и в конце строки
}
```

:: quiz
Что напечатает программа?
```rust
fn main() {
    println!("А");
    // println!("Б");
    println!("В");
}
```
[ ] А, Б, В => Строка с «Б» закомментирована. Компьютер её пропустит.
[x] А, В => Верно. Закомментированная строка не выполняется.
[ ] Только В => Первая строка — обычная команда. Она выполнится.

:: text Пустая строка и `print!`
- `println!()` без текста печатает пустую строку.
- `print!` печатает **без** перехода на новую строку.

```rust
fn main() {
    print!("Раз, ");
    print!("два, ");
    println!("три!");
    println!();
    println!("Конец");
}
```

:: task
Напиши программу, которая печатает три строки:
```text
Rust
это
весело
```
```rust
fn main() {
    // напиши здесь три команды
}
```
```solution
fn main() {
    println!("Rust");
    println!("это");
    println!("весело");
}
```
```expect
Rust
это
весело
```
hint: Тебе нужны три команды `println!`.
hint: Первая: `println!("Rust");`

:: recap
- Команды выполняются сверху вниз.
- `// ...` — комментарий. Компьютер его не читает.
- `println!` переходит на новую строку, `print!` — нет.
