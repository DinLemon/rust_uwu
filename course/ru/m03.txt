# MODULE m03 | Условия и циклы | Как программа выбирает и повторяет

## LESSON m03-1 | if и else | 6
:: goals
- Выполнять код только при условии
- Выбирать между вариантами

:: text Если… то…
`if` («если») выполняет блок, только когда условие — правда.

```rust
if temperature > 30 {
    println!("Жарко!");
}
```
Условие обязательно типа `bool`. Скобки вокруг условия не нужны.

:: code
```rust
fn main() {
    let hour = 14;
    if hour < 12 {
        println!("Доброе утро");
    } else if hour < 18 {
        println!("Добрый день");
    } else {
        println!("Добрый вечер");
    }
}
```
```out
Добрый день
```
Rust проверяет условия сверху вниз и выполняет **первую** подходящую ветку. Поменяй `hour` и запусти снова.

:: quiz
Что напечатает программа при `hour = 9`?
[x] Доброе утро => Верно. Первое же условие `9 < 12` — правда.
[ ] Добрый день => До второй ветки дело не дойдёт: первая уже подошла.
[ ] Доброе утро и Добрый день => Выполняется только одна ветка.

:: text if возвращает значение
Как блок, `if` тоже даёт значение. Его можно положить в переменную:

```rust
let label = if age >= 18 { "взрослый" } else { "ребёнок" };
```
!> Обе ветки должны вернуть **один и тот же тип**.

:: task
Напиши программу: если `number` чётное, напечатай `чётное`, иначе `нечётное`. Сейчас `number = 7`.
```rust
fn main() {
    let number = 7;
    // твой код
}
```
```solution
fn main() {
    let number = 7;
    if number % 2 == 0 {
        println!("чётное");
    } else {
        println!("нечётное");
    }
}
```
```expect
нечётное
```
hint: Число чётное, если остаток от деления на 2 равен 0.
hint: Условие: `number % 2 == 0`.

:: deep Почему в Rust нет оператора «?:»
Во многих языках есть короткая запись условия: `условие ? да : нет`. В Rust её нет.

Она не нужна: `if` в Rust сам возвращает значение. Поэтому то же самое пишут так:

```rust
let price = if is_member { 90 } else { 100 };
```
Это одна из идей Rust: почти всё — **выражение** и даёт значение. Так меньше особых правил.

:: recap
- `if условие { } else if условие { } else { }`.
- Выполняется первая подходящая ветка.
- `if` может вернуть значение; типы веток совпадают.

## LESSON m03-2 | Цикл loop | 5
:: goals
- Повторять код бесконечно
- Выходить из цикла через `break`

:: text Повторяй, пока не скажу стоп
**Цикл** — повторение кода. Самый простой — `loop`. Он крутится бесконечно, пока не встретит `break` («прервать»).

:: code
```rust
fn main() {
    let mut count = 1;
    loop {
        println!("Круг {count}");
        if count == 3 {
            break;
        }
        count += 1;
    }
    println!("Готово!");
}
```
```out
Круг 1
Круг 2
Круг 3
Готово!
```

:: text continue — пропустить шаг
`continue` сразу переходит к следующему повтору, пропуская остаток блока.

> **Аналогия:** `break` — выйти из комнаты. `continue` — выйти и сразу зайти заново.

:: quiz
Что будет, если в цикле `loop` нет `break`?
[ ] Цикл выполнится один раз => `loop` повторяет блок снова и снова.
[x] Цикл будет крутиться вечно => Да. Программа зависнет, пока её не остановят.
[ ] Ошибка компиляции => Компилятор разрешает бесконечные циклы: иногда они и правда нужны.

:: text break может вернуть значение
```rust
let mut n = 1;
let result = loop {
    n *= 2;
    if n > 100 {
        break n;
    }
};
// result = 128
```

:: deep Метки циклов
Если один цикл внутри другого, `break` выходит только из **внутреннего**. Чтобы выйти сразу из внешнего, циклу дают **метку** — имя с апострофом:

```rust
fn main() {
    'outer: for a in 1..=3 {
        for b in 1..=3 {
            if a * b == 4 {
                println!("Нашёл: {a} × {b}");
                break 'outer;
            }
        }
    }
}
```
```out
Нашёл: 2 × 2
```
Так же работает `continue 'outer`: перейти к следующему шагу внешнего цикла.

:: recap
- `loop { }` — повторять бесконечно.
- `break` — выйти, `break значение` — выйти с результатом.
- `continue` — сразу к следующему повтору.

## LESSON m03-3 | Циклы while и for | 7
:: goals
- Цикл с условием `while`
- Перебор чисел через `for` и диапазоны

:: text while — пока правда
`while` («пока») повторяет блок, пока условие правда.

```rust
let mut fuel = 3;
while fuel > 0 {
    println!("Летим! Топливо: {fuel}");
    fuel -= 1;
}
```

:: text for и диапазоны
`for` перебирает значения по очереди. Чаще всего — числа из **диапазона**:

- `1..5` — от 1 до 4. Правый край **не входит**.
- `1..=5` — от 1 до 5. Знак `=` включает правый край.

:: code
```rust
fn main() {
    for i in 1..=3 {
        println!("Отжимание номер {i}");
    }
    for i in (1..=3).rev() {
        println!("{i}...");
    }
    println!("Старт!");
}
```
```out
Отжимание номер 1
Отжимание номер 2
Отжимание номер 3
3...
2...
1...
Старт!
```
`.rev()` переворачивает диапазон: считаем назад.

:: quiz
Сколько раз выполнится `for i in 0..10`?
[ ] 11 => Правый край `10` не входит в `0..10`.
[x] 10 => Верно: числа от 0 до 9.
[ ] 9 => Ноль тоже считается. От 0 до 9 — это десять чисел.

:: task
Посчитай сумму чисел от 1 до 100 включительно и напечатай её.
```rust
fn main() {
    let mut sum = 0;
    // цикл здесь
    println!("{sum}");
}
```
```solution
fn main() {
    let mut sum = 0;
    for i in 1..=100 {
        sum += i;
    }
    println!("{sum}");
}
```
```expect
5050
```
hint: Тебе нужен `for i in 1..=100`.
hint: Внутри цикла: `sum += i;`

:: text Шаг больше единицы
Метод `.step_by(n)` перебирает числа через `n`:

```rust
for i in (0..=10).step_by(5) {
    println!("{i}"); // 0, 5, 10
}
```
`for` умеет перебирать не только числа. Например, буквы строки или элементы списка. Это будет в следующих модулях.

:: recap
- `while условие { }` — пока правда.
- `for x in 1..=n { }` — перебор.
- `a..b` без правого края, `a..=b` с ним.

## LESSON m03-4 | Практика: FizzBuzz | 7
:: goals
- Собрать вместе `for`, `if` и `%`
- Решить классическую задачу

:: text Задача FizzBuzz
Это знаменитая задача с собеседований. Правила для чисел от 1 до 15:

- делится на 3 и на 5 — печатай `FizzBuzz`;
- делится только на 3 — `Fizz`;
- делится только на 5 — `Buzz`;
- иначе — само число.

> Подсказка: проверку «на 3 и на 5» ставь **первой**. Иначе до неё не дойдёт очередь.

:: fill
Заполни условия.
```rust
fn main() {
    for n in 1..=15 {
        if n % 15 == 0 {
            println!("FizzBuzz");
        } else if n % ___ == 0 {
            println!("Fizz");
        } else if n % ___ == 0 {
            println!("Buzz");
        } else {
            println!("{n}");
        }
    }
}
```
= 3
= 5
explain: Число делится на 3 и на 5 одновременно, только если делится на 15.

:: task
Теперь целиком сам. Напиши FizzBuzz для чисел от 1 до 15.
```rust
fn main() {
    for n in 1..=15 {
        // твой код
    }
}
```
```solution
fn main() {
    for n in 1..=15 {
        if n % 15 == 0 {
            println!("FizzBuzz");
        } else if n % 3 == 0 {
            println!("Fizz");
        } else if n % 5 == 0 {
            println!("Buzz");
        } else {
            println!("{n}");
        }
    }
}
```
```expect
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```
hint: Проверь сначала `n % 15 == 0`.
hint: Потом `else if n % 3 == 0`, потом `else if n % 5 == 0`, и в конце `else`.

:: recap
- Порядок условий важен: самое узкое — первым.
- `%` помогает проверять делимость.

## LESSON m03-p | Практика: условия и циклы | 12 | practice
:: goals
- Сочетать циклы и условия
- Писать вложенные циклы

:: task
Напечатай строку таблицы умножения на 7: числа от `7 × 1 = 7` до `7 × 5 = 35`, каждое на своей строке.
```rust
fn main() {
}
```
```solution
fn main() {
    for i in 1..=5 {
        println!("7 × {i} = {}", 7 * i);
    }
}
```
```expect
7 × 1 = 7
7 × 2 = 14
7 × 3 = 21
7 × 4 = 28
7 × 5 = 35
```
check: exact
hint: Цикл `for i in 1..=5`.
hint: `println!("7 × {i} = {}", 7 * i);`

:: task
Посчитай сумму только чётных чисел от 1 до 20.
```rust
fn main() {
    let mut sum = 0;
    println!("{sum}");
}
```
```solution
fn main() {
    let mut sum = 0;
    for i in 1..=20 {
        if i % 2 == 0 {
            sum += i;
        }
    }
    println!("{sum}");
}
```
```expect
110
```
hint: Внутри цикла добавляй `i`, только если `i % 2 == 0`.
hint: Или так: `for i in (2..=20).step_by(2) { sum += i; }`

:: task
Через `while` сделай обратный отсчёт от 5 до 1, а в конце напечатай `Пуск!`.
```rust
fn main() {
    let mut n = 5;
}
```
```solution
fn main() {
    let mut n = 5;
    while n > 0 {
        println!("{n}");
        n -= 1;
    }
    println!("Пуск!");
}
```
```expect
5
4
3
2
1
Пуск!
```
hint: Условие цикла: `while n > 0`.
hint: Не забудь уменьшать `n` внутри цикла: `n -= 1;`

:: task
С помощью `loop` и `break` со значением найди первое число больше 50, которое делится и на 7, и на 4. Напечатай его.
```rust
fn main() {
    let mut n = 51;
    let found = 0; // замени на loop
    println!("{found}");
}
```
```solution
fn main() {
    let mut n = 51;
    let found = loop {
        if n % 7 == 0 && n % 4 == 0 {
            break n;
        }
        n += 1;
    };
    println!("{found}");
}
```
```expect
56
```
hint: `let found = loop { ... };` — после `}` нужна `;`.
hint: Внутри: если подходит — `break n;`, иначе `n += 1;`

:: task
Напечатай треугольник из звёздочек высотой 4. Нужны два цикла: внешний — по строкам, внутренний — по звёздочкам.
```text
*
**
***
****
```
```rust
fn main() {
}
```
```solution
fn main() {
    for row in 1..=4 {
        for _ in 0..row {
            print!("*");
        }
        println!();
    }
}
```
```expect
*
**
***
****
```
check: exact
hint: Внешний цикл `for row in 1..=4`. Внутри — `row` раз печатай `*` через `print!`.
hint: После внутреннего цикла — `println!();`, чтобы перейти на новую строку.

:: recap
- Цикл + `if` внутри — частый приём.
- `loop` с `break значение` удобен для поиска.
- Вложенные циклы: внешний — строки, внутренний — элементы строки.
