# MODULE m09 | Коллекции | Vec, String и HashMap поближе

## LESSON m09-1 | Vec подробнее | 6
:: goals
- Добавлять, удалять и менять элементы вектора
- Безопасный доступ через `get`

:: text Главные операции
```rust
let mut v = vec![10, 20, 30];
v.push(40);          // добавить в конец
let last = v.pop();  // забрать последний: Some(40)
v[0] = 5;            // заменить первый
v.remove(1);         // удалить по индексу
v.insert(0, 1);      // вставить в начало
v.contains(&30);     // есть ли элемент: true
```

:: text [] или get
- `v[i]` — быстро, но если элемента нет — **паника**.
- `v.get(i)` — возвращает `Option`. Нет элемента — `None`, без паники.

> Если индекс приходит от пользователя или из файла, бери `get`.

:: code
Перебор с изменением: `&mut` даёт менять каждый элемент.
```rust
fn main() {
    let mut prices = vec![100, 250, 80];
    for p in &mut prices {
        *p = *p * 2;
    }
    println!("{:?}", prices);
    println!("{:?}", prices.get(10));
}
```
```out
[200, 500, 160]
None
```
`*p` — **разыменование**: «значение, на которое смотрит ссылка». Без `*` мы бы меняли саму ссылку.

:: quiz
Что вернёт `vec![1, 2, 3].get(3)`?
[ ] 3 => Индекс 3 — это четвёртый элемент. Его нет.
[x] None => Верно. Элемента нет, и `get` честно говорит об этом.
[ ] Программа запаникует => Паникует `[3]`, а `get` — нет.

:: task
Удали из вектора все нечётные числа и напечатай результат. Подсказка: у вектора есть метод `retain`.
```rust
fn main() {
    let mut nums = vec![1, 2, 3, 4, 5, 6];
    // твой код
    println!("{:?}", nums);
}
```
```solution
fn main() {
    let mut nums = vec![1, 2, 3, 4, 5, 6];
    nums.retain(|n| n % 2 == 0);
    println!("{:?}", nums);
}
```
```expect
[2, 4, 6]
```
hint: `retain` оставляет только элементы, для которых условие правда.
hint: `nums.retain(|n| n % 2 == 0);` — запись `|n| ...` называется замыканием. Подробно — в модуле про итераторы.

:: text Сортировка и порядок
- `v.sort()` — отсортировать по возрастанию.
- `v.reverse()` — перевернуть.
- `v.dedup()` — убрать **соседние** повторы. Поэтому сначала сортируют, потом `dedup`.
- `v.len()`, `v.is_empty()` — длина и проверка «пустой ли».

```rust
let mut v = vec![3, 1, 3, 2, 1];
v.sort();   // [1, 1, 2, 3, 3]
v.dedup();  // [1, 2, 3]
```
!> Дробные числа `f64` так не сортируются: у них есть особое значение NaN («не число»), которое нельзя сравнить. Для них пишут `v.sort_by(|a, b| a.total_cmp(b))`.

:: recap
- `push`, `pop`, `insert`, `remove`, `contains`.
- `v[i]` паникует за границей, `v.get(i)` возвращает `Option`.
- `for x in &mut v` — менять элементы, `*x` — само значение.

## LESSON m09-2 | String подробнее | 6
:: goals
- Собирать строки из кусочков
- Перебирать слова и буквы

:: text Как собрать строку
```rust
let mut s = String::from("Hello");
s.push_str(", world"); // дописать текст
s.push('!');           // дописать один символ
let name = "Аня";
let msg = format!("Привет, {name}!"); // как println!, но в строку
```
`format!` — самый удобный способ. Он ничего не печатает, а возвращает `String`.

:: code
```rust
fn main() {
    let text = "  Rust делает   код надёжным  ";
    let clean = text.trim();
    println!("[{clean}]");
    println!("Слов: {}", clean.split_whitespace().count());
    println!("Большими: {}", clean.to_uppercase());
    println!("Есть «код»: {}", clean.contains("код"));
    println!("{}", clean.replace("надёжным", "быстрым"));
}
```
```out
[Rust делает   код надёжным]
Слов: 4
Большими: RUST ДЕЛАЕТ   КОД НАДЁЖНЫМ
Есть «код»: true
Rust делает   код быстрым
```
- `trim` — убрать пробелы по краям.
- `split_whitespace` — разрезать по пробелам на слова.

:: quiz
Чем `format!` отличается от `println!`?
[x] `format!` возвращает строку, а не печатает её => Верно. Потом её можно сохранить, передать, напечатать.
[ ] `format!` печатает без перевода строки => Так делает `print!`.
[ ] Ничем => Отличие важное: один печатает, другой создаёт `String`.

:: task
Переверни каждое слово строки задом наперёд, сохраняя порядок слов. Для «привет мир» должно выйти «тевирп рим».
```rust
fn main() {
    let text = "привет мир";
    let mut result = Vec::new();
    for word in text.split_whitespace() {
        // переверни word и положи в result
    }
    println!("{}", result.join(" "));
}
```
```solution
fn main() {
    let text = "привет мир";
    let mut result = Vec::new();
    for word in text.split_whitespace() {
        let reversed: String = word.chars().rev().collect();
        result.push(reversed);
    }
    println!("{}", result.join(" "));
}
```
```expect
тевирп рим
```
hint: Буквы перебирает `word.chars()`, переворачивает `.rev()`.
hint: Собрать обратно в строку: `let r: String = word.chars().rev().collect();`

:: deep Байты, буквы и то, что видит человек
Строка в Rust можно читать на трёх уровнях:
- `bytes()` — байты UTF-8;
- `chars()` — символы Юникода (`char`);
- то, что человек видит как один знак. Иногда это **несколько** `char` подряд.

```rust
fn main() {
    let s = "e\u{301}👍🏽"; // e + знак ударения, палец + цвет кожи
    println!("байт: {}", s.len());
    println!("char: {}", s.chars().count());
}
```
```out
байт: 11
char: 4
```
На экране это 2 знака: «é» и «👍🏽». Но `é` здесь записан как `e` плюс отдельный значок ударения (`\u{301}` — его номер в Юникоде), а 👍🏽 — как палец плюс цвет кожи. Для работы с такими «видимыми знаками» есть отдельная библиотека `unicode-segmentation`. В стандартной библиотеке её нет.

:: recap
- `push_str`, `push`, `format!` — собрать строку.
- `trim`, `split_whitespace`, `contains`, `replace`, `to_uppercase`.
- Буквы — через `.chars()`.

## LESSON m09-3 | HashMap — словарь | 7
:: goals
- Хранить пары «ключ → значение»
- Считать частоту слов

:: text Словарь
**HashMap** хранит пары «ключ → значение». По ключу быстро находится значение.

> **Аналогия:** это как телефонная книга: по имени находишь номер. Не нужно листать всё подряд.

HashMap нужно подключить строчкой `use std::collections::HashMap;`.

:: code
```rust
use std::collections::HashMap;

fn main() {
    let mut phones = HashMap::new();
    phones.insert("Аня", "111-22-33");
    phones.insert("Боря", "444-55-66");

    match phones.get("Аня") {
        Some(num) => println!("Номер Ани: {num}"),
        None => println!("Не знаю такого"),
    }
    println!("Есть Вася? {}", phones.contains_key("Вася"));
    println!("Всего контактов: {}", phones.len());
}
```
```out
Номер Ани: 111-22-33
Есть Вася? false
Всего контактов: 2
```
!> Порядок элементов в HashMap не гарантирован. Если важен порядок — используй `BTreeMap`: он хранит ключи отсортированными.

:: text entry — «найди или создай»
Частая задача: увеличить счётчик, а если ключа нет — начать с нуля.

```rust
*counts.entry(word).or_insert(0) += 1;
```
Читается: «найди запись `word`; если нет — вставь 0; прибавь 1».

:: task
Посчитай, сколько раз встречается каждое слово. Используем `BTreeMap`, чтобы вывод шёл по алфавиту.
```rust
use std::collections::BTreeMap;

fn main() {
    let text = "кот пёс кот рыба кот пёс";
    let mut counts = BTreeMap::new();
    for word in text.split_whitespace() {
        // увеличь счётчик word
    }
    for (word, n) in &counts {
        println!("{word}: {n}");
    }
}
```
```solution
use std::collections::BTreeMap;

fn main() {
    let text = "кот пёс кот рыба кот пёс";
    let mut counts = BTreeMap::new();
    for word in text.split_whitespace() {
        *counts.entry(word).or_insert(0) += 1;
    }
    for (word, n) in &counts {
        println!("{word}: {n}");
    }
}
```
```expect
кот: 3
пёс: 2
рыба: 1
```
hint: Используй `entry(word).or_insert(0)`.
hint: Целиком: `*counts.entry(word).or_insert(0) += 1;`

:: text Перебор словаря и HashSet
Перебрать все пары можно циклом:

```rust
for (name, phone) in &phones {
    println!("{name}: {phone}");
}
```
Если нужны только ключи без значений, есть **HashSet** — набор уникальных элементов:

```rust
use std::collections::HashSet;
let mut seen = HashSet::new();
seen.insert("кот");
seen.insert("кот"); // повтор не добавится
println!("{}", seen.len()); // 1
```

:: deep Как HashMap находит значение так быстро
HashMap превращает ключ в число с помощью **хеш-функции**. По этому числу сразу видно, в какой «ящик» (bucket) положить пару.

Поиск поэтому не перебирает все элементы. Он считает хеш ключа и смотрит в один ящик. Это примерно одинаково быстро и для 10, и для миллиона элементов.

Отсюда два правила:
- ключ должен уметь хешироваться (трейт `Hash`) и сравниваться (`Eq`);
- порядок элементов зависит от хешей, а не от порядка вставки.

Хеш-функция в Rust по умолчанию защищена от специально подобранных ключей, которыми злоумышленник мог бы замедлить сервер.

:: recap
- `HashMap` — ключ → значение. Нужен `use std::collections::HashMap;`.
- `insert`, `get` (вернёт `Option`), `contains_key`.
- `*map.entry(k).or_insert(0) += 1;` — счётчик.
- `BTreeMap` — то же, но ключи по порядку.

:: task
Сделай первую букву каждого слова заглавной: `привет мир` → `Привет Мир`.
```rust
fn capitalize(word: &str) -> String {
    word.to_string()
}

fn main() {
    let text = "привет мир rust";
    let mut words = Vec::new();
    for w in text.split_whitespace() {
```

```solution
fn capitalize(word: &str) -> String {
    let mut chars = word.chars();
    match chars.next() {
        Some(first) => first.to_uppercase().collect::<String>() + chars.as_str(),
        None => String::new(),
    }
}

fn main() {
    let text = "привет мир rust";
    let mut words = Vec::new();
    for w in text.split_whitespace() {
        words.push(capitalize(w));
    }
    println!("{}", words.join(" "));
}
```
```expect
Привет Мир Rust
```
hint: Возьми первую букву: `let mut chars = word.chars(); chars.next()` — это `Option<char>`.
hint: Заглавная: `first.to_uppercase().collect::<String>()`. Остаток слова: `chars.as_str()`. Склей их через `+`.

:: task
Телефонная книга. Напиши функцию `lookup`, которая возвращает номер или текст `неизвестно`.
```rust
use std::collections::HashMap;

fn lookup(book: &HashMap<&str, &str>, name: &str) -> String {
    String::new()
}

fn main() {
    let mut book = HashMap::new();
    book.insert("Аня", "111");
    book.insert("Боря", "222");
    println!("{}", lookup(&book, "Боря"));
    println!("{}", lookup(&book, "Вася"));
}
```
```solution
use std::collections::HashMap;

fn lookup(book: &HashMap<&str, &str>, name: &str) -> String {
    match book.get(name) {
        Some(phone) => phone.to_string(),
        None => String::from("неизвестно"),
    }
}

fn main() {
    let mut book = HashMap::new();
    book.insert("Аня", "111");
    book.insert("Боря", "222");
    println!("{}", lookup(&book, "Боря"));
    println!("{}", lookup(&book, "Вася"));
}
```
```expect
222
неизвестно
```
hint: `book.get(name)` возвращает `Option`.
hint: Разбери через `match`: `Some(phone) => phone.to_string()`, `None => String::from("неизвестно")`.

:: task
Сгруппируй слова по первой букве. Используй `BTreeMap<char, Vec<&str>>`, чтобы буквы шли по алфавиту.
```rust
use std::collections::BTreeMap;

fn main() {
    let words = ["кот", "арбуз", "компот", "ананас", "банан"];
    let mut groups: BTreeMap<char, Vec<&str>> = BTreeMap::new();
    // заполни groups
    for (letter, list) in &groups {
        println!("{letter}: {}", list.join(", "));
    }
}
```
```solution
use std::collections::BTreeMap;

fn main() {
    let words = ["кот", "арбуз", "компот", "ананас", "банан"];
    let mut groups: BTreeMap<char, Vec<&str>> = BTreeMap::new();
    for w in words {
        let first = w.chars().next().unwrap();
        groups.entry(first).or_insert(Vec::new()).push(w);
    }
    for (letter, list) in &groups {
        println!("{letter}: {}", list.join(", "));
    }
}
```
```expect
а: арбуз, ананас
б: банан
к: кот, компот
```
hint: Первая буква: `w.chars().next().unwrap()`.
hint: `groups.entry(first).or_insert(Vec::new()).push(w);`

:: recap
- `sort` + `dedup` — убрать повторы.
- `chars()` для букв, `split_whitespace()` для слов.
- `entry(k).or_insert(...)` — «найди или создай» в словаре.
