## LESSON a00-2 | Повторяем: владение и заимствование | 7
:: goals
- Вспомнить три правила владения
- Вспомнить разницу между `&` и `&mut`

:: text Три правила владения
1. У каждого значения есть **владелец** — одна переменная.
2. Владелец может быть только **один**.
3. Владелец ушёл из области видимости — значение удаляется.

Если забыл подробности — урок первого уровня «Владение».

:: code
```rust
fn main() {
    let a = String::from("кот");
    let b = a; // владение переехало в b
    println!("{b}");
}
```
```out
кот
```
После `let b = a;` переменной `a` пользоваться нельзя. Попробуй добавить `println!("{a}");` и запусти.

:: text Заимствование
- `&x` — дать **посмотреть**. Таких ссылок может быть сколько угодно.
- `&mut x` — дать **поменять**. Такая ссылка может быть только **одна**, и пока она есть — других нет.

> **Аналогия:** книгу в библиотеке могут читать многие. Но исправлять её можно, только когда она у тебя одного в руках.

:: quiz
Сколько изменяемых ссылок `&mut` на одно значение может быть одновременно?
[ ] Сколько угодно => Это про `&`.
[x] Одна => Верно. И пока она жива, обычных `&` тоже нет.
[ ] Ноль, их нельзя создавать => Можно, если переменная объявлена с `mut`.

:: fill
Заполни пропуски, чтобы функция поменяла строку, а `main` её напечатал.
```rust
fn shout(s: ___ String) {
    s.push('!');
}

fn main() {
    let mut word = String::from("ура");
    shout(___ word);
    println!("{word}");
}
```
= &mut
= &mut
explain: Чтобы менять чужое значение, функция берёт `&mut String`, а при вызове пишем `&mut word`.

:: task
Функция `longest` должна вернуть длину самой длинной строки из списка. Она не должна забирать список себе: после вызова `main` печатает его ещё раз.
```rust
fn longest(words: Vec<String>) -> usize {
    let mut best = 0;
    for w in words {
        if w.len() > best {
            best = w.len();
        }
    }
    best
}

fn main() {
    let words = vec![String::from("кот"), String::from("hello"), String::from("Rust")];
    println!("{}", longest(words));
    println!("{}", words.len());
}
```
```solution
fn longest(words: &[String]) -> usize {
    let mut best = 0;
    for w in words {
        if w.len() > best {
            best = w.len();
        }
    }
    best
}

fn main() {
    let words = vec![String::from("кот"), String::from("hello"), String::from("Rust")];
    println!("{}", longest(&words));
    println!("{}", words.len());
}
```
```expect
6
3
```
hint: Пусть функция берёт ссылку: `words: &[String]`, а вызов будет `longest(&words)`.
hint: «кот» — это 6 байт, потому что русские буквы занимают по 2 байта. `len()` считает байты.

:: recap
- Один владелец. Передал — значение переехало.
- `&` — смотреть (много), `&mut` — менять (одна).
- Функциям обычно дают ссылку, а не само значение.

## LESSON a00-3 | Повторяем: enum, Result, трейты | 7
:: goals
- Вспомнить `match` по `enum`
- Вспомнить `Result` и `?`
- Вспомнить, что такое трейт

:: text enum и match
`enum` — «одно из нескольких». `match` — разобрать все варианты.

```rust
enum Light { Red, Yellow, Green }

fn action(l: Light) -> &'static str {
    match l {
        Light::Red => "стой",
        Light::Yellow => "жди",
        Light::Green => "иди",
    }
}
```
`match` должен покрыть **все** варианты. Забыл один — компилятор напомнит.

:: text Result и ?
`Result<T, E>` — либо `Ok(значение)`, либо `Err(ошибка)`.

Знак `?` после вызова значит: «если ошибка — сразу верни её наверх, если успех — достань значение».

:: code
```rust
fn double(text: &str) -> Result<i32, std::num::ParseIntError> {
    let n: i32 = text.parse()?;
    Ok(n * 2)
}

fn main() {
    println!("{:?}", double("21"));
    println!("{}", double("кот").is_err());
}
```
```out
Ok(42)
true
```

:: text Трейт — умение
Трейт описывает, **что умеет** тип. Например, `Display` — «умею печататься через `{}`».

```rust
trait Speak {
    fn speak(&self) -> String;
}
```
Любой тип может реализовать трейт через `impl Speak for Тип`.

:: quiz
Что делает `?` после `text.parse()`?
[ ] Печатает ошибку и продолжает => Нет, он возвращает ошибку из функции.
[x] При ошибке выходит из функции и возвращает её, при успехе отдаёт значение => Верно.
[ ] Превращает ошибку в 0 => Так делает `unwrap_or(0)`.

:: task
Реализуй трейт `Speak` для `Cat` и `Dog`. Кот говорит `Мяу`, собака — `Гав`.
```rust
trait Speak {
    fn speak(&self) -> String;
}

struct Cat;
struct Dog;

// твой код

fn main() {
    println!("{}", Cat.speak());
    println!("{}", Dog.speak());
}
```
```solution
trait Speak {
    fn speak(&self) -> String;
}

struct Cat;
struct Dog;

impl Speak for Cat {
    fn speak(&self) -> String {
        String::from("Мяу")
    }
}

impl Speak for Dog {
    fn speak(&self) -> String {
        String::from("Гав")
    }
}

fn main() {
    println!("{}", Cat.speak());
    println!("{}", Dog.speak());
}
```
```expect
Мяу
Гав
```
hint: Начни так: `impl Speak for Cat { fn speak(&self) -> String { ... } }`.

:: recap
- `enum` + `match` — разбор всех вариантов.
- `Result` + `?` — ошибки идут наверх сами.
- Трейт — набор умений, `impl Трейт for Тип` — научить тип.

## LESSON a00-p | Практика: разминка | 12 | practice
:: goals
- Размять руки перед вторым уровнем
- Собрать вместе структуры, `Vec`, `Option` и итераторы

:: task
Найди в списке первое число больше 10 и напечатай его. Если такого нет — напечатай `нет`.
```rust
fn main() {
    let nums = vec![3, 8, 15, 4, 22];
    // твой код
}
```
```solution
fn main() {
    let nums = vec![3, 8, 15, 4, 22];
    match nums.iter().find(|&&n| n > 10) {
        Some(n) => println!("{n}"),
        None => println!("нет"),
    }
}
```
```expect
15
```
hint: У итератора есть метод `find`. Он возвращает `Option`.
hint: `nums.iter().find(|&&n| n > 10)` — двойной `&`, потому что `find` даёт ссылку на ссылку.

:: task
Структура `Item` хранит название и цену в копейках. Посчитай общую сумму корзины и напечатай её в рублях с двумя знаками: `Итого: 377.50`.
```rust
struct Item {
    name: String,
    cents: u32,
}

fn main() {
    let cart = vec![
        Item { name: String::from("хлеб"), cents: 5500 },
        Item { name: String::from("сыр"), cents: 25000 },
        Item { name: String::from("чай"), cents: 7250 },
    ];
    // твой код
}
```
```solution
struct Item {
    name: String,
    cents: u32,
}

fn main() {
    let cart = vec![
        Item { name: String::from("хлеб"), cents: 5500 },
        Item { name: String::from("сыр"), cents: 25000 },
        Item { name: String::from("чай"), cents: 7250 },
    ];
    let total: u32 = cart.iter().map(|i| i.cents).sum();
    println!("Итого: {}.{:02}", total / 100, total % 100);
}
```
```expect
Итого: 377.50
```
hint: `cart.iter().map(|i| i.cents).sum()` — сумма. Тип укажи явно: `let total: u32 = ...`.
hint: Рубли — `total / 100`, копейки — `total % 100`. `{:02}` дописывает ноль слева: `5` → `05`.

:: task
Функция `parse_age` превращает текст в возраст. Пустая строка — ошибка `"пусто"`, не число — ошибка `"не число"`. Используй `?` или `match`.
```rust
fn parse_age(text: &str) -> Result<u32, String> {
    // твой код
}

fn main() {
    println!("{:?}", parse_age("30"));
    println!("{:?}", parse_age(""));
    println!("{:?}", parse_age("тридцать"));
}
```
```solution
fn parse_age(text: &str) -> Result<u32, String> {
    if text.is_empty() {
        return Err(String::from("пусто"));
    }
    text.parse::<u32>().map_err(|_| String::from("не число"))
}

fn main() {
    println!("{:?}", parse_age("30"));
    println!("{:?}", parse_age(""));
    println!("{:?}", parse_age("тридцать"));
}
```
```expect
Ok(30)
Err("пусто")
Err("не число")
```
hint: Сначала проверь `text.is_empty()` и верни `Err(...)`.
hint: `map_err(|_| ...)` заменяет одну ошибку на другую.

:: recap
- `find` ищет первое подходящее и возвращает `Option`.
- `map` + `sum` считают итог за одну строку.
- `map_err` меняет тип ошибки.
