// термин | английский | объяснение  (словарь третьего уровня)
Константный параметр | const generic | Параметр типа-числа: `struct Buf<const N: usize>`. Размер известен при компиляции.
PhantomData | PhantomData<T> | Поле нулевого размера, которое говорит компилятору: «тип как будто владеет `T`».
Сплошная реализация | blanket impl | Реализация трейта сразу для всех подходящих типов: `impl<T: Display> MyTrait for T`.
Трейт-расширение | extension trait | Свой трейт с методами для чужого типа, например для `str` или `Iterator`.
Безопасность для dyn | dyn compatibility | Свойство трейта, которое позволяет писать `dyn Trait`. Мешают, например, обобщённые методы.
Обобщённый ассоциированный тип | GAT | Ассоциированный тип со своим параметром: `type Item<'a> where Self: 'a;`.
Вариантность | variance | Правило, можно ли подставить `T<длинное>` туда, где ждут `T<короткое>`.
Подтип | subtyping | В Rust — в основном про времена жизни: `&'static str` подходит туда, где ждут `&'a str`.
Будильник | Waker | Объект, через который Future просит исполнитель опросить её снова.
Исполнитель | executor | Код, который опрашивает Future, пока они не завершатся. Например, tokio.
Закрепление | Pin | Обёртка, которая обещает, что значение больше не сдвинется в памяти.
Аллокатор | allocator | Код, который выдаёт и забирает память кучи. Свой подключают через `#[global_allocator]`.
Раскладка | Layout | Размер и выравнивание блока памяти, который просят у аллокатора.
Арена | arena | Большой кусок памяти, из которого объекты выдаются быстро и освобождаются разом.
Ниша | niche | Запрещённое значение типа, в котором Rust прячет вариант `None`. Поэтому `Option<&T>` не больше `&T`.
Сырой указатель | raw pointer | `*const T` и `*mut T`: указатель без правил заимствования. Разыменовывать — только в `unsafe`.
Неинициализированная память | MaybeUninit | Обёртка для памяти, в которой ещё нет корректного значения.
Miri | Miri | Интерпретатор Rust, который ловит неопределённое поведение в `unsafe`-коде.
Порядок памяти | memory ordering | Правила видимости записей между потоками: `Relaxed`, `Acquire`, `Release`, `SeqCst`.
Без блокировок | lock-free | Структура данных на атомарных операциях без мьютексов.
Ядро без std | no_std | Режим без стандартной библиотеки, только `core` (и, по желанию, `alloc`). Для микроконтроллеров.
Регистр | register | Ячейка железа по фиксированному адресу. Биты в ней включают и настраивают устройства.
Подкоманда | subcommand | Режим CLI-программы: `git commit`, `notes add`. В clap — перечисление с `#[derive(Subcommand)]`.
Миграция | migration | Файл с изменением схемы базы данных, который применяется по порядку.
Сервис | Service | Трейт tower: запрос → Future с ответом. На нём построены axum и hyper.
Промежуточный слой | middleware | Service-обёртка, которая добавляет поведение: логи, тайм-ауты, ограничения.
Экстрактор | extractor | Аргумент обработчика axum, который фреймворк достаёт из запроса по типу: `Path`, `Json`, `State`.
WebAssembly | wasm | Формат программ для браузера. Rust собирается в него.
Тест свойства | property test | Тест, который проверяет правило на сотнях случайных входов.
Сжатие | shrinking | Упрощение найденного провала до маленького примера, который всё ещё падает.
Фаззинг | fuzzing | Подача случайных байтов в программу с подсказкой от покрытия кода, чтобы найти падения.
Фейк | fake | Простая тестовая замена внешней зависимости: часов, сети, диска.
Процедурный макрос | procedural macro | Функция «токены → токены», которая генерирует код при компиляции.
Поток токенов | TokenStream | Код в виде последовательности токенов — вход и выход процедурного макроса.
