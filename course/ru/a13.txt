:: text Что строим
Программа читает **лог** — журнал событий программы — и делает отчёт: сколько ошибок, где их больше всего.

Строка лога выглядит так:
```
ERROR db: query failed
```
Уровень (`INFO`, `WARN`, `ERROR`), модуль (`db`), двоеточие и сообщение.

Мы пройдём четыре шага. Каждый использует темы второго уровня. Если что-то забылось — в тексте будет ссылка на модуль.

:: text Трейт FromStr
Ты много раз писал `"42".parse::<i32>()`. Как `parse` узнаёт, как превратить строку в `i32`? Через трейт `FromStr`.

Реализуй `FromStr` для своего типа — и `parse` заработает и для него:

```rust
impl FromStr for Level {
    type Err = ParseError;
    fn from_str(s: &str) -> Result<Level, ParseError> { ... }
}

let lvl: Level = "WARN".parse()?;
```
`type Err` — ассоциированный тип (модуль «Трейты глубже»).

:: code
```rust
use std::str::FromStr;

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
enum Level {
    Info,
    Warn,
    Error,
}

#[derive(Debug, PartialEq)]
enum ParseError {
    NoLevel,
    UnknownLevel(String),
    NoMessage,
}

impl FromStr for Level {
    type Err = ParseError;
    fn from_str(s: &str) -> Result<Level, ParseError> {
        match s {
            "INFO" => Ok(Level::Info),
            "WARN" => Ok(Level::Warn),
            "ERROR" => Ok(Level::Error),
            other => Err(ParseError::UnknownLevel(other.to_string())),
        }
    }
}

fn main() {
    println!("{:?}", "WARN".parse::<Level>());
    println!("{:?}", "DEBUG".parse::<Level>());
}
```
```out
Ok(Warn)
Err(UnknownLevel("DEBUG"))
```
`PartialOrd, Ord` в `derive` — чтобы уровни можно было сравнивать и сортировать: `Info < Warn < Error` (по порядку объявления).

:: text Запись лога без копий
Запись хранит **куски исходной строки**, а не копии — как парсер из модуля «Времена жизни глубже»:

```rust
#[derive(Debug)]

    level: Level,
    module: &'a str,
    msg: &'a str,
}
```
`Entry` не может пережить строку, из которой её разобрали. Зато разбор очень быстрый.

```solution
use std::str::FromStr;

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
enum Level {
    Info,
    Warn,
    Error,
}

#[derive(Debug, PartialEq)]
enum ParseError {
    NoLevel,
    UnknownLevel(String),
    NoMessage,
}

impl FromStr for Level {
    type Err = ParseError;
    fn from_str(s: &str) -> Result<Level, ParseError> {
        match s {
            "INFO" => Ok(Level::Info),
            "WARN" => Ok(Level::Warn),
            "ERROR" => Ok(Level::Error),
            other => Err(ParseError::UnknownLevel(other.to_string())),
        }
    }
}

#[derive(Debug)]
struct Entry<'a> {
    level: Level,
    module: &'a str,
    msg: &'a str,
}

fn parse_line(line: &str) -> Result<Entry<'_>, ParseError> {
    let (lvl, rest) = line.split_once(' ').ok_or(ParseError::NoLevel)?;
    let level: Level = lvl.parse()?;
    let (module, msg) = rest.split_once(": ").ok_or(ParseError::NoMessage)?;
    Ok(Entry { level, module, msg })
}

fn main() {
    for line in ["ERROR db: query failed", "oops", "DEBUG web: hi", "INFO web"] {
        println!("{:?}", parse_line(line));
    }
}
```
```expect
Ok(Entry { level: Error, module: "db", msg: "query failed" })
Err(NoLevel)
Err(UnknownLevel("DEBUG"))
Err(NoMessage)
```
hint: `line.split_once(' ').ok_or(ParseError::NoLevel)?` — уровень и остаток.
hint: `lvl.parse()?` сработает: `Level` умеет `FromStr`, а тип ошибки совпадает.
hint: Потом `rest.split_once(": ").ok_or(ParseError::NoMessage)?`.

:: recap
- `FromStr` учит `parse()` делать твой тип.
- `Entry<'a>` — запись из кусков исходной строки, без копий.
- `split_once` + `ok_or` + `?` — короткий разбор с понятными ошибками.

## LESSON a13-2 | Шаг 2: статистика | 9

:: text Что считаем
- Сколько записей каждого уровня.
- В каком модуле больше всего ошибок.
- Сколько строк не удалось разобрать.

Для подсчёта по ключу — `BTreeMap` и `entry().or_insert(0)` (модуль «Итераторы изнутри»). `BTreeMap` хранит ключи по порядку — отчёт выйдет стабильным.

:: code
Разбор (из шага 1) свёрнут в несколько строк, чтобы пример был короче. Смотри на `main`:
```rust
use std::collections::BTreeMap;

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
enum Level { Info, Warn, Error }

struct Entry<'a> { level: Level, module: &'a str }

fn parse_line(line: &str) -> Option<Entry<'_>> {
    let (lvl, rest) = line.split_once(' ')?;
    let level = match lvl { "INFO" => Level::Info, "WARN" => Level::Warn, "ERROR" => Level::Error, _ => return None };
    let (module, _msg) = rest.split_once(": ")?;
    Some(Entry { level, module })
}

const LOG: &str = "INFO db: connected
WARN net: slow response
ERROR db: query failed
INFO web: request /home
ERROR net: timeout
ERROR db: lost connection
oops";

fn main() {
    let (good, bad): (Vec<_>, Vec<_>) = LOG.lines().map(parse_line).partition(|e| e.is_some());
    let entries: Vec<Entry> = good.into_iter().flatten().collect();

    let mut by_level: BTreeMap<Level, usize> = BTreeMap::new();
    for e in &entries {
        *by_level.entry(e.level).or_insert(0) += 1;
    }
    println!("{by_level:?}");
    println!("плохих строк: {}", bad.len());
}
```
```out
{Info: 2, Warn: 1, Error: 3}
плохих строк: 1
```
- `lines()` — строки текста по одной.
- `partition` — разделить на две кучи по условию.
- `flatten()` убирает `Some` и оставляет сами записи.

```solution
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
enum Level { Info, Warn, Error }

struct Entry<'a> { level: Level, module: &'a str }

fn parse_line(line: &str) -> Option<Entry<'_>> {
    let (lvl, rest) = line.split_once(' ')?;
    let level = match lvl { "INFO" => Level::Info, "WARN" => Level::Warn, "ERROR" => Level::Error, _ => return None };
    let (module, _msg) = rest.split_once(": ")?;
    Some(Entry { level, module })
}

const LOG: &str = "INFO db: connected
ERROR net: timeout
ERROR db: query failed
ERROR db: lost connection
WARN web: slow";

fn main() {
    let entries: Vec<Entry> = LOG.lines().filter_map(parse_line).collect();
    let mut errors: BTreeMap<&str, usize> = BTreeMap::new();
    for e in entries.iter().filter(|e| e.level == Level::Error) {
        *errors.entry(e.module).or_insert(0) += 1;
    }
    println!("{errors:?}");
    if let Some((module, n)) = errors.iter().max_by_key(|(_, n)| **n) {
        println!("больше всего ошибок: {module} ({n})");
    }
}
```

:: text Один отчёт — разные виды
Человеку удобен текст, таблице — CSV, другой программе — JSON. Логика подсчёта одна, а вывод разный.

Описываем **умение** «нарисовать отчёт» трейтом, и каждый формат реализует его по-своему (модуль «Трейты глубже»):

```rust
trait Report {
    fn name(&self) -> &str;
    fn render(&self, counts: &[(&str, usize)]) -> String;
}
```

:: code
```rust
trait Report {
    fn name(&self) -> &str;
    fn render(&self, counts: &[(&str, usize)]) -> String;
}

struct Plain;
struct Bars;

impl Report for Plain {
    fn name(&self) -> &str { "текст" }
    fn render(&self, counts: &[(&str, usize)]) -> String {
        counts.iter().map(|(m, n)| format!("{m}: {n}")).collect::<Vec<_>>().join(", ")
    }
}

impl Report for Bars {
    fn name(&self) -> &str { "полоски" }
    fn render(&self, counts: &[(&str, usize)]) -> String {
        counts.iter().map(|(m, n)| format!("{m:>4} {}", "#".repeat(*n))).collect::<Vec<_>>().join("\n")
    }
}

fn pick(name: &str) -> Box<dyn Report> {
    match name {
        "bars" => Box::new(Bars),
        _ => Box::new(Plain),
    }
}

fn main() {
    let counts = [("db", 3), ("net", 1), ("web", 2)];
    for choice in ["plain", "bars"] {
        let r = pick(choice);
        println!("[{}]", r.name());
        println!("{}", r.render(&counts));
    }
}
```
```out
[текст]
db: 3, net: 1, web: 2
[полоски]
  db ###
 net #
 web ##
```
`{m:>4}` — выровнять по правому краю в 4 символа. Так полоски начинаются ровно.

:: quiz
Зачем `pick` возвращает `Box<dyn Report>`, а не `impl Report`?
[x] В разных ветках возвращаются разные типы => Верно. `impl` — только один конкретный тип.
[ ] `impl` нельзя возвращать из функций => Можно, но только один тип.
[ ] `Box` быстрее => Нет, `dyn` чуть медленнее; он нужен ради гибкости.

```solution
trait Report {
    fn render(&self, counts: &[(&str, usize)]) -> String;
}

struct Plain;
struct Csv;

impl Report for Plain {
    fn render(&self, counts: &[(&str, usize)]) -> String {
        counts.iter().map(|(m, n)| format!("{m}: {n}")).collect::<Vec<_>>().join(", ")
    }
}

impl Report for Csv {
    fn render(&self, counts: &[(&str, usize)]) -> String {
        let mut out = String::from("module,errors");
        for (m, n) in counts {
            out.push_str(&format!("\n{m},{n}"));
        }
        out
    }
}

fn pick(name: &str) -> Box<dyn Report> {
    match name {
        "csv" => Box::new(Csv),
        _ => Box::new(Plain),
    }
}

fn main() {
    let counts = [("db", 3), ("net", 1)];
    println!("{}", pick("csv").render(&counts));
}
```

:: text Большой лог — несколько потоков
Если в логе миллион строк, разбор можно разделить: каждый поток берёт свой кусок строк (модуль «Потоки глубже»). `thread::scope` позволяет потокам смотреть на общий текст без `Arc` и копий.

:: code
```rust
use std::thread;

fn is_error(line: &str) -> bool {
    line.starts_with("ERROR ")
}

fn main() {
    let log: String = (0..10_000)
        .map(|i| if i % 4 == 0 { "ERROR db: x\n" } else { "INFO web: y\n" })
        .collect();
    let lines: Vec<&str> = log.lines().collect();

    let total: usize = thread::scope(|s| {
        let handles: Vec<_> = lines
            .chunks(2_500)
            .map(|part| s.spawn(move || part.iter().filter(|l| is_error(l)).count()))
            .collect();
        handles.into_iter().map(|h| h.join().unwrap()).sum()
    });
    println!("ошибок: {total}");
}
```
```out
ошибок: 2500
```
Четыре потока по 2500 строк. Строки — `&str` в общий `log`, ничего не скопировано.

```solution
enum Level { Info, Warn, Error }

struct Entry<'a> {
    level: Level,
    module: &'a str,
    msg: &'a str,
}

impl fmt::Display for Entry<'_> {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        let lvl = match self.level {
            Level::Info => "INFO",
            Level::Warn => "WARN",
            Level::Error => "ERROR",
        };
        write!(f, "[{lvl}] {} — {}", self.module, self.msg)
    }
}

fn main() {
    let e = Entry { level: Level::Error, module: "db", msg: "query failed" };
    println!("{e}");
    let w = Entry { level: Level::Warn, module: "net", msg: "slow" };
    println!("{w}");
}
```
```expect
[ERROR] db — query failed
[WARN] net — slow
```
hint: `impl fmt::Display for Entry<'_>` — `'_` значит «какое-то время жизни, неважно какое».
hint: Сначала `match self.level` в текст, потом `write!(f, "[{lvl}] {} — {}", self.module, self.msg)`.

```solution
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
enum Level { Info, Warn, Error }

struct Entry<'a> { level: Level, module: &'a str, msg: &'a str }

struct Query<'q> {
    min_level: Level,
    module: Option<&'q str>,
}

impl<'q> Query<'q> {
    fn new() -> Self {
        Query { min_level: Level::Info, module: None }
    }
    fn min_level(mut self, l: Level) -> Self {
        self.min_level = l;
        self
    }
    fn module(mut self, m: &'q str) -> Self {
        self.module = Some(m);
        self
    }
    fn matches(&self, e: &Entry) -> bool {
        e.level >= self.min_level && self.module.is_none_or(|m| m == e.module)
    }
}

fn main() {
    let log = [
        Entry { level: Level::Info, module: "db", msg: "connected" },
        Entry { level: Level::Error, module: "db", msg: "query failed" },
        Entry { level: Level::Warn, module: "net", msg: "slow" },
        Entry { level: Level::Warn, module: "db", msg: "retry" },
    ];
    let q = Query::new().min_level(Level::Warn).module("db");
    for e in log.iter().filter(|e| q.matches(e)) {
        println!("{}", e.msg);
    }
}
```

hint: Модуль: если фильтра нет — подходит любой. `self.module.is_none_or(|m| m == e.module)`.

```solution
use std::collections::BTreeMap;

fn main() {
    let modules = ["db", "web", "net", "db", "web", "db", "auth"];
    let mut counts: BTreeMap<&str, usize> = BTreeMap::new();
    for m in modules {
        *counts.entry(m).or_insert(0) += 1;
    }
    let mut top: Vec<(&str, usize)> = counts.into_iter().collect();
    top.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(b.0)));
    for (m, n) in top.iter().take(2) {
        println!("{m}: {n}");
    }
}
```
```expect
db: 3
web: 2
```
hint: `counts.into_iter().collect::<Vec<_>>()` — пары `(модуль, число)`.
hint: `sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(b.0)))` — сначала по числу (убывание), потом по имени.
