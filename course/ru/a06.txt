# MODULE a06 | Память без сюрпризов | Drop, mem::take, Cow и Weak

## LESSON a06-1 | Drop: что происходит в конце | 7
:: goals
- Узнать, в каком порядке удаляются значения
- Написать свой `Drop`

:: text Уборка по расписанию
Когда владелец уходит из области видимости, Rust **удаляет** значение. Перед этим он вызывает метод `drop` из трейта `Drop`, если тот есть.

Так `String` освобождает память, файл закрывается, а замок отпускается. Сам ты `drop` не вызываешь — это делает Rust.

> **Аналогия:** выезд из гостиницы. Ты просто уходишь, а горничная убирает номер. Свой `Drop` — это записка горничной: «полейте, пожалуйста, цветок».

:: code
```rust
struct Noisy(&'static str);

impl Drop for Noisy {
    fn drop(&mut self) {
        println!("убираю {}", self.0);
    }
}

fn main() {
    let _a = Noisy("а");
    let _b = Noisy("б");
    {
        let _c = Noisy("в");
        println!("конец блока");
    }
    println!("конец main");
}
```
```out
конец блока
убираю в
конец main
убираю б
убираю а
```
Переменные удаляются в **обратном** порядке: последняя созданная — первой. Как тарелки в стопке.

:: text Убрать раньше: drop(x)
Иногда значение надо убрать **до** конца блока: закрыть файл, отпустить замок. Для этого есть функция `drop(x)`:

```rust
let lock = data.lock().unwrap();
// работа с данными
drop(lock); // отпустили замок сейчас, а не в конце функции
```
`drop(x)` просто забирает `x` себе и сразу заканчивается. Вызвать `x.drop()` напрямую Rust не разрешит — чтобы не убрать одно и то же дважды.

:: quiz
`let a = ...; let b = ...;` — в каком порядке их удалит Rust в конце блока?
[ ] Сначала `a`, потом `b` => Наоборот.
[x] Сначала `b`, потом `a` => Верно. Обратный порядок создания.
[ ] Одновременно => Порядок всегда строгий.

:: quiz
Как убрать значение `x` раньше конца блока?
[ ] `x.drop()` => Так Rust не разрешает.
[x] `drop(x)` => Верно.
[ ] `x = null` => В Rust нет `null`.

:: deep Порядок полей и почему _ опасен
Поля структуры удаляются в порядке **объявления** — сверху вниз. Это редко важно, но иногда одно поле должно умереть раньше другого (например, поток раньше канала). Тогда меняют порядок полей.

Ещё одна ловушка: `let _ = значение;` удаляет значение **сразу**, потому что `_` — это не переменная, а «выбросить». А `let _guard = значение;` держит его до конца блока. С замками разница огромная:

```rust
let _ = mutex.lock(); // замок тут же отпущен!
let _g = mutex.lock(); // замок держится до конца блока
```

:: task
Сделай `Drop` для `Guard`, чтобы он печатал `выход: <имя>`. Проверь порядок.
```rust
struct Guard {
    name: String,
}

// твой код

fn main() {
    let _outer = Guard { name: String::from("внешний") };
    let inner = Guard { name: String::from("внутренний") };
    drop(inner);
    println!("работаю");
}
```
```solution
struct Guard {
    name: String,
}

impl Drop for Guard {
    fn drop(&mut self) {
        println!("выход: {}", self.name);
    }
}

fn main() {
    let _outer = Guard { name: String::from("внешний") };
    let inner = Guard { name: String::from("внутренний") };
    drop(inner);
    println!("работаю");
}
```
```expect
выход: внутренний
работаю
выход: внешний
```
hint: `impl Drop for Guard { fn drop(&mut self) { println!("выход: {}", self.name); } }`.

:: recap
- `Drop::drop` вызывается сам, когда значение удаляется.
- Переменные удаляются в обратном порядке.
- `drop(x)` — убрать раньше.

## LESSON a06-2 | mem::take и mem::replace | 7
:: goals
- Достать значение из `&mut` без клонирования
- Знать `take`, `replace` и `swap`

:: text Проблема: забрать из-под ссылки
У тебя `&mut self`, а нужно **забрать** поле `self.items` себе (например, отдать наружу). Просто `let v = self.items;` нельзя: нельзя оставить структуру с «дыркой».

Решение — поменять значение на другое:
- `std::mem::take(&mut x)` — забрать `x`, а на его место положить пустое (значение по умолчанию).
- `std::mem::replace(&mut x, новое)` — забрать `x`, на место положить `новое`.
- `std::mem::swap(&mut a, &mut b)` — поменять местами.

> **Аналогия:** подменить вазу на столе. Забираешь старую, тут же ставишь новую — стол ни секунды не пустой.

:: code
```rust
use std::mem;

struct Inbox {
    messages: Vec<String>,
}

impl Inbox {
    fn drain_all(&mut self) -> Vec<String> {
        mem::take(&mut self.messages) // забрали, на месте пустой Vec
    }
}

fn main() {
    let mut inbox = Inbox { messages: vec![String::from("привет"), String::from("как дела")] };
    let got = inbox.drain_all();
    println!("забрали {}: {:?}", got.len(), got);
    println!("в ящике: {}", inbox.messages.len());

    let mut mode = String::from("день");
    let old = mem::replace(&mut mode, String::from("ночь"));
    println!("{old} -> {mode}");
}
```
```out
забрали 2: ["привет", "как дела"]
в ящике: 0
день -> ночь
```
Никаких `clone()`: строки просто переехали.

:: text take и Option
С `Option` есть удобный метод `take()`: забирает значение и оставляет `None`.

```rust
let mut slot: Option<String> = Some(String::from("ключ"));
let k = slot.take(); // k = Some("ключ"), slot = None
```
Так часто устроены «одноразовые» вещи: забрал — и больше нет.

:: quiz
Что останется в `v` после `let x = std::mem::take(&mut v);`, если `v: Vec<i32>`?
[x] Пустой вектор => Верно. `take` кладёт значение по умолчанию.
[ ] Ничего, `v` удалён => `v` жив, просто пуст.
[ ] Копия старого вектора => Копий нет, всё переехало в `x`.

:: task
Метод `finish` должен вернуть накопленный текст и очистить буфер. Используй `mem::take`.

```solution
use std::mem;

struct Writer {
    buf: String,
}

impl Writer {
    fn write(&mut self, s: &str) {
        self.buf.push_str(s);
    }
    fn finish(&mut self) -> String {
        mem::take(&mut self.buf)
    }
}

fn main() {
    let mut w = Writer { buf: String::new() };
    w.write("Раз, ");
    w.write("два");
    let text = w.finish();
    println!("{text}");
    println!("пусто: {}", w.buf.is_empty());
}
```
```expect
Раз, два
пусто: true
```
hint: Одна строка: `mem::take(&mut self.buf)`.

:: recap
- `mem::take` — забрать и оставить пустое.
- `mem::replace` — забрать и оставить своё.
- `Option::take()` — забрать и оставить `None`.

## LESSON a06-3 | Cow: копировать, только если надо | 7
:: goals
- Понять, что такое `Cow`
- Возвращать то ссылку, то новую строку из одной функции

:: text Иногда менять, иногда нет
Функция чистит текст: убирает лишние пробелы. Часто текст **уже** чистый — копировать незачем. Но иногда менять надо — и тогда нужна новая `String`.

`Cow` (clone on write, «копировать при записи») — это `enum` из двух вариантов:
- `Cow::Borrowed(&str)` — просто ссылка, ничего не копировали;
- `Cow::Owned(String)` — пришлось сделать свою копию.

> **Аналогия:** берёшь книгу у друга. Если только читаешь — возвращаешь как есть. Захотел подчеркнуть — покупаешь свою.

:: code
```rust
use std::borrow::Cow;

fn no_tabs(s: &str) -> Cow<'_, str> {
    if s.contains('\t') {
        Cow::Owned(s.replace('\t', "    "))
    } else {
        Cow::Borrowed(s)
    }
}

fn main() {
    for line in ["clean line", "a\tb"] {
        let r = no_tabs(line);
        let kind = match r {
            Cow::Borrowed(_) => "без копии",
            Cow::Owned(_) => "копия",
        };
        println!("{kind}: {r}");
    }
}
```
```out
без копии: clean line
копия: a    b
```
`Cow` печатается и используется как обычная строка. Разница только в том, была ли копия.

:: text Где Cow встречается
- `String::from_utf8_lossy` возвращает `Cow<str>`: если байты правильные — без копии.
- В функциях, которые «обычно ничего не меняют».
- `.into_owned()` превращает любой `Cow` в своё значение, когда нужно точно владеть.

:: quiz
Функция вернула `Cow::Borrowed(s)`. Было ли копирование?
[ ] Да, `Cow` всегда копирует => Копирует только при записи.
[x] Нет, это просто ссылка на исходные данные => Верно.
[ ] Неизвестно => Вариант `Borrowed` прямо говорит: копии нет.

:: task
Функция `shout` возвращает текст как есть, если он уже весь в верхнем регистре, иначе — новую строку в верхнем регистре. Используй `Cow`.
```rust
use std::borrow::Cow;

fn shout(s: &str) -> Cow<'_, str> {
    // твой код
}

fn main() {
    for s in ["HELLO", "Hi"] {
        let r = shout(s);
        println!("{} {}", r, matches!(r, Cow::Borrowed(_)));
    }
}
```
```solution
use std::borrow::Cow;

fn shout(s: &str) -> Cow<'_, str> {
    if s.chars().all(|c| !c.is_lowercase()) {
        Cow::Borrowed(s)
    } else {
        Cow::Owned(s.to_uppercase())
    }
}

fn main() {
    for s in ["HELLO", "Hi"] {
        let r = shout(s);
        println!("{} {}", r, matches!(r, Cow::Borrowed(_)));
    }
}
```
```expect
HELLO true
HI false
```
hint: Проверка: нет ни одной строчной буквы — `s.chars().all(|c| !c.is_lowercase())`.

:: recap
- `Cow` = либо ссылка (`Borrowed`), либо своё значение (`Owned`).
- Удобно, когда изменения нужны редко.
- `.into_owned()` — получить своё значение в любом случае.

## LESSON a06-4 | Weak: ссылка, которая не держит | 8
:: goals
- Понять, как `Rc` может создать утечку памяти
- Разорвать цикл с помощью `Weak`

:: text Утечка через круг
`Rc` удаляет значение, когда счётчик владельцев доходит до нуля. А если A держит B, а B держит A? Счётчики никогда не станут нулём — память не освободится. Это **утечка**.

> **Аналогия:** двое держат друг друга за руки и ждут, пока другой отпустит первым. Стоят вечно.

:: text Weak — смотреть, не держа
`Weak` — слабая ссылка. Она знает, где значение, но **не продлевает** ему жизнь.
- `Rc::downgrade(&rc)` — сделать `Weak` из `Rc`.
- `weak.upgrade()` — попробовать получить `Rc`. Вернёт `Option`: `None`, если значение уже удалено.

Правило: **родитель держит детей через `Rc`, ребёнок смотрит на родителя через `Weak`**.

:: code
```rust
use std::cell::RefCell;
use std::rc::{Rc, Weak};

struct Node {
    name: String,
    parent: RefCell<Weak<Node>>,
    children: RefCell<Vec<Rc<Node>>>,
}

fn main() {
    let root = Rc::new(Node {
        name: String::from("корень"),
        parent: RefCell::new(Weak::new()),
        children: RefCell::new(vec![]),
    });
    let leaf = Rc::new(Node {
        name: String::from("лист"),
        parent: RefCell::new(Weak::new()),
        children: RefCell::new(vec![]),
    });
    *leaf.parent.borrow_mut() = Rc::downgrade(&root);
    root.children.borrow_mut().push(Rc::clone(&leaf));

    let p = leaf.parent.borrow().upgrade();
    println!("родитель листа: {}", p.map(|n| n.name.clone()).unwrap_or_default());
    println!("детей у корня: {}", root.children.borrow().len());
    println!("сильных у корня: {}, слабых: {}", Rc::strong_count(&root), Rc::weak_count(&root));
}
```
```out
родитель листа: корень
детей у корня: 1
сильных у корня: 1, слабых: 1
```
У корня один сильный владелец (`root`) и одна слабая ссылка (от листа). Когда `root` уйдёт — корень удалится, цикла нет.

:: code
`upgrade` возвращает `None`, если значение уже удалено:
```rust
use std::rc::Rc;

fn main() {
    let strong = Rc::new(5);
    let weak = Rc::downgrade(&strong);
    println!("{:?}", weak.upgrade());
    drop(strong);
    println!("{:?}", weak.upgrade());
}
```
```out
Some(5)
None
```

:: quiz
В дереве ребёнок хранит ссылку на родителя. Какую?
[ ] `Rc<Node>` => Получится цикл: родитель держит ребёнка, ребёнок — родителя.
[x] `Weak<Node>` => Верно. Ребёнок смотрит, но не держит.
[ ] `Box<Node>` => `Box` — единственный владелец, у родителя уже есть владелец.

:: fill
Заполни пропуски: получи `Weak` из `Rc`, а потом попробуй вернуть `Rc`.
```rust
let strong = Rc::new(String::from("данные"));
let weak = Rc::___(&strong);
if let Some(s) = weak.___() {
    println!("{s}");
}
```
= downgrade
= upgrade
explain: `downgrade` — сделать слабую ссылку, `upgrade` — попытаться снова получить сильную.

:: recap
- Круг из `Rc` — утечка: счётчики не дойдут до нуля.
- `Weak` смотрит, но не держит. `upgrade()` → `Option<Rc>`.
- Родитель → ребёнок: `Rc`. Ребёнок → родитель: `Weak`.

```solution
use std::mem;

#[derive(Debug)]
enum Light {
    Red,
    Green,
    Yellow,
}

struct Traffic {
    light: Light,
}

impl Traffic {
    fn next(&mut self) -> Light {
        let new = match self.light {
            Light::Red => Light::Green,
            Light::Green => Light::Yellow,
            Light::Yellow => Light::Red,
        };
        mem::replace(&mut self.light, new)
    }
}

fn main() {
    let mut t = Traffic { light: Light::Red };
    println!("{:?}", t.next());
    println!("{:?}", t.next());
    println!("{:?}", t.light);
}
```
```expect
Red
Green
Yellow
```
hint: `mem::replace(&mut self.light, new)` положит `new` и вернёт старое.

fn normalize(s: &str) -> Cow<'_, str> {
    if s.contains('ё') {
        Cow::Owned(s.replace('ё', "е"))

        Cow::Borrowed(s)

}

    let words = ["ёжик", "кот", "всё", "дом"];
    let mut copies = 0;
    for w in words {
        let n = normalize(w);
        if let Cow::Owned(_) = n {
            copies += 1;
        }
        print!("{n} ");
    }
    println!();
    println!("копий: {copies}");

- `Drop` — код «на выходе».
