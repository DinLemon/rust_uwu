# MODULE m18 | Async и макросы | Обзор продвинутых тем

## LESSON m18-1 | Async: ждать, не простаивая | 7
:: goals
- Чем async отличается от потоков
- Что значат `async` и `.await`

:: text Официант, а не повар на каждый стол
Программа часто **ждёт**: ответа от сервера, чтения файла. Пока ждёт — процессор простаивает.

> Потоки — нанять по повару на каждый стол. Async — один официант: принял заказ, отнёс на кухню и, пока блюдо готовится, обслуживает другие столы.

Async выгоден, когда задач очень много, а работы у каждой мало: веб-серверы, чаты, сетевые программы.

:: text async и .await
- `async fn` — функция, которая возвращает не результат, а **обещание** результата (future).
- `.await` — «дождись обещания, а пока дай поработать другим».

```rust
async fn load_user() -> String {
    String::from("Аня")
}

async fn hello() {
    let name = load_user().await;
    println!("Привет, {name}");
}
```

:: text Нужен исполнитель
Future сам по себе ленивый, как итератор. Его кто-то должен «крутить». Это делает **рантайм** — исполнитель.

В стандартной библиотеке рантайма нет. В реальных проектах берут крейт **tokio**:

```text
#[tokio::main]
async fn main() {
    hello().await;
}
```

:: code
Для любопытных: крошечный исполнитель на одной стандартной библиотеке. Понимать каждую строку не нужно.
```rust
use std::future::Future;
use std::pin::pin;
use std::sync::Arc;
use std::task::{Context, Poll, Wake};

struct Noop;
impl Wake for Noop {
    fn wake(self: Arc<Self>) {}
}

fn block_on<F: Future>(fut: F) -> F::Output {
    let waker = Arc::new(Noop).into();
    let mut cx = Context::from_waker(&waker);
    let mut fut = pin!(fut);
    loop {
        if let Poll::Ready(v) = fut.as_mut().poll(&mut cx) {
            return v;
        }
    }
}

async fn load_user() -> String {
    String::from("Аня")
}

async fn hello() -> String {
    let name = load_user().await;
    format!("Привет, {name}")
}

fn main() {
    println!("{}", block_on(hello()));
}
```
```out
Привет, Аня
```

:: quiz
Что произойдёт, если вызвать `async fn` без `.await` и без исполнителя?
[ ] Функция выполнится сразу => Future ленивый: без исполнителя ничего не происходит.
[x] Ничего: создастся future, но он не запустится => Верно. Как итератор без `collect`.
[ ] Программа запаникует => Паники не будет, просто код не выполнится. Компилятор об этом предупредит.

:: text Что выбрать: потоки или async
- **Потоки** — когда задач немного и каждая много **считает**: обработка картинок, сжатие, вычисления.
- **Async** — когда задач очень много и каждая в основном **ждёт**: тысячи сетевых соединений, чат, веб-сервер.

Если сомневаешься и задач немного — начни с потоков. Они проще.

:: deep Что такое Future внутри
Компилятор превращает `async fn` в **машину состояний**: структуру, которая помнит, на каком `.await` остановилась.

У Future один главный метод — `poll` («опросить»). Исполнитель вызывает `poll`:
- если результат готов, `poll` возвращает `Poll::Ready(значение)`;
- если нет — `Poll::Pending`, и Future обещает «разбудить» исполнителя, когда можно пробовать снова.

Пока один Future ждёт, исполнитель опрашивает другие. Так один поток обслуживает тысячи задач.

:: recap
- Async — много задач, которые в основном ждут.
- `async fn` возвращает future, `.await` его дожидается.
- Нужен рантайм. В реальных проектах — tokio.

## LESSON m18-2 | Макросы | 6
:: goals
- Чем макрос отличается от функции
- Написать простой макрос `macro_rules!`

:: text Макрос пишет код за тебя
Ты весь курс пользуешься макросами: `println!`, `vec!`, `format!`, `assert_eq!`. Восклицательный знак — их метка.

**Макрос** — это код, который **пишет код** ещё до компиляции. Поэтому `println!` может принять любое количество аргументов, а обычная функция — нет.

:: code
Простой макрос через `macro_rules!`:
```rust
macro_rules! square {
    ($x:expr) => {
        $x * $x
    };
}

macro_rules! hello_all {
    ($($name:expr),*) => {
        $( println!("Привет, {}!", $name); )*
    };
}

fn main() {
    println!("{}", square!(7));
    hello_all!("Аня", "Боря", "Вика");
}
```
```out
49
Привет, Аня!
Привет, Боря!
Привет, Вика!
```
- `$x:expr` — «сюда подставь любое выражение».
- `$(...),*` — «повтори сколько угодно раз через запятую».

:: text derive — тоже макрос
`#[derive(Debug)]` — это **процедурный макрос**. Он читает твою структуру и дописывает к ней реализацию трейта.

Свои процедурные макросы пишут редко. Но знать, что это они, полезно.

:: text unsafe — одна строчка правды
В Rust есть слово `unsafe`. Внутри такого блока можно делать то, что компилятор не может проверить: работать с сырыми указателями, вызывать код на C.

Новичку `unsafe` не нужен. Большинство программ на Rust его вообще не содержат.

:: quiz
Почему `println!` — макрос, а не функция?
[x] Он принимает разное число аргументов и проверяет формат при компиляции => Верно. Обычная функция в Rust так не умеет.
[ ] Макросы работают быстрее функций => Дело не в скорости.
[ ] Так исторически сложилось, разницы нет => Разница есть: макрос раскрывается в код до компиляции.

:: text Полезные макросы стандартной библиотеки
- `vec![...]`, `format!(...)`, `println!`, `print!`, `eprintln!` (печать в поток ошибок);
- `assert!`, `assert_eq!`, `assert_ne!`;
- `dbg!(x)` — напечатать выражение, его значение и строку кода. Удобно при отладке;
- `todo!()` — «ещё не написано». Компилируется, но паникует при запуске;
- `matches!(x, образец)` — `true`, если `x` подходит под образец.

```rust
let c = 'z';
let is_letter = matches!(c, 'a'..='z' | 'A'..='Z'); // true
```

:: deep Процедурные макросы
`macro_rules!` подставляет код по шаблону. Есть второй, более мощный вид — **процедурные макросы**. Это отдельные маленькие программы на Rust, которые получают код как набор токенов и возвращают новый код.

Три вида:
- `#[derive(...)]` — дописать реализацию трейта;
- атрибуты вроде `#[tokio::main]` — переделать функцию;
- функциональные, вроде `sql!(...)` — разобрать свой мини-язык.

Их пишут в отдельном крейте с пометкой `proc-macro = true`. Новичку писать их не нужно, но полезно знать, откуда берутся `#[derive]` и `#[tokio::main]`.

:: recap
- Макросы с `!` генерируют код до компиляции.
- `macro_rules!` — свои простые макросы.
- `#[derive]` — тоже макрос.
- `unsafe` существует, но новичку не нужен.

## LESSON m18-p | Практика: макросы и async | 12 | practice
:: goals
- Писать простые макросы
- Пользоваться макросами стандартной библиотеки
- Писать async-функции

:: task
Напиши макрос `max!(a, b)`, который возвращает большее из двух выражений.
```rust
// напиши macro_rules! max

fn main() {
    println!("{}", max!(3, 8));
    println!("{}", max!(10 - 1, 2 * 2));
}
```
```solution
macro_rules! max {
    ($a:expr, $b:expr) => {
        if $a > $b { $a } else { $b }
    };
}

fn main() {
    println!("{}", max!(3, 8));
    println!("{}", max!(10 - 1, 2 * 2));
}
```
```expect
8
9
```
hint: Шаблон: `($a:expr, $b:expr) => { ... };`
hint: Тело: `if $a > $b { $a } else { $b }`

:: task
Напиши макрос `sum!`, который складывает любое количество чисел: `sum!(1, 2, 3)`.
```rust
// напиши macro_rules! sum

fn main() {
    println!("{}", sum!(1, 2, 3));
    println!("{}", sum!(10));
}
```
```solution
macro_rules! sum {
    ($($x:expr),*) => {
        0 $(+ $x)*
    };
}

fn main() {
    println!("{}", sum!(1, 2, 3));
    println!("{}", sum!(10));
}
```
```expect
6
10
```
hint: Повторение: `($($x:expr),*)` в шаблоне и `$( ... )*` в теле.
hint: Тело: `0 $(+ $x)*` — превратится в `0 + 1 + 2 + 3`.

:: task
Посчитай гласные латинские буквы в строке с помощью `matches!`.
```rust
fn main() {
    let text = "macro rules";
    let n = text.chars().filter(|c| false).count();
    println!("{n}");
}
```
```solution
fn main() {
    let text = "macro rules";
    let n = text.chars().filter(|c| matches!(c, 'a' | 'e' | 'i' | 'o' | 'u')).count();
    println!("{n}");
}
```
```expect
4
```
hint: `matches!(c, 'a' | 'e' | 'i' | 'o' | 'u')`
hint: Поставь это условие внутрь `filter`.

```solution
use std::future::Future;
use std::pin::pin;
use std::sync::Arc;
use std::task::{Context, Poll, Wake};

struct Noop;
impl Wake for Noop {
    fn wake(self: Arc<Self>) {}
}

fn block_on<F: Future>(fut: F) -> F::Output {
    let waker = Arc::new(Noop).into();
    let mut cx = Context::from_waker(&waker);
    let mut fut = pin!(fut);
    loop {
        if let Poll::Ready(v) = fut.as_mut().poll(&mut cx) {
            return v;
        }
    }
}

async fn price(item: &str) -> u32 {
    if item == "чай" { 100 } else { 250 }
}

async fn total() -> u32 {
    let a = price("чай").await;
    let b = price("торт").await;
    a + b
}

fn main() {
    println!("{}", block_on(total()));
}
```
```expect
350
```
hint: Результат async-функции получают через `.await`: `let a = price("чай").await;`
hint: Верни `a + b`.

:: recap
- `macro_rules!` + `$x:expr` + `$(...)*` — свои простые макросы.
- `matches!`, `dbg!`, `todo!` — удобные встроенные макросы.
- `.await` достаёт результат из async-функции.
