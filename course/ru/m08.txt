# MODULE m08 | Перечисления и match | Один из нескольких вариантов

## LESSON m08-1 | enum — один вариант из списка | 6
:: goals
- Что такое перечисление `enum`
- Как хранить в вариантах данные

:: text Выбор из списка
**Перечисление** (enum) — тип, значение которого — **один** вариант из заранее известного списка.

```rust
enum Light {
    Red,
    Yellow,
    Green,
}
let now = Light::Red;
```
> **Аналогия:** это как светофор. Он горит красным, жёлтым или зелёным. Ничего другого быть не может.

:: text Варианты могут нести данные
У каждого варианта могут быть свои данные:

```rust
enum Message {
    Quit,                    // без данных
    Move { x: i32, y: i32 }, // как структура
    Write(String),           // одно значение
}
```
Один тип `Message`, но внутри — разные виды сообщений.

:: quiz
Сколько вариантов одновременно хранит значение типа `Light`?
[x] Ровно один => Верно. В этом и смысл enum.
[ ] Все три => Это была бы структура с тремя полями.
[ ] Ноль или один => Пустым значение enum быть не может. Хотя для «может не быть» есть Option — скоро о нём.

:: text У перечисления тоже бывают методы
Как у структуры, у `enum` можно написать блок `impl`:

```rust
impl Light {
    fn next(&self) -> Light {
        match self {
            Light::Red => Light::Green,
            Light::Green => Light::Yellow,
            Light::Yellow => Light::Red,
        }
    }
}
```
`match` здесь разбирает, какой сейчас свет. Ему посвящён следующий урок.

:: recap
- `enum` — один вариант из списка.
- Вариант пишется через `::` — `Light::Red`.
- Варианты могут хранить данные.

## LESSON m08-2 | match — разбор вариантов | 7
:: goals
- Разобрать enum через `match`
- Понять, почему `match` требует все варианты

:: text match — сортировочная машина
`match` смотрит на значение и выбирает подходящую ветку. Это **сопоставление с образцом**.

```rust
match light {
    Light::Red => println!("Стой"),
    Light::Yellow => println!("Жди"),
    Light::Green => println!("Иди"),
}
```
> **Аналогия:** это как сортировщик посылок: по адресу отправляет в нужное окно.

:: code
```rust
enum Coin {
    Ruble1,
    Ruble5,
    Ruble10,
}

fn value(c: Coin) -> u32 {
    match c {
        Coin::Ruble1 => 1,
        Coin::Ruble5 => 5,
        Coin::Ruble10 => 10,
    }
}

fn main() {
    let total = value(Coin::Ruble5) + value(Coin::Ruble10);
    println!("Всего: {total} руб.");
}
```
```out
Всего: 15 руб.
```
`match` тоже выражение: возвращает значение выбранной ветки.

:: text match проверяет всё
Если забыть вариант, компилятор не пропустит: ошибка `E0004`.

Это огромная помощь. Добавил новый вариант в enum — компилятор покажет **все** места, которые надо обновить.

Не хочешь перечислять всё? Ветка `_` ловит «всё остальное»:

```rust
match number {
    1 => println!("один"),
    2 => println!("два"),
    _ => println!("много"),
}
```

:: code
Данные из варианта достаются прямо в `match`:
```rust
enum Shape {
    Circle(f64),
    Rect(f64, f64),
}

fn area(s: &Shape) -> f64 {
    match s {
        Shape::Circle(r) => 3.14 * r * r,
        Shape::Rect(w, h) => w * h,
    }
}

fn main() {
    println!("{}", area(&Shape::Rect(2.0, 3.0)));
    println!("{}", area(&Shape::Circle(1.0)));
}
```
```out
6
3.14
```

:: quiz
Что делает ветка `_ =>` в `match`?
[ ] Ловит ошибки => Это не про ошибки, а про оставшиеся варианты.
[x] Подходит под любое значение, которое не поймали раньше => Верно. Это «всё остальное».
[ ] Пропускает `match` целиком => Ветка `_` выполняется, если до неё ничего не подошло.

:: task
Напиши функцию `describe`, которая для числа печатает: `0` → `ноль`, `1` → `один`, любое другое → `другое`. Используй `match`.
```rust
fn describe(n: i32) -> &'static str {
    // твой match
}

fn main() {
    println!("{}", describe(0));
    println!("{}", describe(1));
    println!("{}", describe(42));
}
```
```solution
fn describe(n: i32) -> &'static str {
    match n {
        0 => "ноль",
        1 => "один",
        _ => "другое",
    }
}

fn main() {
    println!("{}", describe(0));
    println!("{}", describe(1));
    println!("{}", describe(42));
}
```
```expect
ноль
один
другое
```
hint: `&'static str` — это просто «текст в кавычках». Странную метку `'static` разберём позже.
hint: Ветки: `0 => "ноль",`, `1 => "один",`, `_ => "другое",`

:: text Более сложные образцы
В ветках `match` можно писать не только конкретные значения:

- `1 | 2` — «1 или 2»;
- `3..=9` — «от 3 до 9 включительно»;
- `n if n < 0` — «любое `n`, но только если оно меньше нуля». Такое условие называют **охранником** (guard).

```rust
let text = match score {
    0 => "ноль",
    1 | 2 => "мало",
    3..=9 => "средне",
    n if n < 0 => "меньше нуля",
    _ => "много",
};
```

:: deep match по кортежу
`match` умеет разбирать сразу несколько значений, если сложить их в кортеж:

```rust
fn main() {
    for (a, b) in [(true, true), (true, false), (false, false)] {
        let text = match (a, b) {
            (true, true) => "оба",
            (true, false) | (false, true) => "один",
            (false, false) => "никто",
        };
        println!("{text}");
    }
}
```
```out
оба
один
никто
```

:: recap
- `match` выбирает ветку по образцу.
- Нужно разобрать все варианты, иначе ошибка.
- `_` — «всё остальное».

## LESSON m08-3 | Option: может быть, а может нет | 7
:: goals
- Почему в Rust нет `null`
- Как работать с `Option`

:: text Значения может не быть
Часто результата может не оказаться. Например, ищем пользователя, а его нет.

Во многих языках для этого есть `null` — «ничего». Его изобретатель назвал `null` своей «ошибкой на миллиард долларов»: программы постоянно падали, забыв проверить.

В Rust `null` нет. Вместо него — `Option`.

:: text Option — коробка, которая может быть пустой
```rust
enum Option<T> {
    Some(T), // внутри есть значение
    None,    // пусто
}
```
> **Аналогия:** подарочная коробка. Внутри может лежать подарок (`Some`), а может быть пусто (`None`). Пока не откроешь — не знаешь. И Rust заставит открыть.

`T` — «любой тип». Об этом подробно в модуле про обобщения.

:: code
```rust
fn divide(a: i32, b: i32) -> Option<i32> {
    if b == 0 {
        None
    } else {
        Some(a / b)
    }
}

fn main() {
    for b in [2, 0] {
        match divide(10, b) {
            Some(result) => println!("10 / {b} = {result}"),
            None => println!("На {b} делить нельзя"),
        }
    }
}
```
```out
10 / 2 = 5
На 0 делить нельзя
```

:: quiz
Можно ли сложить `Option<i32>` и `i32` напрямую: `Some(5) + 3`?
[ ] Да, Rust сам достанет 5 => Нет. Сначала надо проверить, что коробка не пустая.
[x] Нет, сначала нужно достать значение из Option => Верно. Это и защищает от «забыл проверить».

:: text Удобные способы открыть коробку
- `if let Some(x) = value { ... }` — сделать что-то, только если есть значение.
- `value.unwrap_or(0)` — достать значение или взять 0, если пусто.
- `value.unwrap()` — достать, а если пусто — **паника**. Только когда уверен.

```rust
let first = vec![3, 1, 2].first().copied().unwrap_or(0);
```

:: code
`if let` — короткий `match` на один вариант:
```rust
fn main() {
    let names = vec!["Аня", "Боря"];
    if let Some(name) = names.get(1) {
        println!("Второй: {name}");
    }
    if let Some(name) = names.get(5) {
        println!("Шестой: {name}");
    } else {
        println!("Шестого нет");
    }
}
```
```out
Второй: Боря
Шестого нет
```
`get(i)` возвращает `Option`: элемента может не быть. Безопаснее, чем `[i]`.

:: deep Сколько стоит Option
`Option<&T>` занимает **столько же** памяти, сколько просто `&T`. Как так?

Ссылка в Rust никогда не бывает нулевым адресом. Поэтому компилятор использует нулевой адрес как метку `None`. Отдельного места под «есть / нет» не нужно.

```rust
fn main() {
    println!("{}", std::mem::size_of::<&i32>());
    println!("{}", std::mem::size_of::<Option<&i32>>());
}
```
```out
8
8
```
Безопасность `Option` ничего не стоит по памяти. То же верно для `Option<Box<T>>`.

:: recap
- `null` в Rust нет. Есть `Option<T>`: `Some(x)` или `None`.
- Rust заставляет проверить, есть ли значение.
- `if let Some(x) = ...`, `unwrap_or(запасное)`, `unwrap()` — только когда уверен.

## LESSON m08-4 | let else и цепочки let | 5
:: goals
- Ранний выход через `let ... else`
- Несколько условий через `&&` в `if let`

:: text let else — «достань или уходи»
Часто нужно: «достань значение, а если его нет — выйди из функции». Для этого есть `let ... else`:

```rust
fn greet_first(names: &[&str]) {
    let Some(first) = names.first() else {
        println!("Никого нет");
        return;
    };
    println!("Привет, {first}!");
}
```
После этого блока `first` — уже обычное значение, без `Some`.

:: text Цепочки let (Rust 2024)
В новой редакции Rust 2024 в `if` можно склеивать проверки через `&&`:

```rust
if let Some(age) = maybe_age && age >= 18 {
    println!("Взрослый");
}
```
Раньше для этого приходилось вкладывать `if` в `if`.

:: code
```rust
fn parse_age(text: &str) -> Option<u32> {
    let Ok(n) = text.parse::<u32>() else {
        return None;
    };
    Some(n)
}

fn main() {
    for t in ["25", "abc", "15"] {
        if let Some(age) = parse_age(t) && age >= 18 {
            println!("{t}: взрослый");
        } else {
            println!("{t}: нет");
        }
    }
}
```
```out
25: взрослый
abc: нет
15: нет
```
`Ok(n)` — вариант из типа `Result`. Он про ошибки, мы разберём его в отдельном модуле.

:: quiz
Что обязательно должно быть в блоке `else` у `let ... else`?
[ ] Ничего, можно оставить пустым => Нет: после `else` программа не может идти дальше без значения.
[x] Выход: `return`, `break`, `continue` или паника => Верно. Блок обязан «уйти», ведь значения нет.

:: recap
- `let Some(x) = opt else { return; };` — достань или выйди.
- `if let Some(x) = opt && условие` — цепочка в Rust 2024.

## LESSON m08-p | Практика: enum и match | 12 | practice
:: goals
- Описывать варианты через `enum`
- Разбирать их через `match`, `if let`, `Option`

:: task
Есть направления. Допиши функцию `turn_right`: север → восток → юг → запад → север.
```rust
#[derive(Debug)]
enum Dir {
    North,
    East,
    South,
    West,
}

fn turn_right(d: Dir) -> Dir {
    d
}

fn main() {
    println!("{:?}", turn_right(Dir::North));
    println!("{:?}", turn_right(Dir::West));
}
```
```solution
#[derive(Debug)]
enum Dir {
    North,
    East,
    South,
    West,
}

fn turn_right(d: Dir) -> Dir {
    match d {
        Dir::North => Dir::East,
        Dir::East => Dir::South,
        Dir::South => Dir::West,
        Dir::West => Dir::North,
    }
}

fn main() {
    println!("{:?}", turn_right(Dir::North));
    println!("{:?}", turn_right(Dir::West));
}
```
```expect
East
North
```
hint: Нужен `match d { ... }` с четырьмя ветками.
hint: Первая ветка: `Dir::North => Dir::East,`

:: task
Переведи баллы в оценку через `match` с диапазонами: 90–100 → `отлично`, 70–89 → `хорошо`, 50–69 → `удовлетворительно`, остальное → `плохо`.
```rust
fn grade(score: u32) -> &'static str {
    "плохо"
}

fn main() {
    for s in [95, 75, 50, 10] {
        println!("{}", grade(s));
    }
}
```
```solution
fn grade(score: u32) -> &'static str {
    match score {
        90..=100 => "отлично",
        70..=89 => "хорошо",
        50..=69 => "удовлетворительно",
        _ => "плохо",
    }
}

fn main() {
    for s in [95, 75, 50, 10] {
        println!("{}", grade(s));
    }
}
```
```expect
отлично
хорошо
удовлетворительно
плохо
```
hint: Ветка с диапазоном: `90..=100 => "отлично",`
hint: Последняя ветка: `_ => "плохо",`

:: task
Напиши функцию `first_negative`, которая возвращает первое отрицательное число среза в `Some`, или `None`, если таких нет.
```rust
fn first_negative(items: &[i32]) -> Option<i32> {
    None
}

fn main() {
    println!("{:?}", first_negative(&[3, -4, -1]));
    println!("{:?}", first_negative(&[1, 2]));
}
```
```solution
fn first_negative(items: &[i32]) -> Option<i32> {
    for &x in items {
        if x < 0 {
            return Some(x);
        }
    }
    None
}

fn main() {
    println!("{:?}", first_negative(&[3, -4, -1]));
    println!("{:?}", first_negative(&[1, 2]));
}
```
```expect
Some(-4)
None
```
hint: В цикле, как только нашёл `x < 0`, верни `Some(x)` через `return`.
hint: `for &x in items` достаёт число из ссылки сразу. После цикла верни `None`.

:: task
С помощью `if let` напечатай квадрат числа, только если оно есть. Для `None` ничего не печатай.
```rust
fn main() {
    let values = [Some(3), None, Some(5)];
    for v in values {
        // твой if let
    }
}
```
```solution
fn main() {
    let values = [Some(3), None, Some(5)];
    for v in values {
        if let Some(n) = v {
            println!("{}", n * n);
        }
    }
}
```
```expect
9
25
```
hint: `if let Some(n) = v { ... }`
hint: Внутри: `println!("{}", n * n);`

:: task
Перечисление команд для робота. Посчитай, где окажется робот, начав с позиции 0: `Forward(n)` прибавляет `n`, `Back(n)` отнимает `n`, `Stop` останавливает выполнение.
```rust
enum Cmd {
    Forward(i32),
    Back(i32),
    Stop,
}

fn main() {
    let program = [Cmd::Forward(5), Cmd::Back(2), Cmd::Forward(4), Cmd::Stop, Cmd::Forward(100)];
    let mut pos = 0;
    // пройди по program
    println!("{pos}");
}
```
```solution
enum Cmd {
    Forward(i32),
    Back(i32),
    Stop,
}

fn main() {
    let program = [Cmd::Forward(5), Cmd::Back(2), Cmd::Forward(4), Cmd::Stop, Cmd::Forward(100)];
    let mut pos = 0;
    for cmd in program {
        match cmd {
            Cmd::Forward(n) => pos += n,
            Cmd::Back(n) => pos -= n,
            Cmd::Stop => break,
        }
    }
    println!("{pos}");
}
```
```expect
7
```
hint: `for cmd in program { match cmd { ... } }`
hint: Ветки: `Cmd::Forward(n) => pos += n,`, `Cmd::Back(n) => pos -= n,`, `Cmd::Stop => break,`

:: recap
- `match` проверяет все варианты, `_` ловит остальное.
- Диапазоны `a..=b` и `|` делают ветки короче.
- `Option` — «есть значение или нет», `if let` — проверить один вариант.
