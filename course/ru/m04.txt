# MODULE m04 | Кортежи, массивы, векторы | Как хранить много значений сразу

## LESSON m04-1 | Кортежи | 5
:: goals
- Хранить несколько разных значений вместе
- Доставать их по номеру и через распаковку

:: text Кортеж — набор разных вещей
**Кортеж** (tuple) — несколько значений в одних скобках. Типы могут быть разными.

```rust
let person = ("Аня", 25, true);
```
> **Аналогия:** это как рюкзак: в нём лежат книга, бутылка и ключи. Разные вещи, но вместе.

:: code
Достать элемент — точка и номер. Нумерация с **нуля**.
```rust
fn main() {
    let person = ("Аня", 25, true);
    println!("Имя: {}", person.0);
    println!("Возраст: {}", person.1);

    let (name, age, student) = person;
    println!("{name}, {age}, студент: {student}");
}
```
```out
Имя: Аня
Возраст: 25
Аня, 25, студент: true
```
Вторая часть — **распаковка**: сразу три переменные из одного кортежа.

:: text Функция может вернуть кортеж
Так удобно вернуть сразу два результата:

```rust
fn min_max(a: i32, b: i32) -> (i32, i32) {
    if a < b { (a, b) } else { (b, a) }
}
```

:: quiz
Как достать `true` из `let t = (10, "да", true);`?
[ ] `t.3` => Нумерация с нуля: 0, 1, 2.
[x] `t.2` => Верно. Третий элемент имеет номер 2.
[ ] `t[2]` => Квадратные скобки — для массивов. У кортежа — точка.

:: deep Пустой кортеж
Помнишь значение `()` из модуля про функции? Это **пустой кортеж** — кортеж, в котором ноль элементов.

Поэтому функция «без результата» на самом деле возвращает пустой кортеж. Тип и значение пишутся одинаково: `()`.

:: recap
- `(a, b, c)` — кортеж, типы могут быть разными.
- `t.0`, `t.1` — доступ по номеру с нуля.
- `let (x, y) = t;` — распаковка.

## LESSON m04-2 | Массивы | 6
:: goals
- Хранить много значений одного типа
- Обходить массив циклом

:: text Массив — ряд одинаковых ячеек
**Массив** — ряд значений **одного** типа. Длина фиксирована: её нельзя поменять.

```rust
let days = ["пн", "вт", "ср", "чт", "пт"];
let zeros = [0; 10]; // десять нулей
```
> **Аналогия:** это как коробка для яиц: десять одинаковых ячеек, не больше и не меньше.

:: code
```rust
fn main() {
    let scores = [7, 9, 4, 10];
    println!("Первая оценка: {}", scores[0]);
    println!("Всего оценок: {}", scores.len());
    for s in scores {
        println!("Оценка {s}");
    }
}
```
```out
Первая оценка: 7
Всего оценок: 4
Оценка 7
Оценка 9
Оценка 4
Оценка 10
```

:: code
Что будет, если попросить ячейку, которой нет? Запусти.
```rust
fn main() {
    let a = [1, 2, 3];
    for i in 0..=3 {
        println!("{}", a[i]);
    }
}
```
Три числа напечатаются, а на `a[3]` программа **запаникует**: `index out of bounds` — «индекс за границей». Rust не даёт читать чужую память. Это защита, а не поломка.

:: quiz
Какой индекс у последнего элемента массива из 5 элементов?
[ ] 5 => Индексы идут с нуля, поэтому последний на единицу меньше длины.
[x] 4 => Верно: 0, 1, 2, 3, 4.
[ ] -1 => В Rust нет отрицательных индексов.

:: task
Найди самую большую оценку в массиве и напечатай её.
```rust
fn main() {
    let scores = [7, 9, 4, 10, 6];
    let mut best = scores[0];
    // пройди циклом по scores и обнови best
    println!("Лучшая: {best}");
}
```
```solution
fn main() {
    let scores = [7, 9, 4, 10, 6];
    let mut best = scores[0];
    for s in scores {
        if s > best {
            best = s;
        }
    }
    println!("Лучшая: {best}");
}
```
```expect
Лучшая: 10
```
hint: `for s in scores { ... }`
hint: Внутри: если `s > best`, то `best = s;`

:: text Тип массива
У массива тип пишут так: `[тип; длина]`.

```rust
let days: [&str; 7] = ["пн", "вт", "ср", "чт", "пт", "сб", "вс"];
```
Длина — часть типа. `[i32; 3]` и `[i32; 4]` — **разные** типы.

:: deep Таблица: массив массивов
Массив может хранить другие массивы. Так получается таблица:

```rust
fn main() {
    let grid = [[1, 2, 3], [4, 5, 6]];
    println!("Строка 1, столбец 2: {}", grid[1][2]);
    for row in grid {
        for cell in row {
            print!("{cell} ");
        }
        println!();
    }
}
```
```out
Строка 1, столбец 2: 6
1 2 3 
4 5 6 
```
Тип `grid` — `[[i32; 3]; 2]`: два ряда по три числа.

:: recap
- `[a, b, c]` — массив одного типа, длина постоянна.
- `a[0]` — первый элемент, `a.len()` — длина.
- Выход за границы — паника, а не тихая ошибка.

## LESSON m04-3 | Первый взгляд на Vec | 5
:: goals
- Список, который может расти
- Добавлять элементы через `push`

:: text Vec — растущий список
Массив не растёт. А часто нужно добавлять элементы по ходу. Для этого есть **вектор** `Vec`.

```rust
let mut list = Vec::new();
list.push("хлеб");
list.push("молоко");
```
Есть и короткая запись: `let v = vec![1, 2, 3];`

:: code
```rust
fn main() {
    let mut todo = vec!["проснуться", "умыться"];
    todo.push("учить Rust");
    println!("Дел: {}", todo.len());
    for task in &todo {
        println!("- {task}");
    }
}
```
```out
Дел: 3
- проснуться
- умыться
- учить Rust
```
Значок `&` перед `todo` значит «просто посмотреть». Почему он нужен — узнаешь в модуле о владении. Это самая важная тема Rust.

:: quiz
Чем `Vec` отличается от массива?
[x] Vec может расти и уменьшаться => Верно. Массив — фиксированная коробка, вектор — резиновая.
[ ] В Vec можно хранить значения разных типов => Нет, в векторе тоже всё одного типа.
[ ] Vec нумеруется с единицы => Тоже с нуля, как массив.

:: deep Длина и вместимость Vec
У вектора есть два числа:
- `len()` — сколько элементов лежит сейчас;
- `capacity()` — на сколько элементов уже выделено место.

Когда места не хватает, вектор выделяет новый кусок памяти, обычно вдвое больше, и переносит туда элементы. Это происходит редко, поэтому `push` в среднем быстрый.

Если заранее известно, сколько будет элементов, можно сразу попросить место: `Vec::with_capacity(100)`.

:: recap
- `Vec::new()` или `vec![...]` — вектор.
- `push` добавляет в конец, `len` даёт длину.
- Вектор должен быть `mut`, чтобы в него добавлять.

## LESSON m04-p | Практика: кортежи, массивы, векторы | 10 | practice
:: goals
- Обходить массивы циклами
- Собирать данные в Vec

:: task
Посчитай сумму всех чисел массива.
```rust
fn main() {
    let nums = [4, 8, 15, 16, 23, 42];
    let mut sum = 0;
    println!("{sum}");
}
```
```solution
fn main() {
    let nums = [4, 8, 15, 16, 23, 42];
    let mut sum = 0;
    for n in nums {
        sum += n;
    }
    println!("{sum}");
}
```
```expect
108
```
hint: `for n in nums { ... }`
hint: Внутри: `sum += n;`

:: task
Посчитай, сколько в массиве отрицательных чисел.
```rust
fn main() {
    let temps = [3, -2, 0, -7, 5, -1];
}
```
```solution
fn main() {
    let temps = [3, -2, 0, -7, 5, -1];
    let mut count = 0;
    for t in temps {
        if t < 0 {
            count += 1;
        }
    }
    println!("{count}");
}
```
```expect
3
```
hint: Нужен счётчик `let mut count = 0;`.
hint: В цикле: если `t < 0`, то `count += 1;`

:: task
Напиши функцию `swap`, которая принимает кортеж `(i32, i32)` и возвращает его с элементами в обратном порядке.
```rust
// напиши функцию swap

fn main() {
    let p = swap((1, 2));
    println!("{} {}", p.0, p.1);
}
```
```solution
fn swap(pair: (i32, i32)) -> (i32, i32) {
    (pair.1, pair.0)
}

fn main() {
    let p = swap((1, 2));
    println!("{} {}", p.0, p.1);
}
```
```expect
2 1
```
hint: Заголовок: `fn swap(pair: (i32, i32)) -> (i32, i32)`
hint: Тело: `(pair.1, pair.0)`

:: task
Найди номер (индекс) числа 23 в массиве. Перебери индексы от 0 до длины массива.
```rust
fn main() {
    let nums = [4, 8, 15, 16, 23, 42];
}
```
```solution
fn main() {
    let nums = [4, 8, 15, 16, 23, 42];
    for i in 0..nums.len() {
        if nums[i] == 23 {
            println!("{i}");
        }
    }
}
```
```expect
4
```
hint: `for i in 0..nums.len()` перебирает индексы.
hint: Внутри: `if nums[i] == 23 { println!("{i}"); }`

:: task
Собери вектор квадратов чисел от 1 до 5 и напечатай его через `{:?}`.
```rust
fn main() {
    let mut squares = Vec::new();
    println!("{:?}", squares);
}
```
```solution
fn main() {
    let mut squares = Vec::new();
    for i in 1..=5 {
        squares.push(i * i);
    }
    println!("{:?}", squares);
}
```
```expect
[1, 4, 9, 16, 25]
```
hint: Цикл `for i in 1..=5`.
hint: Внутри: `squares.push(i * i);`

:: recap
- `for x in массив` — перебор значений, `for i in 0..a.len()` — перебор индексов.
- `Vec::new()` + `push` — собрать список по ходу.
- `{:?}` печатает массивы и векторы целиком.
