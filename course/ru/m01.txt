# MODULE m01 | Переменные и типы | Как программа запоминает данные

## LESSON m01-1 | Переменная — коробка с именем | 6
:: goals
- Что такое переменная
- Как создать её словом `let`
- Как напечатать её значение

:: text Коробка с наклейкой
**Переменная** — это коробка с наклейкой. На наклейке имя. Внутри значение.

В Rust коробку создают словом `let` («пусть»):

```rust
let age = 25;
```
Читается так: «пусть `age` будет 25».

:: code
Чтобы напечатать переменную, поставь её имя в фигурные скобки внутри текста.
```rust
fn main() {
    let age = 25;
    let name = "Аня";
    println!("{name}, тебе {age} лет");
}
```
```out
Аня, тебе 25 лет
```
Попробуй поменять имя и возраст и снова запусти.

:: text Ещё один способ печати
Можно оставить пустые скобки `{}`, а переменные перечислить после текста через запятую. Они подставятся по порядку.

```rust
let a = 2;
let b = 3;
println!("{} плюс {} равно {}", a, b, a + b);
```
Напечатает: `2 плюс 3 равно 5`.

:: fill
Заполни пропуски, чтобы программа напечатала `Кот: Барсик`.
```rust
fn main() {
    ___ cat = "Барсик";
    println!("Кот: {___}");
}
```
= let
= cat
explain: `let` создаёт переменную, а `{cat}` подставляет её значение в текст.

:: text Как называть переменные
- Только латиница, цифры и `_`.
- Слова разделяй подчёркиванием: `user_name`, `max_speed`.
- Имя должно объяснять, что внутри. `price` лучше, чем `p`.

> Этот стиль называется snake_case («змеиный регистр»). Так пишут все программисты на Rust.

:: quiz
Какое имя переменной написано в стиле Rust?
[ ] `UserName` => Так в Rust называют типы, а не переменные.
[x] `user_name` => Верно. Маленькие буквы и подчёркивание.
[ ] `user-name` => Дефис означает минус. Компилятор прочитает это как «user минус name».

:: recap
- `let имя = значение;` создаёт переменную.
- `{имя}` внутри текста подставляет значение.
- Имена пишем в snake_case: `my_value`.

## LESSON m01-2 | Изменяемые переменные: mut | 6
:: goals
- Почему переменную нельзя просто поменять
- Как разрешить изменения словом `mut`

:: text Коробка запечатана
В Rust переменная по умолчанию **неизменяемая**. Положил значение — коробка запечатана.

Зачем так? Чтобы значение не поменялось случайно где-то в середине большой программы.

:: code
Запусти и прочитай ошибку.
```rust
fn main() {
    let score = 10;
    score = 20;
    println!("{score}");
}
```
fails: yes
Компилятор говорит `cannot assign twice to immutable variable` — «нельзя дважды присвоить значение неизменяемой переменной». И даже подсказывает решение в `help`.

:: text Слово mut
Чтобы коробку можно было открывать, добавь `mut` (от mutable — изменяемый):

```rust
let mut score = 10;
score = 20;
```
Теперь всё работает. `mut` — это честная пометка: «эта переменная будет меняться».

:: task
Почини программу. Она должна напечатать `Очки: 15`.
```rust
fn main() {
    let points = 10;
    points = points + 5;
    println!("Очки: {points}");
}
```
```solution
fn main() {
    let mut points = 10;
    points = points + 5;
    println!("Очки: {points}");
}
```
```expect
Очки: 15
```
hint: Компилятор жалуется, что переменную нельзя менять.
hint: Добавь `mut` после `let`.

:: text Сокращения
Вместо `x = x + 5` можно писать `x += 5`. Так же работают `-=`, `*=`, `/=`.

```rust
let mut lives = 3;
lives -= 1; // теперь 2
```

:: quiz
Что напечатает программа?
```rust
fn main() {
    let mut coins = 5;
    coins += 10;
    coins -= 3;
    println!("{coins}");
}
```
[ ] 5 => Значение менялось два раза. Посчитай: 5 + 10 − 3.
[x] 12 => Верно: 5 + 10 − 3 = 12.
[ ] Ошибка компиляции => Здесь есть `mut`, значит менять можно.

:: recap
- Переменные по умолчанию нельзя менять.
- `let mut` разрешает изменения.
- `x += 1` — короткая запись для `x = x + 1`.

## LESSON m01-3 | Числа | 7
:: goals
- Целые и дробные числа
- Что значат `i32` и `f64`
- Арифметика

:: text У каждого значения есть тип
**Тип** говорит, что лежит в коробке: число, текст, да/нет.

Обычно Rust угадывает тип сам. Но можно написать его явно, через двоеточие:

```rust
let age: i32 = 30;
let price: f64 = 99.5;
```

:: text Целые числа
`i32` — целое число со знаком: может быть отрицательным. Это тип «по умолчанию».

- Буква `i` — integer, целое.
- `u` — unsigned, только ноль и больше: `u8`, `u32`, `u64`.
- Цифры — сколько бит занимает число. Больше бит — больше максимум.

`u8` хранит от 0 до 255. `i32` — примерно ±2 миллиарда. Обычно хватает `i32`.

:: text Дробные числа
Дробные числа пишут через **точку**: `3.14`, не через запятую.

Тип по умолчанию — `f64` (f — float, «плавающая точка»).

!> Целое и дробное не складываются напрямую. `5 + 2.5` — ошибка. Пиши `5.0 + 2.5`.

:: code
```rust
fn main() {
    let a = 7;
    let b = 2;
    println!("Сумма: {}", a + b);
    println!("Разность: {}", a - b);
    println!("Произведение: {}", a * b);
    println!("Целое деление: {}", a / b);
    println!("Остаток: {}", a % b);
    println!("Дробное деление: {}", 7.0 / 2.0);
}
```
```out
Сумма: 9
Разность: 5
Произведение: 14
Целое деление: 3
Остаток: 1
Дробное деление: 3.5
```
Заметь: `7 / 2` у целых даёт `3`. Дробная часть просто отбрасывается.

:: quiz
Сколько будет `10 % 3`?
[ ] 3 => `%` — это не деление, а остаток от деления.
[x] 1 => Верно. 10 = 3 × 3 + 1. Остаток — 1.
[ ] 3.33 => У целых чисел нет дробной части.

:: text Превращаем целое в дробное
Чтобы смешать целое и дробное, превращают тип словом `as`:

```rust
let apples = 7;
let half = apples as f64 / 2.0; // 3.5
```

:: task
Есть температура в градусах Цельсия. Переведи её в Фаренгейты по формуле `F = C × 1.8 + 32` и напечатай `Фаренгейт: 77`.
```rust
fn main() {
    let celsius = 25.0;
    let fahrenheit = 0.0; // поправь эту строку
    println!("Фаренгейт: {fahrenheit}");
}
```
```solution
fn main() {
    let celsius = 25.0;
    let fahrenheit = celsius * 1.8 + 32.0;
    println!("Фаренгейт: {fahrenheit}");
}
```
```expect
Фаренгейт: 77
```
hint: Умножение — `*`, сложение — `+`.
hint: Не забудь: дробное число пишется `32.0`, а не `32`.

:: text Удобная запись больших чисел
В числе можно ставить подчёркивания для удобства чтения. Компьютер их не замечает:

```rust
let million = 1_000_000;
```
Тип можно указать прямо в числе, в конце: `5u8`, `10i64`, `2.5f32`.

:: deep Что будет, если число не влезает
У каждого целого типа есть предел. `u8` хранит максимум 255. Что будет, если прибавить 1 к 255?

- При обычном запуске (режим debug) программа **запаникует**: `attempt to add with overflow` — «попытка сложения с переполнением».
- Если нужно другое поведение, его выбирают явно специальными методами.

```rust
fn main() {
    let x: u8 = 255;
    println!("{:?}", x.checked_add(1));
    println!("{}", x.wrapping_add(1));
    println!("{}", x.saturating_add(1));
    println!("Предел u8: {}, предел i32: {}", u8::MAX, i32::MAX);
}
```
```out
None
0
255
Предел u8: 255, предел i32: 2147483647
```
- `checked_add` — вернуть «ничего» (`None`), если не влезло;
- `wrapping_add` — пойти по кругу: после 255 идёт 0;
- `saturating_add` — остановиться на пределе.

:: recap
- `i32` — целое, `f64` — дробное. Это типы по умолчанию.
- Целое деление отбрасывает дробь: `7 / 2 == 3`. `%` — остаток.
- Целое в дробное: `x as f64`.

## LESSON m01-4 | Да, нет и символы | 5
:: goals
- Тип `bool`: правда или ложь
- Тип `char`: один символ
- Сравнения

:: text bool — правда или ложь
Тип `bool` хранит одно из двух: `true` (правда) или `false` (ложь).

```rust
let is_raining = true;
let has_umbrella = false;
```
Это как выключатель: включён или выключен.

:: text Сравнения дают bool
- `==` равно (два знака! один `=` — это присваивание)
- `!=` не равно
- `<`, `>` меньше, больше
- `<=`, `>=` меньше или равно, больше или равно

```rust
let adult = 20 >= 18; // true
```

:: text И, или, не
- `&&` — «и»: правда, если обе части правда.
- `||` — «или»: правда, если хотя бы одна правда.
- `!` — «не»: переворачивает.

```rust
let go_outside = !is_raining || has_umbrella;
```
Читается: «идём гулять, если нет дождя или есть зонт».

:: quiz
Чему равно `5 > 3 && 2 > 4`?
[ ] true => Первая часть правда, но вторая — нет. Для `&&` нужны обе.
[x] false => Верно. `2 > 4` — ложь, значит всё выражение ложь.

:: text char — один символ
Тип `char` хранит **один** символ. Пишется в **одинарных** кавычках:

```rust
let letter = 'Я';
let smile = '☺';
```
!> `'a'` — символ (char). `"a"` — текст (строка). Это разные типы.

:: quiz
Где здесь `char`?
[ ] `"Б"` => Двойные кавычки — это строка, даже из одной буквы.
[x] `'Б'` => Верно. Одинарные кавычки — один символ.
[ ] `Б` => Без кавычек компилятор подумает, что это имя переменной.

:: deep Сколько места занимает char
`char` в Rust занимает **4 байта**. В нём помещается любой символ Юникода: буквы всех алфавитов, иероглифы, эмодзи.

У каждого символа есть номер в таблице Юникода. Его можно узнать через `as u32`:

```rust
fn main() {
    println!("{}", 'A' as u32);
    println!("{}", 'Я' as u32);
    println!("{}", char::from_u32(1071).unwrap());
}
```
```out
65
1071
Я
```

:: recap
- `bool`: `true` или `false`.
- `==` сравнивает, `=` присваивает.
- `&&` и, `||` или, `!` не.
- `char` — один символ в одинарных кавычках.

## LESSON m01-5 | Константы и затенение | 6
:: goals
- Константы `const`
- Затенение: новая переменная со старым именем

:: text Константа
**Константа** — значение, которое не меняется никогда. Например, число секунд в минуте.

```rust
const SECONDS_IN_MINUTE: u32 = 60;
```
Правила:
- Пишется большими буквами.
- Тип указывать **обязательно**.
- `mut` нельзя.

:: text Затенение
Можно снова написать `let` с тем же именем. Получится **новая** переменная, а старая спрячется. Это называется **затенение** (shadowing).

```rust
let x = 5;
let x = x * 2; // новая x = 10
```
> **Аналогия:** это похоже на наклейку поверх старой наклейки. Старая коробка есть, но мы её больше не видим.

:: code
Затенение даже позволяет поменять тип:
```rust
fn main() {
    let input = "42";
    let input: i32 = input.parse().unwrap();
    println!("Число плюс один: {}", input + 1);
}
```
```out
Число плюс один: 43
```
Здесь `parse()` превращает текст в число. `unwrap()` пока просто «доверяем, что получилось». Подробно — в модуле про ошибки.

:: quiz
Что напечатает программа?
```rust
fn main() {
    let a = 3;
    let a = a + 1;
    let a = a * 10;
    println!("{a}");
}
```
[ ] 3 => Каждое `let` создаёт новую `a` из старой. Посчитай по шагам.
[x] 40 => Верно: 3 → 4 → 40.
[ ] Ошибка: переменная без mut => Затенение — это не изменение, а новая переменная. `mut` не нужен.

:: task
Создай константу `MAX_LIVES` типа `u32` со значением 3 и напечатай `Жизней: 3`.
```rust
// создай константу здесь

fn main() {
    println!("Жизней: {}", MAX_LIVES);
}
```
```solution
const MAX_LIVES: u32 = 3;

fn main() {
    println!("Жизней: {}", MAX_LIVES);
}
```
```expect
Жизней: 3
```
hint: Формат: `const ИМЯ: тип = значение;`
hint: `const MAX_LIVES: u32 = 3;`

:: deep Почему по умолчанию нельзя менять
В больших программах много кода читает одни и те же данные. Если данные могут измениться в любой момент, сложно понять, откуда взялась ошибка.

Rust делает неизменяемость обычным случаем. Тогда `mut` работает как метка: «внимание, здесь значение меняется». Читать такой код проще.

Есть и вторая причина: неизменяемые данные безопасно отдавать сразу нескольким частям программы и даже нескольким потокам. Про потоки — в модуле 17.

:: recap
- `const ИМЯ: тип = значение;` — константа навсегда.
- Повторный `let` с тем же именем — затенение, новая переменная.
- Затенение может сменить тип, `mut` — нет.

## LESSON m01-p | Практика: переменные и числа | 10 | practice
:: goals
- Создавать переменные и менять их
- Считать с целыми и дробными числами

:: fill
Заполни типы: целое со знаком, дробное, логическое, символ.
```rust
let a: ___ = -5;
let b: ___ = 2.5;
let c: ___ = true;
let d: ___ = 'z';
```
= i32 | i64 | i8 | i16 | i128 | isize
= f64 | f32
= bool
= char

:: task
Посчитай площадь и периметр прямоугольника 7 на 3. Напечатай две строки: `Площадь: 21` и `Периметр: 20`.
```rust
fn main() {
    let width = 7;
    let height = 3;
}
```
```solution
fn main() {
    let width = 7;
    let height = 3;
    println!("Площадь: {}", width * height);
    println!("Периметр: {}", 2 * (width + height));
}
```
```expect
Площадь: 21
Периметр: 20
```
hint: Площадь — `width * height`. Периметр — `2 * (width + height)`.
hint: `println!("Площадь: {}", width * height);`

:: task
Переведи 135 секунд в минуты и секунды. Напечатай `2 мин 15 сек`.
```rust
fn main() {
    let total = 135;
}
```
```solution
fn main() {
    let total = 135;
    let minutes = total / 60;
    let seconds = total % 60;
    println!("{minutes} мин {seconds} сек");
}
```
```expect
2 мин 15 сек
```
hint: Целое деление `/` даёт минуты. Остаток `%` даёт секунды.
hint: `let minutes = total / 60; let seconds = total % 60;`

:: task
Почини программу. Она должна напечатать `Средняя: 2.5`.
```rust
fn main() {
    let sum = 10;
    let count = 4;
    let avg = sum / count;
    println!("Средняя: {avg}");
}
```
```solution
fn main() {
    let sum = 10;
    let count = 4;
    let avg = sum as f64 / count as f64;
    println!("Средняя: {avg}");
}
```
```expect
Средняя: 2.5
```
hint: Сейчас деление целое, и дробная часть теряется.
hint: Преврати оба числа в `f64`: `sum as f64 / count as f64`.

:: task
Есть счёт игрока: 15. Добавь 50 очков, потом отними 20, потом удвой. Напечатай `Счёт: 90`. Используй `+=`, `-=`, `*=`.
```rust
fn main() {
    let score = 15;
    println!("Счёт: {score}");
}
```
```solution
fn main() {
    let mut score = 15;
    score += 50;
    score -= 20;
    score *= 2;
    println!("Счёт: {score}");
}
```
```expect
Счёт: 90
```
hint: Переменная должна быть `mut`.
hint: 15 + 50 = 65, 65 − 20 = 45, 45 × 2 = 90.

:: quiz
Что напечатает `println!("{}", 17 / 5 * 5 + 17 % 5);`?
[x] 17 => Верно. 17 / 5 = 3, 3 × 5 = 15, 17 % 5 = 2, 15 + 2 = 17.
[ ] 17.0 => Все числа целые, дробной точки не будет.
[ ] 3 => Это только первая часть: 17 / 5.

:: recap
- Целые числа делятся без остатка, остаток даёт `%`.
- Для дробного результата нужно `as f64`.
- Меняешь переменную — нужен `mut`.
