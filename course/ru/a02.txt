# MODULE a02 | Итераторы изнутри | Свой итератор, IntoIterator, fold, collect во что угодно

## LESSON a02-1 | Свой итератор | 7
:: goals
- Написать тип, который умеет `next()`
- Получить все методы итератора бесплатно

:: text Итератор — это просто next
Чтобы стать итератором, типу нужно реализовать **один** метод:

```rust
fn next(&mut self) -> Option<Self::Item>
```
- Есть ещё значение — вернуть `Some(значение)`.
- Значения кончились — вернуть `None`.

Всё остальное (`map`, `filter`, `sum`, `collect`…) — методы по умолчанию. Они появятся сами.

> **Аналогия:** диспенсер салфеток. Тянешь — получаешь салфетку. Пусто — ничего не выходит.

:: code
```rust
struct Countdown {
    n: u32,
}

impl Iterator for Countdown {
    type Item = u32;
    fn next(&mut self) -> Option<u32> {
        if self.n == 0 {
            None
        } else {
            self.n -= 1;
            Some(self.n + 1)
        }
    }
}

fn main() {
    for x in (Countdown { n: 3 }) {
        println!("{x}");
    }
    println!("старт!");
}
```
```out
3
2
1
старт!
```
Почему `&mut self`? Итератор **помнит, где остановился**, и меняет это состояние на каждом шаге.

:: code
Свой итератор сразу умеет всё, что умеют обычные:
```rust
struct Countdown {
    n: u32,
}

impl Iterator for Countdown {
    type Item = u32;
    fn next(&mut self) -> Option<u32> {
        if self.n == 0 {
            None
        } else {
            self.n -= 1;
            Some(self.n + 1)
        }
    }
}

fn main() {
    let total: u32 = Countdown { n: 5 }.filter(|x| x % 2 == 1).sum();
    println!("{total}");
}
```
```out
9
```
5 + 3 + 1 = 9. Мы написали только `next`, а `filter` и `sum` достались даром.

:: quiz
Какой метод обязательно реализовать, чтобы тип стал итератором?
[ ] `iter` => Это метод коллекций, не итератора.
[x] `next` => Верно. Всё остальное — по умолчанию.
[ ] `map` и `filter` => Они уже готовы в трейте.

:: text Бесконечные итераторы
`next` может **никогда** не вернуть `None`. Это нормально — просто бери нужное количество через `take`.

```rust
struct Fib { a: u64, b: u64 }

impl Iterator for Fib {
    type Item = u64;
    fn next(&mut self) -> Option<u64> {
        let r = self.a;
        self.a = self.b;
        self.b += r;
        Some(r)
    }
}
```
`Fib { a: 0, b: 1 }.take(10)` даст первые 10 чисел Фибоначчи.


hint: `let r = self.a; self.a = self.b; self.b += r; Some(r)`.

:: deep Где живёт состояние
У каждого итератора своё состояние: счётчик, позиция в массиве, два последних числа Фибоначчи.

Когда ты пишешь `v.iter().map(f).filter(g)`, получается **матрёшка** структур: `Filter<Map<Iter<i32>, F>, G>`. Каждая хранит внутреннюю и своё замыкание. Вызов `next` у внешней дёргает `next` у внутренней.

Компилятор умеет «расплющить» эту матрёшку в простой цикл. Поэтому цепочка итераторов в Rust обычно так же быстра, как цикл `for` руками. Это называют **абстракцией без накладных расходов** (zero-cost abstraction).

:: recap
- Итератор = `type Item` + `fn next(&mut self) -> Option<Item>`.
- `None` — конец. Можно никогда не заканчивать и брать `take(n)`.
- Все адаптеры (`map`, `filter`, `sum`…) приходят бесплатно.

## LESSON a02-2 | IntoIterator: как работает for | 7
:: goals
- Понять, что `for` вызывает `into_iter()`
- Различать `iter()`, `iter_mut()`, `into_iter()`

:: text Что делает for на самом деле
Строка `for x in коллекция` превращается примерно в такое:

```rust
let mut it = коллекция.into_iter();
while let Some(x) = it.next() {
    // тело цикла
}
```
`into_iter()` — метод трейта `IntoIterator`: «как из меня сделать итератор».

:: text Три способа обойти Vec
- `for x in v.iter()` (или `for x in &v`) — `x` это `&T`. Смотрим.
- `for x in v.iter_mut()` (или `for x in &mut v`) — `x` это `&mut T`. Меняем.
- `for x in v` (или `v.into_iter()`) — `x` это `T`. Забираем. После цикла `v` больше нет.

> **Аналогия:** коробка с конфетами. Посмотреть на каждую, переложить каждую по-другому или съесть все. После третьего коробка пустая.

:: code
```rust
fn main() {
    let mut v = vec![1, 2, 3];
    for x in &mut v {
        *x *= 10;
    }
    for x in &v {
        print!("{x} ");
    }
    println!();
    let total: i32 = v.into_iter().sum();
    println!("{total}");
}
```
```out
10 20 30
60
```
`*x *= 10` — звёздочка, потому что `x` здесь ссылка, а менять нужно само число.

:: quiz
После `for s in names { ... }` где `names: Vec<String>` — можно ли использовать `names`?
[ ] Да, цикл ничего не меняет => Цикл забрал владение.
[x] Нет, `for` по значению забрал вектор => Верно. Пиши `for s in &names`, если вектор ещё нужен.
[ ] Да, но только `names.len()` => Даже это нельзя.

:: text Свой тип в for
Хочешь писать `for x in &my_list`? Реализуй `IntoIterator` для `&MyList`. Проще всего — отдать итератор внутреннего вектора:

```rust
struct Playlist { songs: Vec<String> }

impl<'a> IntoIterator for &'a Playlist {
    type Item = &'a String;
    type IntoIter = std::slice::Iter<'a, String>;
    fn into_iter(self) -> Self::IntoIter {
        self.songs.iter()
    }
}
```
`'a` — время жизни: элементы живут, пока жив плейлист. Подробнее — в модуле про времена жизни.

:: code
```rust
struct Playlist {
    songs: Vec<String>,
}

impl<'a> IntoIterator for &'a Playlist {
    type Item = &'a String;
    type IntoIter = std::slice::Iter<'a, String>;
    fn into_iter(self) -> Self::IntoIter {
        self.songs.iter()
    }
}

fn main() {
    let p = Playlist { songs: vec![String::from("Intro"), String::from("Outro")] };
    for s in &p {
        println!("♪ {s}");
    }
    println!("всего: {}", p.songs.len());
}
```
```out
♪ Intro
♪ Outro
всего: 2
```

:: fill
Заполни пропуски: удвой каждое число на месте, потом напечатай вектор.
```rust
fn main() {
    let mut v = vec![1, 2, 3];
    for x in v.___() {
        ___x *= 2;
    }
    println!("{v:?}");
}
```
= iter_mut
= *
explain: `iter_mut()` даёт `&mut i32`, а `*x` — само число, которое меняем.

:: recap
- `for x in c` = `c.into_iter()` + `next()` в цикле.
- `&v` → `&T`, `&mut v` → `&mut T`, `v` → `T` (вектор съеден).
- Свой тип в `for` — реализуй `IntoIterator`.

## LESSON a02-3 | Адаптеры, о которых забывают | 8
:: goals
- Познакомиться с `zip`, `chain`, `windows`, `flat_map`, `take_while`
- Собирать короткие конвейеры вместо циклов

:: text Склеить и соединить
- `a.zip(b)` — идти по двум итераторам **парами**: `(a1, b1)`, `(a2, b2)`… Кончается, когда кончился короткий.
- `a.chain(b)` — сначала весь `a`, потом весь `b`.
- `enumerate()` — добавить номер: `(0, x)`, `(1, y)`…

:: code
```rust
fn main() {
    let names = ["Аня", "Боря", "Вика"];
    let scores = [90, 75, 82];
    for (n, s) in names.iter().zip(scores.iter()) {
        println!("{n}: {s}");
    }
    let all: Vec<i32> = (1..3).chain(7..9).collect();
    println!("{all:?}");
}
```
```out
Аня: 90
Боря: 75
Вика: 82
[1, 2, 7, 8]
```

:: text Окна и куски (у срезов)
- `v.windows(2)` — скользящее окно: `[a,b]`, `[b,c]`, `[c,d]`…
- `v.chunks(2)` — нарезка без перекрытия: `[a,b]`, `[c,d]`, `[e]`.

> **Аналогия:** `windows` — смотреть в окно поезда: каждый кадр чуть сдвинут. `chunks` — резать батон на куски.

:: code
```rust
fn main() {
    let temps = [3, 5, 4, 8, 10];
    let rises = temps.windows(2).filter(|w| w[1] > w[0]).count();
    println!("потеплело {rises} раза");

    for part in [1, 2, 3, 4, 5].chunks(2) {
        println!("{part:?}");
    }
}
```
```out
потеплело 3 раза
[1, 2]
[3, 4]
[5]
```

:: text Остановиться и пропустить
- `take_while(условие)` — брать, **пока** условие правда. Первое «ложь» — стоп.
- `skip_while(условие)` — пропускать, пока правда, потом брать всё.
- `step_by(n)` — каждый n-й.
- `rev()` — задом наперёд.

:: text Развернуть вложенное
`flat_map` — как `map`, но каждый элемент превращается в **несколько**, и всё склеивается в один поток.

```rust
let words = ["кот", "пёс"];
let letters: Vec<char> = words.iter().flat_map(|w| w.chars()).collect();
// ['к', 'о', 'т', 'п', 'ё', 'с']
```
Если внутри уже готовые итераторы или `Vec`, хватит `flatten()`.

:: quiz
Что вернёт `[1, 2, 3, 10, 4].iter().take_while(|&&x| x < 5).count()`?
[ ] 4 => `take_while` останавливается на первом неподходящем, а `4` после `10` не учитывается.
[x] 3 => Верно. `1, 2, 3`, потом `10` — стоп.
[ ] 5 => Не все элементы меньше 5.

:: task
Посчитай, сколько раз в списке два соседних числа **равны**. Используй `windows(2)`.
```rust
fn main() {
    let v = [1, 1, 2, 3, 3, 3, 4];
    // твой код
}
```
```solution
fn main() {
    let v = [1, 1, 2, 3, 3, 3, 4];
    let pairs = v.windows(2).filter(|w| w[0] == w[1]).count();
    println!("{pairs}");
}
```
```expect
3
```
hint: `v.windows(2)` даёт срезы из двух элементов: `w[0]` и `w[1]`.

:: recap
- `zip` — парами, `chain` — друг за другом, `enumerate` — с номером.
- `windows` — скользящее окно, `chunks` — куски.
- `take_while`, `skip_while`, `step_by`, `rev` — управлять потоком.
- `flat_map`/`flatten` — развернуть вложенное.

## LESSON a02-4 | fold и collect во что угодно | 8
:: goals
- Сворачивать поток в одно значение через `fold`
- Собирать в `String`, `HashMap`, `Result<Vec>`

:: text fold — свернуть всё в одно
`fold(начало, |накопленное, x| новое_накопленное)`.

```rust
let sum = [1, 2, 3].iter().fold(0, |acc, x| acc + x); // 6
```
`sum`, `count`, `max` — это частные случаи `fold`. Когда готового метода нет — бери `fold`.

> **Аналогия:** снежный ком. Катишь по снегу — каждый шаг он прилипает к себе ещё немного.

:: code
```rust
fn main() {
    let words = ["rust", "это", "весело"];
    let longest = words.iter().fold("", |best, &w| {
        if w.chars().count() > best.chars().count() { w } else { best }
    });
    println!("{longest}");

    let sentence = words.iter().fold(String::new(), |mut s, w| {
        if !s.is_empty() { s.push(' '); }
        s.push_str(w);
        s
    });
    println!("{sentence}");
}
```
```out
весело
rust это весело
```

:: text collect умеет многое
`collect()` смотрит на **тип**, который ты просишь, и собирает в него:
- `Vec<T>` — список.
- `String` — из символов или строк.
- `HashMap<K, V>` или `BTreeMap<K, V>` — из пар `(ключ, значение)`.
- `Result<Vec<T>, E>` — из потока `Result`ов. Первая ошибка — и весь результат `Err`.

:: code
```rust
use std::collections::BTreeMap;

fn main() {
    let s: String = ['R', 'u', 's', 't'].iter().collect();
    println!("{s}");

    let ages: BTreeMap<&str, u32> = [("Аня", 30), ("Боря", 25)].into_iter().collect();
    println!("{ages:?}");

    let good: Result<Vec<i32>, _> = ["1", "2", "3"].iter().map(|x| x.parse::<i32>()).collect();
    println!("{good:?}");

    let bad: Result<Vec<i32>, _> = ["1", "кот", "3"].iter().map(|x| x.parse::<i32>()).collect();
    println!("{}", bad.is_err());
}
```
```out
Rust
{"Аня": 30, "Боря": 25}
Ok([1, 2, 3])
true
```
`BTreeMap` хранит ключи по порядку. Поэтому вывод всегда одинаковый — удобно для примеров.

:: quiz
Что получится, если собрать `["4", "x", "6"]` в `Result<Vec<i32>, _>` через `parse`?
[ ] `Ok([4, 6])` => Ошибки не выбрасываются молча.
[x] `Err(...)` => Верно. Одна ошибка — и весь результат ошибка.
[ ] `Ok([4, 0, 6])` => Rust не подставляет ноль сам.

:: text peekable — подсмотреть следующий
Иногда нужно посмотреть на следующий элемент, **не забирая** его. Для этого `peekable()`:

```rust
let mut it = [1, 2, 3].iter().peekable();
if let Some(&&next) = it.peek() {
    // next == 1, но он всё ещё в итераторе
}
```
Пригождается, когда разбираешь текст: «следующий символ цифра? тогда читаю число дальше».

:: task
Посчитай, сколько раз встречается каждое слово. Собери в `BTreeMap<&str, u32>` и напечатай его.
```rust
use std::collections::BTreeMap;

fn main() {
    let text = "кот пёс кот рыба кот пёс";
    let mut counts: BTreeMap<&str, u32> = BTreeMap::new();
    // твой код
    println!("{counts:?}");
}
```
```solution
use std::collections::BTreeMap;

fn main() {
    let text = "кот пёс кот рыба кот пёс";
    let mut counts: BTreeMap<&str, u32> = BTreeMap::new();
    for w in text.split_whitespace() {
        *counts.entry(w).or_insert(0) += 1;
    }
    println!("{counts:?}");
}
```
```expect
{"кот": 3, "пёс": 2, "рыба": 1}
```
hint: `text.split_whitespace()` даёт слова.
hint: `*counts.entry(w).or_insert(0) += 1;` — увеличить счётчик слова, создав его при первом появлении.

:: recap
- `fold(start, |acc, x| ...)` — свернуть в одно значение.
- `collect` собирает в тот тип, который ты попросил.
- `Result<Vec<_>, _>` через `collect` — остановиться на первой ошибке.
- `peekable` — посмотреть следующий, не забирая.

## LESSON a02-p | Практика: итераторы | 15 | practice
:: goals
- Написать свой итератор и пару конвейеров

:: task
Итератор `Steps` выдаёт числа от `start` до `end` включительно с шагом `step`. Допиши `next`.
```rust
struct Steps {
    cur: u32,
    end: u32,
    step: u32,
}

impl Iterator for Steps {
    type Item = u32;
    fn next(&mut self) -> Option<u32> {
        // твой код
    }
}

fn main() {
    let v: Vec<u32> = Steps { cur: 2, end: 11, step: 3 }.collect();
    println!("{v:?}");
}
```
```solution
struct Steps {
    cur: u32,
    end: u32,
    step: u32,
}

impl Iterator for Steps {
    type Item = u32;
    fn next(&mut self) -> Option<u32> {
        if self.cur > self.end {
            return None;
        }
        let r = self.cur;
        self.cur += self.step;
        Some(r)
    }
}

fn main() {
    let v: Vec<u32> = Steps { cur: 2, end: 11, step: 3 }.collect();
    println!("{v:?}");
}
```
```expect
[2, 5, 8, 11]
```
hint: Если `cur` уже больше `end` — `None`. Иначе запомни `cur`, увеличь на `step` и верни запомненное.

:: task
Даны имена и баллы. Выведи только тех, у кого больше 80, в формате `имя — баллы`. Используй `zip` и `filter`.
```rust
fn main() {
    let names = ["Аня", "Боря", "Вика", "Гена"];
    let scores = [95, 70, 88, 80];
    // твой код
}
```
```solution
fn main() {
    let names = ["Аня", "Боря", "Вика", "Гена"];
    let scores = [95, 70, 88, 80];
    for (n, s) in names.iter().zip(scores.iter()).filter(|(_, s)| **s > 80) {
        println!("{n} — {s}");
    }
}
```
```expect
Аня — 95
Вика — 88
```
hint: `names.iter().zip(scores.iter())` даёт пары `(&имя, &балл)`.
hint: В `filter` приходит ссылка на пару, поэтому `**s > 80`.

:: task
Преврати строку `"3,8,x,1"` в сумму чисел, **пропуская** то, что не число. Используй `filter_map`.
```rust
fn main() {
    let line = "3,8,x,1";
    // твой код
}
```
```solution
fn main() {
    let line = "3,8,x,1";

```
```expect
12
```
hint: `filter_map` оставляет только `Some`. А `.ok()` превращает `Result` в `Option`.

:: task
Через `fold` найди одновременно минимум и максимум списка и напечатай `мин 2, макс 9`.
```rust
fn main() {
    let v = [5, 2, 9, 4];
    // твой код
}
```
```solution
fn main() {
    let v = [5, 2, 9, 4];
    let (lo, hi) = v.iter().fold((i32::MAX, i32::MIN), |(lo, hi), &x| (lo.min(x), hi.max(x)));
    println!("мин {lo}, макс {hi}");
}
```
```expect
мин 2, макс 9
```
hint: Накопленное значение может быть парой: `(минимум, максимум)`.
hint: Начни с `(i32::MAX, i32::MIN)`, а на каждом шаге `(lo.min(x), hi.max(x))`.

:: recap
- Свой итератор — только `next`.
- `zip` + `filter`, `filter_map` + `ok()`, `fold` с парой — частые приёмы.
