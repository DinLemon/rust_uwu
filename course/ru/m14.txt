# MODULE m14 | Замыкания и итераторы | Конвейер для данных

## LESSON m14-1 | Замыкания | 6
:: goals
- Что такое замыкание
- Как оно «захватывает» переменные

:: text Функция на лету
**Замыкание** (closure) — маленькая функция без имени, которую пишут прямо на месте. Параметры — между палочками `| |`.

```rust
let double = |x| x * 2;
println!("{}", double(5)); // 10
```
Типы обычно указывать не нужно: компилятор поймёт сам.

:: text Замыкание видит переменные вокруг
В отличие от `fn`, замыкание **захватывает** переменные из окружения:

```rust
let bonus = 10;
let add_bonus = |x| x + bonus;
println!("{}", add_bonus(5)); // 15
```
> Как записка, в которой уже вписан адрес. Не нужно передавать его каждый раз.

:: code
```rust
fn main() {
    let mut count = 0;
    let mut click = || {
        count += 1;
        println!("Клик номер {count}");
    };
    click();
    click();
    println!("Всего: {count}");
}
```
```out
Клик номер 1
Клик номер 2
Всего: 2
```
Замыкание меняет `count`, поэтому само должно быть `mut`.

:: text move — забрать с собой
Слово `move` перед замыканием заставляет его **забрать** переменные во владение, а не одолжить.

```rust
let name = String::from("Аня");
let hello = move || println!("Привет, {name}");
```
Это понадобится в модуле про потоки.

:: quiz
Что напечатает `let f = |a, b| a * b; println!("{}", f(3, 4));`?
[ ] 7 => `*` — умножение, а не сложение.
[x] 12 => Верно.
[ ] Ошибка: у замыкания нет имени => Имя ему и не нужно: мы положили его в переменную `f`.

:: deep Три вида замыканий
Компилятор делит замыкания на три вида по тому, что они делают с захваченными переменными:
- `Fn` — только **читает**. Можно вызывать сколько угодно раз.
- `FnMut` — **меняет**. Само замыкание должно быть `mut`.
- `FnOnce` — **забирает** владение. Вызвать можно только один раз.

Функция может требовать нужный вид:

```rust
fn twice<F: Fn()>(f: F) {
    f();
    f();
}

fn main() {
    let name = String::from("Rust");
    twice(|| println!("Привет, {name}"));
}
```
```out
Привет, Rust
Привет, Rust
```

:: recap
- `|параметры| выражение` — замыкание.
- Замыкание видит переменные вокруг себя.
- `move` — забрать их во владение.

## LESSON m14-2 | Итераторы и конвейер | 7
:: goals
- Что такое итератор
- Главные операции: `map`, `filter`, `collect`, `sum`

:: text Итератор — конвейер
**Итератор** выдаёт элементы по одному. На него можно навесить операции.

> Конвейерная лента. Элементы едут по ней, по пути их моют (`map`), отбраковывают (`filter`), а в конце складывают в коробку (`collect`).

```rust
let v = vec![1, 2, 3, 4, 5];
let even_squares: Vec<i32> = v.iter()
    .filter(|x| *x % 2 == 0)
    .map(|x| x * x)
    .collect();
// [4, 16]
```

:: text Главные операции
- `map(|x| ...)` — превратить каждый элемент.
- `filter(|x| ...)` — оставить подходящие.
- `collect()` — собрать в коллекцию (обычно `Vec`).
- `sum()`, `count()`, `max()`, `min()` — посчитать итог.
- `enumerate()` — дать номер каждому элементу.
- `zip(другой)` — шагать по двум спискам парами.

:: code
```rust
fn main() {
    let prices = vec![120, 45, 300, 80];
    let total: i32 = prices.iter().sum();
    let cheap = prices.iter().filter(|p| **p < 100).count();
    let with_tax: Vec<i32> = prices.iter().map(|p| p * 12 / 10).collect();
    println!("Сумма: {total}, дешёвых: {cheap}");
    println!("С налогом: {:?}", with_tax);
    for (i, p) in prices.iter().enumerate() {
        println!("{}. {p}", i + 1);
    }
}
```
```out
Сумма: 545, дешёвых: 2
С налогом: [144, 54, 360, 96]
1. 120
2. 45
3. 300
4. 80
```
`**p` — два разыменования. `iter()` даёт ссылки, а `filter` даёт ссылку на ссылку. Если звёздочки путают — пиши `|&&p| p < 100` или просто следуй подсказкам компилятора.

:: order
Собери конвейер: сумма квадратов чисел от 1 до 3.
```rust
let total: i32 = (1..=3)
    .map(|x| x * x)
    .sum();
```

:: quiz
Что вернёт `vec![1, 2, 3].iter().map(|x| x + 10).collect::<Vec<i32>>()`?
[x] `[11, 12, 13]` => Верно. `map` меняет каждый элемент.
[ ] `[1, 2, 3]` => `map` не просто перебирает, он превращает.
[ ] `36` => Это было бы `sum()`, а не `collect()`.

:: text Ещё полезные операции
- `take(n)` — взять первые `n`; `skip(n)` — пропустить первые `n`.
- `any(|x| ...)` — есть ли хоть один подходящий; `all(|x| ...)` — подходят ли все.
- `find(|x| ...)` — первый подходящий, в `Option`.
- `position(|x| ...)` — номер первого подходящего, в `Option`.
- `fold(начало, |акк, x| ...)` — свернуть всё в одно значение.

```rust
let v = vec![3, 8, 1, 9];
v.iter().any(|&x| x > 8);          // true
v.iter().find(|&&x| x > 5);        // Some(&8)
v.iter().fold(0, |acc, x| acc + x); // 21
```

:: recap
- `.iter()` — ссылки на элементы.
- `map`, `filter`, `enumerate`, `zip` — по пути.
- `collect`, `sum`, `count`, `max` — в конце.

## LESSON m14-3 | Ленивость и виды перебора | 6
:: goals
- Почему итераторы ленивые
- Разница `iter`, `iter_mut`, `into_iter`

:: text Конвейер не едет без команды
Итераторы **ленивые**. Пока ты не попросишь результат (`collect`, `sum`, `for`), ничего не происходит.

```rust
let v = vec![1, 2, 3];
v.iter().map(|x| println!("{x}")); // ничего не напечатает!
```
Компилятор даже предупредит: «iterators are lazy and do nothing unless consumed».

> Это экономно: если взять только первые 3 элемента через `.take(3)`, остальные даже не будут обработаны.

:: text Три способа перебора
- `iter()` — смотреть: даёт `&T`.
- `iter_mut()` — менять: даёт `&mut T`.
- `into_iter()` — забрать: даёт `T`, вектор после этого исчезает.

`for x in &v` — то же, что `v.iter()`. `for x in v` — то же, что `v.into_iter()`.

:: task
Из списка слов собери новый вектор: только слова длиннее 3 букв, большими буквами.
```rust
fn main() {
    let words = vec!["кот", "собака", "ёж", "попугай"];
    let result: Vec<String> = words
        .iter()
        // твой конвейер
        .collect();
    println!("{:?}", result);
}
```
```solution
fn main() {
    let words = vec!["кот", "собака", "ёж", "попугай"];
    let result: Vec<String> = words
        .iter()
        .filter(|w| w.chars().count() > 3)
        .map(|w| w.to_uppercase())
        .collect();
    println!("{:?}", result);
}
```
```expect
["СОБАКА", "ПОПУГАЙ"]
```
hint: Длина в буквах — `w.chars().count()`, не `len()`: русские буквы занимают два байта.
hint: `.filter(|w| w.chars().count() > 3).map(|w| w.to_uppercase())`

:: deep Свой итератор
Итератором становится любой тип, у которого есть метод `next`, возвращающий `Option`. Это трейт `Iterator`:

```rust
struct Countdown(u32);

impl Iterator for Countdown {
    type Item = u32;
    fn next(&mut self) -> Option<u32> {
        if self.0 == 0 {
            None
        } else {
            self.0 -= 1;
            Some(self.0 + 1)
        }
    }
}

fn main() {
    let v: Vec<u32> = Countdown(3).collect();
    println!("{:?}", v);
    println!("{}", Countdown(4).map(|x| x * 10).sum::<u32>());
}
```
```out
[3, 2, 1]
100
```
Написал один `next` — и получил бесплатно `map`, `filter`, `sum` и всё остальное.

Кстати, цепочки итераторов работают так же быстро, как ручной цикл: компилятор превращает их в обычный цикл.

:: recap
- Итераторы ленивые: работа начинается в `collect`/`sum`/`for`.
- `iter` — смотреть, `iter_mut` — менять, `into_iter` — забрать.

:: task
Посчитай сумму квадратов нечётных чисел от 1 до 9 одной цепочкой.
```rust
fn main() {
    let total: i32 = (1..=9)
        // твоя цепочка
        .sum();
    println!("{total}");
}
```
```solution
fn main() {
    let total: i32 = (1..=9)
        .filter(|x| x % 2 == 1)
        .map(|x| x * x)
        .sum();
    println!("{total}");
}
```
```expect
165
```
hint: Сначала `filter` для нечётных, потом `map` для квадратов.
hint: `.filter(|x| x % 2 == 1).map(|x| x * x)`

:: task
Найди первое слово длиннее 5 букв. Используй `find`.
```rust
fn main() {
    let words = ["код", "ржавчина", "краб", "компилятор"];
    let long = words.iter().find(|w| true);
    println!("{:?}", long);
}
```
```solution
fn main() {
    let words = ["код", "ржавчина", "краб", "компилятор"];
    let long = words.iter().find(|w| w.chars().count() > 5);
    println!("{:?}", long);
}
```
```expect
Some("ржавчина")
```
hint: Длина в буквах — `w.chars().count()`.
hint: `.find(|w| w.chars().count() > 5)`

:: task
Проверь список оценок: есть ли хоть одна двойка и все ли оценки положительные. Напечатай `true` и `true`.
```rust
fn main() {
    let marks = [5, 4, 2, 5, 3];
    let has_two = false;
    let all_positive = false;
    println!("{has_two} {all_positive}");
}
```
```solution
fn main() {
    let marks = [5, 4, 2, 5, 3];
    let has_two = marks.iter().any(|&m| m == 2);
    let all_positive = marks.iter().all(|&m| m > 0);
    println!("{has_two} {all_positive}");
}
```
```expect
true true
```
hint: `any` — «хотя бы один», `all` — «все».
hint: `marks.iter().any(|&m| m == 2)` и `marks.iter().all(|&m| m > 0)`

:: task
Напиши функцию `above`, которая возвращает вектор чисел больше `limit`. Замыкание внутри `filter` должно захватить `limit`.
```rust
fn above(nums: &[i32], limit: i32) -> Vec<i32> {
    Vec::new()
}

fn main() {
    println!("{:?}", above(&[4, 10, 7, 1, 12], 6));
}
```
```solution
fn above(nums: &[i32], limit: i32) -> Vec<i32> {
    nums.iter().filter(|&&x| x > limit).copied().collect()
}

fn main() {
    println!("{:?}", above(&[4, 10, 7, 1, 12], 6));
}
```
```expect
[10, 7, 12]
```
hint: `nums.iter().filter(...)` даёт ссылки. `.copied()` превращает `&i32` в `i32`.
hint: `nums.iter().filter(|&&x| x > limit).copied().collect()`

:: task
Пронумеруй задачи с единицы через `enumerate` и собери строки в вектор.
```rust
fn main() {
    let tasks = ["купить хлеб", "учить Rust"];
    let lines: Vec<String> = Vec::new();
    for l in &lines {
        println!("{l}");
    }
}
```
```solution
fn main() {
    let tasks = ["купить хлеб", "учить Rust"];
    let lines: Vec<String> = tasks
        .iter()
        .enumerate()
        .map(|(i, t)| format!("{}. {}", i + 1, t))
        .collect();
    for l in &lines {
        println!("{l}");
    }
}
```
```expect
1. купить хлеб
2. учить Rust
```
hint: `enumerate()` даёт пары `(номер, элемент)`, номера с нуля.
hint: `.map(|(i, t)| format!("{}. {}", i + 1, t))`

:: recap
- `filter` → `map` → `sum`/`collect` — основной конвейер.
- `find`, `any`, `all`, `position` — поиск и проверки.
- `fold` сворачивает всё в одно значение.
