// термин | английский | объяснение  (словарь второго уровня)
Метод по умолчанию | default method | Метод трейта с готовым телом. Тип получает его бесплатно и может переопределить.
Супертрейт | supertrait | Трейт, который требуется для другого: `trait Report: Display` — чтобы быть `Report`, нужно быть `Display`.
Ассоциированный тип | associated type | Тип внутри трейта, который выбирает каждая реализация: `type Item = u32;`.
Динамическая диспетчеризация | dynamic dispatch | Вызов метода через таблицу во время работы. Так работает `dyn Trait`.
Таблица методов | vtable | Список методов конкретного типа, на который указывает `Box<dyn Trait>`.
Правило сироты | orphan rule | Реализовать трейт для типа можно, только если трейт или тип объявлены в твоём крейте.
FromStr | FromStr | Трейт «как сделать мой тип из строки». Благодаря ему работает `"...".parse()`.
IntoIterator | IntoIterator | Трейт «как сделать из меня итератор». Его вызывает цикл `for`.
Свёртка | fold | Сведение всех элементов к одному значению: `fold(0, ...)`.
FnOnce, FnMut, Fn | closure traits | Виды замыканий: забирает, меняет, только смотрит.
Указатель на функцию | fn pointer | Тип `fn(A) -> B`: обычная функция или замыкание без захвата.
'static | static lifetime | Ссылка на то, что живёт всю программу, или требование «в типе нет временных ссылок».
Пропуск меток | lifetime elision | Правила, по которым компилятор сам дописывает метки времени жизни.
Cow | clone on write | Либо ссылка, либо своё значение. Копия делается, только если нужно менять.
Слабая ссылка | Weak | Ссылка от `Rc`, которая не держит значение. `upgrade()` вернёт `None`, если оно удалено.
Newtype | newtype | Обёртка-структура с одним полем, чтобы не путать значения: `struct Meters(f64);`.
Строитель | builder | Объект, который собирает настройки по одной и в конце создаёт готовую вещь.
Typestate | typestate | Приём, когда каждое состояние — отдельный тип. Неправильный порядок не компилируется.
Send и Sync | Send, Sync | Метки типов: можно передать в другой поток / можно делиться ссылкой между потоками.
Атомик | atomic | Тип, операции с которым неделимы: `AtomicUsize`, `AtomicBool`. Работает без замка.
RwLock | read-write lock | Замок: много читателей одновременно или один писатель.
Future | future | Значение «результат будет потом». Работает, только пока его опрашивают через `poll`.
Среда выполнения | runtime | Программа, которая опрашивает Future и управляет задачами. Например, tokio.
Фрагмент макроса | fragment specifier | Что ловит `$x:...` в макросе: `expr`, `ident`, `ty`, `tt`…
Процедурный макрос | procedural macro | Программа на Rust, которая получает код и возвращает новый. Например, `#[derive(Serialize)]`.
Неопределённое поведение | undefined behavior | Ситуация, про которую язык ничего не обещает. В безопасном Rust её нет.
Сырой указатель | raw pointer | `*const T` или `*mut T`. Разыменовывать можно только в `unsafe`.
FFI | foreign function interface | Вызов функций из других языков (обычно C) и наоборот.
Семантическая версия | semver | Версия `MAJOR.MINOR.PATCH`: ломающее, новое, исправление.
Feature крейта | cargo feature | Необязательная часть крейта, которую включают в `Cargo.toml`.
