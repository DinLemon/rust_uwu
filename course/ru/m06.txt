# MODULE m06 | Заимствование и срезы | Дать посмотреть, не отдавая

## LESSON m06-1 | Ссылки: дать посмотреть | 6
:: goals
- Что такое ссылка `&`
- Как передать значение в функцию, не отдавая его

:: text Ссылка — это «посмотри, но не забирай»
**Ссылка** — это доступ к значению без владения. Пишется через `&`.

```rust
let book = String::from("Война и мир");
let r = &book; // r смотрит на book
```
Создание ссылки называется **заимствованием** (borrowing).

> Ты даёшь другу книгу почитать. Книга по-прежнему твоя. Друг вернёт её, когда дочитает.

:: code
```rust
fn count_letters(s: &String) -> usize {
    s.chars().count()
}

fn main() {
    let word = String::from("привет");
    let n = count_letters(&word);
    println!("В слове «{word}» {n} букв");
}
```
```out
В слове «привет» 6 букв
```
`word` всё ещё наша: функция только посмотрела. `usize` — тип для размеров и количеств.

:: quiz
Что значит `&word` при вызове функции?
[ ] Отдать `word` функции навсегда => Это было бы без `&`. Со знаком `&` владение остаётся.
[x] Дать функции посмотреть на `word` => Верно. Функция получает ссылку, владелец не меняется.
[ ] Сделать копию `word` => Копию делает `.clone()`. Ссылка ничего не копирует.

:: task
Функция забирает строку, и потом её нельзя напечатать. Почини, используя ссылку.
```rust
fn shout(s: String) {
    println!("{}!!!", s);
}

fn main() {
    let msg = String::from("Ура");
    shout(msg);
    println!("{msg}");
}
```
```solution
fn shout(s: &String) {
    println!("{}!!!", s);
}

fn main() {
    let msg = String::from("Ура");
    shout(&msg);
    println!("{msg}");
}
```
```expect
Ура!!!
Ура
```
hint: Изменить надо два места: тип параметра и вызов.
hint: `fn shout(s: &String)` и `shout(&msg);`

:: deep Что внутри ссылки
Ссылка — это просто **адрес** значения в памяти. Она занимает 8 байт (на 64-битном компьютере), как бы ни было велико само значение.

Адрес можно напечатать через `{:p}` (p — pointer, указатель):

```rust
fn main() {
    let big = String::from("очень длинный текст");
    let r = &big;
    println!("Адрес: {:p}", r);
    println!("Размер ссылки: {} байт", std::mem::size_of::<&String>());
}
```
Адрес будет разным при каждом запуске. Размер ссылки всегда `8 байт`.

:: recap
- `&x` — ссылка, доступ без владения.
- Функция с параметром `&T` только смотрит.
- После такого вызова переменная остаётся твоей.

## LESSON m06-2 | Изменяемые ссылки | 6
:: goals
- Как дать изменить значение: `&mut`
- Главное правило ссылок

:: text &mut — дать подписать на полях
Обычная ссылка `&` только читает. Чтобы функция могла **изменить** значение, нужна изменяемая ссылка `&mut`.

```rust
fn add_smile(s: &mut String) {
    s.push_str(" :)");
}
```
Сама переменная тоже должна быть `mut`.

:: code
```rust
fn add_smile(s: &mut String) {
    s.push_str(" :)");
}

fn main() {
    let mut text = String::from("Привет");
    add_smile(&mut text);
    add_smile(&mut text);
    println!("{text}");
}
```
```out
Привет :) :)
```

:: text Главное правило
В каждый момент можно **одно** из двух:

- сколько угодно **читателей** `&`;
- или ровно **один писатель** `&mut`.

> Как документ в общей папке. Читать могут все сразу. Но если кто-то правит — остальные ждут, чтобы не увидеть кашу.

Это правило спасает от целого класса ошибок, когда данные меняются под ногами.

:: code
Две изменяемые ссылки одновременно. Запусти.
```rust
fn main() {
    let mut s = String::from("текст");
    let a = &mut s;
    let b = &mut s;
    a.push_str("1");
    b.push_str("2");
}
```
fails: yes
Ошибка `E0499`: нельзя взять `&mut` дважды, пока первая ссылка ещё используется.

:: text Ссылка «живёт» до последнего использования
Хорошая новость: ссылка заканчивается после **последнего** места, где её использовали. Не на `}`.

```rust
let mut s = String::from("a");
let r1 = &s;
println!("{r1}"); // r1 больше не нужна
let r2 = &mut s;  // теперь можно
r2.push_str("b");
```

:: quiz
Какой набор ссылок разрешён одновременно?
[x] Три ссылки `&` => Верно. Читателей может быть сколько угодно.
[ ] Две ссылки `&mut` => Писатель может быть только один.
[ ] Одна `&` и одна `&mut` => Пока кто-то читает, писать нельзя.

:: deep От какой ошибки спасает правило
Представь: ты держишь ссылку на первый элемент вектора и в это время добавляешь в вектор новый элемент.

```rust
let mut v = vec![1, 2, 3];
let first = &v[0];
v.push(4);            // ошибка E0502
println!("{first}");
```
При `push` вектору может не хватить места. Тогда он переезжает в новую память, а старая освобождается. Ссылка `first` указывала бы на освобождённую память.

В C++ такая ошибка компилируется и потом ломает программу в случайный момент. Rust её не пропускает: пока есть читатель `first`, менять `v` нельзя.

:: recap
- `&mut x` — ссылка, через которую можно менять.
- Или много `&`, или один `&mut`.
- Ссылка живёт до последнего использования.

## LESSON m06-3 | Висячих ссылок не бывает | 5
:: goals
- Что такое висячая ссылка
- Как Rust её не допускает

:: text Ссылка в никуда
**Висячая ссылка** указывает на значение, которого уже нет. Как адрес снесённого дома.

В C такие ссылки — частая причина взломов и падений. В Rust их **не бывает**: компилятор следит.

:: code
Функция пытается вернуть ссылку на свою локальную строку. Запусти.
```rust
fn make() -> &String {
    let s = String::from("привет");
    &s
}

fn main() {
    let r = make();
}
```
fails: yes
Компилятор не пропускает. Строка `s` умрёт на `}` функции, и ссылка указывала бы в пустоту. Ошибка говорит про **lifetime** — время жизни. О нём будет отдельный модуль.

:: text Как исправить
Верни саму строку, а не ссылку. Тогда владение просто переедет наружу:

```rust
fn make() -> String {
    String::from("привет")
}
```

:: quiz
Почему нельзя вернуть `&s`, где `s` создана внутри функции?
[ ] Ссылки вообще нельзя возвращать => Можно, если значение живёт дольше функции.
[x] `s` удалится в конце функции, и ссылка повиснет => Верно. Ссылка не может пережить своё значение.
[ ] Строки нельзя создавать в функциях => Можно, просто вернуть надо её саму.

:: recap
- Ссылка не может пережить значение.
- Создал внутри функции — возвращай значение, а не ссылку.

## LESSON m06-4 | Срезы и &str | 7
:: goals
- Что такое срез
- Разница между `String` и `&str`
- Ловушка с русскими буквами

:: text Срез — окошко в часть данных
**Срез** — ссылка на кусок последовательности. Не копия, а окошко.

```rust
let nums = [10, 20, 30, 40, 50];
let middle = &nums[1..4]; // [20, 30, 40]
```
> Как рамка, которую положили на фото: видно только часть, но фото то же самое.

:: text String и &str
- `String` — **владеющая** строка в куче. Может расти.
- `&str` — **срез строки**: окошко в чужой текст.

Текст в кавычках `"привет"` — это `&str`. Он вшит прямо в программу.

> Правило: в параметрах функций пиши `&str`. Туда подойдут и `&String`, и `"текст"`.

:: code
```rust
fn greet(name: &str) {
    println!("Привет, {name}!");
}

fn main() {
    let owned = String::from("Аня");
    greet(&owned);
    greet("Боря");
    let part = &owned[0..2];
    println!("Первые байты: {part}");
}
```
```out
Привет, Аня!
Привет, Боря!
Первые байты: А
```
Стоп. `0..2` дало **одну** букву «А», а не две. Почему?

:: text Русские буквы занимают 2 байта
Строки в Rust хранятся в **UTF-8**. Латинская буква — 1 байт. Русская — 2 байта.

Срез `[0..2]` берёт **байты**, а не буквы. Если разрезать букву пополам, программа запаникует.

!> Для русского текста не режь строку по номерам. Используй `.chars()` — перебор по буквам.

:: code
```rust
fn main() {
    let word = "привет";
    println!("Байт: {}", word.len());
    println!("Букв: {}", word.chars().count());
    let first: String = word.chars().take(3).collect();
    println!("Первые три буквы: {first}");
}
```
```out
Байт: 12
Букв: 6
Первые три буквы: при
```

:: quiz
Что вернёт `"мир".len()`?
[ ] 3 => `len()` считает байты. В русской букве их два.
[x] 6 => Верно. Три русские буквы × 2 байта.
[ ] 1 => Это количество слов, а `len()` о другом.

:: task
Напиши функцию `first_word`, которая возвращает первое слово строки (до пробела). Если пробела нет — всю строку.
```rust
fn first_word(s: &str) -> &str {
    // подсказка: s.split(' ').next()
    s
}

fn main() {
    println!("{}", first_word("hello world"));
    println!("{}", first_word("rust"));
}
```
```solution
fn first_word(s: &str) -> &str {
    match s.find(' ') {
        Some(i) => &s[..i],
        None => s,
    }
}

fn main() {
    println!("{}", first_word("hello world"));
    println!("{}", first_word("rust"));
}
```
```expect
hello
rust
```
hint: `s.split(' ')` режет строку по пробелам. `.next()` даёт первый кусок.
hint: Короткое решение: `s.split(' ').next().unwrap()`. `unwrap` подробно разберём позже.

:: deep Почему &String подходит туда, где ждут &str
Функция `greet(name: &str)` принимает и `&String`. Как так, ведь типы разные?

Rust сам превращает `&String` в `&str`. Это называется **автоматическое разыменование** (deref coercion). `String` умеет выдавать срез на весь свой текст.

То же работает с векторами: `&Vec<i32>` превращается в срез `&[i32]`. Поэтому в параметрах пишут `&[i32]` — так функция примет и массив, и вектор.

:: recap
- Срез `&a[1..3]` — окошко в часть данных.
- `String` владеет текстом, `&str` — смотрит на текст.
- В параметрах функций пиши `&str`.
- `len()` — байты. Для букв — `.chars()`.

:: task
Напиши функцию `count_vowels`, которая считает гласные русские буквы в строке. Гласные: `аеёиоуыэюя`.
```rust
fn count_vowels(s: &str) -> usize {
    0
}

fn main() {
    println!("{}", count_vowels("программирование"));
}
```
```solution
fn count_vowels(s: &str) -> usize {
    let mut n = 0;
    for c in s.chars() {
        if "аеёиоуыэюя".contains(c) {
            n += 1;
        }
    }
    n
}

fn main() {
    println!("{}", count_vowels("программирование"));
}
```
```expect
7
```
hint: Перебирай буквы: `for c in s.chars()`.
hint: Проверка гласной: `"аеёиоуыэюя".contains(c)`.

:: task
Напиши функцию `double_all`, которая удваивает каждый элемент вектора через `&mut`.
```rust
fn double_all(v: &mut Vec<i32>) {
}

fn main() {
    let mut nums = vec![1, 2, 3];
    double_all(&mut nums);
    println!("{:?}", nums);
}
```
```solution
fn double_all(v: &mut Vec<i32>) {
    for x in v.iter_mut() {
        *x *= 2;
    }
}

fn main() {
    let mut nums = vec![1, 2, 3];
    double_all(&mut nums);
    println!("{:?}", nums);
}
```
```expect
[2, 4, 6]
```
hint: `for x in v.iter_mut()` даёт изменяемую ссылку на каждый элемент.
hint: Значение по ссылке меняют через `*`: `*x *= 2;`

Почини ошибку E0502: печать ссылки мешает изменению. Поменяй порядок строк так, чтобы программа напечатала `1` и `[1, 2, 3, 4]`.

:: task
Напиши функцию `sum`, которая принимает срез `&[i32]` и возвращает сумму. Она должна работать и с массивом, и с вектором.
```rust
// напиши функцию sum

fn main() {
    let arr = [1, 2, 3];
    let v = vec![10, 20];
    println!("{} {}", sum(&arr), sum(&v));
    println!("{}", sum(&arr[1..]));
}
```
```solution
fn sum(items: &[i32]) -> i32 {
    let mut total = 0;
    for x in items {
        total += x;
    }
    total
}

fn main() {
    let arr = [1, 2, 3];
    let v = vec![10, 20];
    println!("{} {}", sum(&arr), sum(&v));
    println!("{}", sum(&arr[1..]));
}
```
```expect
6 30
5
```
hint: Заголовок: `fn sum(items: &[i32]) -> i32`
hint: `&arr[1..]` — срез от второго элемента до конца.

:: recap
- `&` — читать, `&mut` — менять.
- Пока есть читатель, писать нельзя: заканчивай работу со ссылкой раньше.
- Параметр `&[i32]` принимает и массив, и вектор, и их части.
