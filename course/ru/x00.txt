# MODULE x00 | Добро пожаловать в мастерскую | Как здесь учиться, домашние задания и разминка

## LESSON x00-1 | Как устроен третий уровень | 6
:: goals
- Понять, чем мастерская отличается от первых двух уровней
- Узнать, что такое домашние задания

:: text Мастерская
Первый уровень учил водить. Второй открыл капот. Третий — **мастерская**: тут собирают свои детали.

Что изменилось:
- **Практики больше, чем теории.** В каждом уроке несколько задач, в конце модуля — большая практика.
- **Темы глубже.** Свои аллокаторы, свой Future, lock-free, макросы, веб, базы данных.
- **Есть домашние задания.** Некоторые вещи не помещаются в один файл Playground: веб-сервер, свой процедурный макрос, прошивка для платы. Их делают на своём компьютере.

Правила прежние: короткие шаги, «Углубиться» можно пропускать, прогресс сохраняется сам.

> **Аналогия:** раньше ты собирал модели по инструкции. Теперь у тебя верстак, инструменты и чертежи — а детали ты вытачиваешь сам.

:: text Домашние задания
Карточка «Домашнее задание» выглядит так:
- что сделать — по шагам, с командами `cargo`;
- список **самопроверки**: пункты, которые ты отмечаешь сам.

Сайт такой код не запускает. Отметки нужны тебе: видно, что сделано. Идти дальше можно и без них.

Для домашних заданий нужен Rust на компьютере. Ставится одной командой с сайта **rustup.rs**.

:: quiz
Что делает сайт с домашним заданием?
[ ] Проверяет код автоматически => Нет, такой код запускается на твоём компьютере.
[x] Запоминает пункты самопроверки, которые ты отметил => Верно.
[ ] Не пускает дальше, пока всё не отмечено => Не запирает: идти дальше можно всегда.

:: homework Подготовь верстак
Поставь Rust и проверь, что всё работает.

1. Установи Rust с сайта **rustup.rs** (Windows: скачай `rustup-init.exe`; macOS и Linux: одна команда в терминале).
2. Проверь версии:
```sh
rustc --version
cargo --version
```
3. Создай проект и запусти его:
```sh
cargo new workshop
cd workshop
cargo run
```
4. Поставь редактор с подсказками: VS Code + расширение **rust-analyzer** (или RustRover).
[ ] `cargo --version` печатает версию
[ ] `cargo run` в новом проекте печатает `Hello, world!`
[ ] В редакторе работают подсказки и подчёркивание ошибок

:: recap
- Мастерская: много практики и глубокие темы.
- Домашние задания — на своём компьютере, самопроверка отмечается вручную.
- Rust ставится через rustup.rs.

## LESSON x00-2 | Читаем ошибки компилятора как профи | 8
:: goals
- Разбирать длинные сообщения компилятора по частям
- Пользоваться `rustc --explain`

:: text Ошибка — это подсказка
На третьем уровне сообщения компилятора станут длиннее: обобщения, времена жизни, трейты. Но устроены они одинаково:
1. **Код ошибки** — `error[E0502]`.
2. **Главная фраза** — что не так.
3. **Стрелки** под кодом — где именно.
4. **help** и **note** — как починить. Часто там готовое исправление.

Читай сверху вниз и сначала смотри **первую** ошибку: остальные часто её последствия.

> **Аналогия:** навигатор говорит «через 200 метров поверните направо». Он не ругается — он показывает дорогу.

:: text rustc --explain
У каждой ошибки есть подробное объяснение с примерами:
```sh
rustc --explain E0502
```
То же самое есть на сайте: «Rust error codes index». В Playground можно просто нажать на код ошибки.

:: code
Этот код не скомпилируется. Запусти и прочитай ошибку: код, главная фраза, стрелки, help.
```rust
fn main() {
    let mut list = vec![1, 2, 3];
    let first = &list[0];
    list.push(4);
    println!("{first}");
}
```
fails: yes
Ошибка `E0502`: нельзя изменять `list` (`push`), пока жива ссылка `first`. Починить можно, перенеся `println!` выше `push`, или скопировав число: `let first = list[0];`.

:: quiz
В выводе компилятора пять ошибок. С какой начинать?
[x] С первой => Верно. Остальные часто следуют из неё.
[ ] С последней => Последние обычно последствия первых.
[ ] С самой короткой => Длина ничего не говорит о важности.

:: task
Почини код, не меняя смысла: сначала напечатать первый элемент, потом добавить `4` и напечатать длину.
```rust
fn main() {
    let mut list = vec![1, 2, 3];
    let first = &list[0];
    list.push(4);
    println!("{first}");
    println!("{}", list.len());
}
```
```solution
fn main() {
    let mut list = vec![1, 2, 3];
    let first = list[0];
    list.push(4);
    println!("{first}");
    println!("{}", list.len());
}
```
```expect
1
4
```
hint: `i32` — `Copy`. Возьми копию числа вместо ссылки: `let first = list[0];`.

:: task
Почини ошибку `E0382` (использование после перемещения): функция должна только **посмотреть** на строку.
```rust
fn shout(s: String) -> String {
    s.to_uppercase()
}

fn main() {
    let name = String::from("ferris");
    println!("{}", shout(name));
    println!("{name}");
}
```
```solution
fn shout(s: &str) -> String {
    s.to_uppercase()
}

fn main() {
    let name = String::from("ferris");
    println!("{}", shout(&name));
    println!("{name}");
}
```
```expect
FERRIS
ferris
```
hint: Пусть функция берёт `&str`, а вызов будет `shout(&name)`.

:: recap
- Код ошибки, главная фраза, стрелки, help — читай по порядку.
- Начинай с первой ошибки.
- `rustc --explain E0XXX` — подробное объяснение.

## LESSON x00-3 | Как писать задачи мастерской | 6
:: goals
- Узнать формат задач третьего уровня
- Привыкнуть к тестам внутри задач

:: text Задачи стали больше
Многие задачи теперь проверяются не выводом, а **тестами**: в коде есть `#[cfg(test)] mod tests`, и сайт запускает `cargo test`. Задача решена, когда все тесты зелёные.

Так проверяют настоящие проекты: не «напечатало ли то», а «работает ли функция на разных входах».

:: text Как решать большую задачу
1. Прочитай условие и **тесты**: они говорят точнее любого текста.
2. Сначала добейся, чтобы код **скомпилировался** — можно с `todo!()` внутри.
3. Потом чини тесты по одному.
4. Застрял — открой подсказку. Это не стыдно, это инструмент.

> **Аналогия:** тесты — как чертёж с размерами. Деталь готова, когда все размеры совпали.

:: task
Допиши `median`, чтобы тесты прошли. Пустой срез — `None`; при чётной длине — среднее двух средних (округление вниз).
```rust
pub fn median(v: &[i32]) -> Option<i32> {
    todo!()
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn empty() {
        assert_eq!(median(&[]), None);
    }

    #[test]
    fn odd() {
        assert_eq!(median(&[5, 1, 3]), Some(3));
    }

    #[test]
    fn even() {
        assert_eq!(median(&[4, 1, 3, 2]), Some(2));
    }
}
```
```solution
pub fn median(v: &[i32]) -> Option<i32> {
    if v.is_empty() {
        return None;
    }
    let mut s = v.to_vec();
    s.sort();
    let n = s.len();
    if n % 2 == 1 {
        Some(s[n / 2])
    } else {
        Some((s[n / 2 - 1] + s[n / 2]) / 2)
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn empty() {
        assert_eq!(median(&[]), None);
    }

    #[test]
    fn odd() {
        assert_eq!(median(&[5, 1, 3]), Some(3));
    }

    #[test]
    fn even() {
        assert_eq!(median(&[4, 1, 3, 2]), Some(2));
    }
}
```
tests: yes
hint: Скопируй срез в `Vec` (`v.to_vec()`) и отсортируй.
hint: Для `[1, 2, 3, 4]` средние — индексы `1` и `2`: `(2 + 3) / 2 = 2`.

:: recap
- Задачи с тестами: решено, когда все тесты прошли.
- Сначала скомпилируй (можно с `todo!()`), потом чини тесты.
- Тесты — самое точное условие задачи.

:: task
Итератор `Pairs` выдаёт соседние пары элементов среза: для `[1, 2, 3]` — `(1, 2)`, `(2, 3)`. Допиши `next`.
```rust
struct Pairs<'a> {
    items: &'a [i32],
    pos: usize,
}

impl<'a> Iterator for Pairs<'a> {
    type Item = (i32, i32);
    fn next(&mut self) -> Option<(i32, i32)> {
        // твой код
    }
}

fn main() {
    let v: Vec<(i32, i32)> = Pairs { items: &[1, 2, 3, 4], pos: 0 }.collect();
    println!("{v:?}");
}
```
```solution
struct Pairs<'a> {
    items: &'a [i32],
    pos: usize,
}

impl<'a> Iterator for Pairs<'a> {
    type Item = (i32, i32);
    fn next(&mut self) -> Option<(i32, i32)> {
        if self.pos + 1 >= self.items.len() {
            return None;
        }
        let r = (self.items[self.pos], self.items[self.pos + 1]);
        self.pos += 1;
        Some(r)
    }
}

fn main() {
    let v: Vec<(i32, i32)> = Pairs { items: &[1, 2, 3, 4], pos: 0 }.collect();
    println!("{v:?}");
}
```
```expect
[(1, 2), (2, 3), (3, 4)]
```
hint: Если `pos + 1` уже за краем — `None`.

Функция `group_by_len` раскладывает слова по длине в `BTreeMap<usize, Vec<&str>>`. Допиши так, чтобы тесты прошли.

    todo!()

        let g = group_by_len(&["кот", "ёж", "пёс", "rust"]);
        assert_eq!(g[&2], vec!["ёж"]);
        assert_eq!(g[&3], vec!["кот", "пёс"]);

```solution
use std::collections::BTreeMap;

pub fn group_by_len<'a>(words: &[&'a str]) -> BTreeMap<usize, Vec<&'a str>> {
    let mut g: BTreeMap<usize, Vec<&'a str>> = BTreeMap::new();
    for w in words {
        g.entry(w.chars().count()).or_default().push(*w);
    }
    g
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn groups() {
        let g = group_by_len(&["кот", "ёж", "пёс", "rust"]);
        assert_eq!(g[&2], vec!["ёж"]);
        assert_eq!(g[&3], vec!["кот", "пёс"]);
        assert_eq!(g[&4], vec!["rust"]);
    }
}
```
tests: yes
hint: Длину считай в символах: `w.chars().count()`.
hint: `g.entry(len).or_default().push(w)` — создать пустой `Vec` при первом появлении.

:: task
Сделай `impl From<&str> for Rgb`, который разбирает `"#ff8000"` в три байта. Неверная строка — чёрный цвет `Rgb(0, 0, 0)`.
```rust
#[derive(Debug, PartialEq)]
struct Rgb(u8, u8, u8);

// твой код

fn main() {
    let a: Rgb = "#ff8000".into();
    let b: Rgb = "oops".into();
    println!("{a:?} {b:?}");
}
```
```solution
#[derive(Debug, PartialEq)]
struct Rgb(u8, u8, u8);

impl From<&str> for Rgb {
    fn from(s: &str) -> Self {
        let parse = |i: usize| s.get(i..i + 2).and_then(|h| u8::from_str_radix(h, 16).ok());
        if s.len() == 7 && s.starts_with('#') {
            if let (Some(r), Some(g), Some(b)) = (parse(1), parse(3), parse(5)) {
                return Rgb(r, g, b);
            }
        }
        Rgb(0, 0, 0)
    }
}

fn main() {
    let a: Rgb = "#ff8000".into();
    let b: Rgb = "oops".into();
    println!("{a:?} {b:?}");
}
```
```expect
Rgb(255, 128, 0) Rgb(0, 0, 0)
```
hint: `u8::from_str_radix("ff", 16)` превращает шестнадцатеричный текст в число.
hint: `s.get(1..3)` безопасно берёт кусок строки и вернёт `None`, если его нет.

:: task
Замыкание-счётчик: `make_counter()` возвращает `impl FnMut() -> u32`, которое при каждом вызове возвращает следующее число, начиная с 1.
```rust
fn make_counter() -> impl FnMut() -> u32 {
    // твой код
}

fn main() {
    let mut c = make_counter();
    let mut d = make_counter();
    println!("{} {} {}", c(), c(), c());
    println!("{}", d());
}
```
```solution
fn make_counter() -> impl FnMut() -> u32 {
    let mut n = 0;
    move || {
        n += 1;
        n
    }
}

fn main() {
    let mut c = make_counter();
    let mut d = make_counter();
    println!("{} {} {}", c(), c(), c());
    println!("{}", d());
}
```
```expect
1 2 3
1
```
hint: `let mut n = 0; move || { n += 1; n }` — у каждого счётчика своё `n`.

:: recap
- Итераторы, `BTreeMap`, `From`, замыкания со состоянием — база для мастерской.
- Если что-то далось трудно — повтори модуль второго уровня по этой теме.
