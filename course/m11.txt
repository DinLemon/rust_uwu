# MODULE m11 | Модули и Cargo | Как устроен настоящий проект

## LESSON m11-1 | Модули: mod, pub, use | 6
:: goals
- Раскладывать код по модулям
- Решать, что видно снаружи

:: text Модуль — папка для кода
Большую программу делят на **модули** (`mod`). Это как ящики в шкафу: инструменты отдельно, документы отдельно.

```rust
mod math {
    pub fn double(x: i32) -> i32 {
        x * 2
    }
    fn secret() {} // видно только внутри math
}
```

:: text pub — открыть наружу
По умолчанию всё внутри модуля **закрыто**. Чтобы пользоваться снаружи, пометь `pub` (public — публичный).

Обращаются через `::` — `math::double(5)`.

`use` создаёт короткое имя: после `use math::double;` можно писать просто `double(5)`.

:: code
```rust
mod shop {
    pub struct Item {
        pub name: String,
        price: u32,
    }

    impl Item {
        pub fn new(name: &str, price: u32) -> Self {
            Item { name: name.to_string(), price }
        }
        pub fn price_with_tax(&self) -> u32 {
            self.price * 120 / 100
        }
    }
}

use shop::Item;

fn main() {
    let it = Item::new("чай", 100);
    println!("{}: {} руб.", it.name, it.price_with_tax());
}
```
```out
чай: 120 руб.
```
Поле `price` закрыто: снаружи его не прочесть и не испортить. Доступ — только через метод.

:: quiz
Что будет, если вызвать `math::secret()` из `main`?
[ ] Сработает => `secret` без `pub`, значит она закрыта.
[x] Ошибка: функция приватная => Верно. Без `pub` — только для своих.

:: recap
- `mod имя { }` — модуль.
- Всё закрыто, пока не помечено `pub`.
- `use путь::имя;` — короткое имя.

## LESSON m11-2 | Установка Rust на компьютер | 7
:: goals
- Установить Rust через rustup
- Выбрать редактор

:: text Пора на свой компьютер
До сих пор мы запускали код в браузере. Для настоящих проектов Rust ставят на компьютер.

Официальный установщик называется **rustup**. Он ставит компилятор `rustc`, менеджер проектов `cargo` и документацию.

:: text Windows
1. Открой [rust-lang.org/tools/install](https://www.rust-lang.org/tools/install).
2. Скачай `rustup-init.exe` и запусти.
3. Он предложит поставить Visual Studio Build Tools — соглашайся. Это нужно для сборки программ.
4. Жми Enter на стандартных настройках.

> Установка занимает 5–15 минут. Хороший момент для перерыва.

:: text macOS и Linux
Открой терминал и вставь одну команду:

```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
На Linux ещё понадобится компилятор C: пакет `build-essential` (Ubuntu) или похожий.

:: text Проверь, что всё работает
Открой **новое** окно терминала и введи:

```sh
rustc --version
cargo --version
```
Должны появиться номера версий. Например, `rustc 1.99.1`. Версии выходят каждые 6 недель. Обновиться: `rustup update`.

:: text Редактор
- **VS Code** + расширение **rust-analyzer**. Бесплатно. Подсветка, подсказки, ошибки прямо в коде.
- **RustRover** от JetBrains. Бесплатен для некоммерческого использования.

> rust-analyzer показывает типы переменных серым прямо в коде. Для новичка это очень помогает.

:: quiz
Как называется официальный установщик Rust?
[x] rustup => Верно. Он ставит и обновляет весь набор инструментов.
[ ] cargo => `cargo` ставится вместе с Rust. Это менеджер проектов.
[ ] npm => Это менеджер пакетов JavaScript.

:: recap
- Установка — через rustup с rust-lang.org.
- Проверка: `rustc --version`, обновление: `rustup update`.
- Редактор: VS Code + rust-analyzer или RustRover.

## LESSON m11-3 | Cargo: первый проект | 7
:: goals
- Создать проект командой `cargo new`
- Собрать и запустить его

:: text Cargo — завхоз проекта
**Cargo** создаёт проекты, собирает их, запускает, скачивает библиотеки и гоняет тесты. Почти всё делают через него.

:: text Новый проект
```sh
cargo new hello
cd hello
cargo run
```
Ты увидишь `Hello, world!`. Cargo уже написал программу за тебя.

:: text Что внутри
```sh
hello/
├── Cargo.toml     ← описание проекта
└── src/
    └── main.rs    ← твой код
```
`Cargo.toml` выглядит так:

```sh
[package]
name = "hello"
version = "0.1.0"
edition = "2024"

[dependencies]
```
`edition = "2024"` — какая редакция языка. Мы весь курс пишем на 2024.

:: text Главные команды
- `cargo run` — собрать и запустить.
- `cargo check` — только проверить ошибки. Очень быстро.
- `cargo build --release` — собрать быструю версию для пользователей.
- `cargo test` — запустить тесты.
- `cargo fmt` — красиво выровнять код.
- `cargo clippy` — подсказки, как писать лучше.

:: quiz
Какая команда быстрее всего покажет ошибки компиляции, ничего не запуская?
[ ] `cargo run` => Она ещё и запускает. Медленнее.
[x] `cargo check` => Верно. Только проверка, без сборки программы.
[ ] `cargo build --release` => Это самая долгая сборка: с оптимизацией.

:: recap
- `cargo new имя` — новый проект.
- Код в `src/main.rs`, настройки в `Cargo.toml`.
- `run`, `check`, `build --release`, `test`, `fmt`, `clippy`.

## LESSON m11-4 | Крейты и библиотеки | 5
:: goals
- Что такое крейт
- Как подключить чужую библиотеку

:: text Крейт — единица кода
**Крейт** (crate) — то, что собирается за один раз: программа или библиотека.

Тысячи готовых библиотек лежат на сайте [crates.io](https://crates.io). Не нужно писать всё самому.

:: text Подключаем библиотеку
Например, библиотеку случайных чисел `rand`. В папке проекта:

```sh
cargo add rand
```
Cargo сам допишет её в `Cargo.toml` и скачает при сборке. Потом в коде:

```
use rand::Rng;
let n = rand::rng().random_range(1..=6);
```
!> Rust Playground знает только самые популярные библиотеки. Поэтому в задачах курса мы обходимся стандартной библиотекой `std`.

:: text Модули в разных файлах
В настоящем проекте модуль часто лежит в своём файле. Если в `main.rs` написать `mod shop;` (с точкой с запятой), Cargo возьмёт код из `src/shop.rs`.

:: quiz
Где искать готовые библиотеки для Rust?
[x] crates.io => Верно. Это официальный реестр крейтов.
[ ] В Rust Playground => Playground лишь запускает код. Библиотеки живут на crates.io.
[ ] В Cargo.toml => В `Cargo.toml` их только перечисляют, а лежат они на crates.io.

:: recap
- Крейт — программа или библиотека.
- Библиотеки — на crates.io, подключать: `cargo add имя`.
- `mod shop;` берёт код из файла `src/shop.rs`.
